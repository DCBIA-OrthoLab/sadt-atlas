ASO — 출처

ASO의 참고문헌: 이 폴더에 받아 둔 자료, 아직 온라인으로 읽어야 하는 자료, 그리고 주변 연구, 즉 코드를 설명하지는 않지만 방법의 토대가 되는 연구.

저장소 전체 PDF 29개 / 전문 54개 ← 파이프라인 페이지

ASO_CBCT는 발표되었다. MICCAI 워크숍 논문집의 한 장(LNCS 14242, 2023)이며, AREG_CBCT와 공유한다. 같은 글이 방향 정렬(ASO)과 정합(AREG)을 함께 설명한다. 이 장은 Springer에서 유료지만, 저자 원고는 PMC에서 무료로 읽을 수 있다(PMC11104011). PMC는 자동화된 PDF 다운로드를 막기 때문에 여기에 받아 둘 수 없었다( "온라인 열람" 참조). ASO_IOS에는 자체 논문이 없다. 가장 가까운 발표 문헌은 AReg IOS(Hutin et al., LNCS 14350, 2023)로, 공유 치아 중심점을 이용한 초기 정렬, 즉 PrePreAso를 설명한다.

이 장의 ASO_CBCT 설명은 코드와 일치한다(ALI_CBCT 랜드마크, 랜드마크 3개 정렬 후 ICP 정밀화). 논문에 없는 DenseNet 사전 방향 정렬기는 실제로 더 이상 연결되어 있지 않다. 다만 같은 장의 AREG 부분에는 주의해야 한다. 현재 정합 코드를 더 이상 설명하지 않는다(2회가 아닌 1회 실행, SimpleElastix 대신 itk-elastix, AMASSS는 nnU-Net v2 사용, UNETR 아님). 자세한 내용은 ../AREG_CBCT/SOURCES.md.

관련 연구

이 연구들은 ASO를 설명하지 않는다. 방법의 토대가 되거나 실제 사용을 보여 준다.

  • Ruellas 2016, Common 3-dimensional coordinate system. ASO가 방향을 맞추는 공통 좌표계를 정의한 논문이다. 먼저 머리 방향이 3D에서 측정되는 변위 값을 바꾼다는 것을 보이고, 이어 랜드마크로 공통 좌표계를 구성하는 방법을 제안한다. ASO의 방향 정렬 "gold standard"와 모듈에 포함된 기준 랜드마크는 이 규약에서 나온다. ASO도 딥러닝도 언급하지 않으며, 모든 것이 수동이다.
  • Gillot 2023, ALI_CBCT. ASO_CBCT가 입력 방향과 무관하게 점을 찾기 위해 의존하는 강화학습 랜드마크 검출기. 32개 랜드마크와 다중 스케일 에이전트를 설명하며, 방향 정렬 단계는 설명하지 않는다. 별도 페이지: ../ALI/.
  • Barone 2024 (AJODO). 검증이 아닌 임상 사용이다. 논문은 3D Slicer에서 CBCT의 "deep-learning-based automated tools were used for orientation, registration, bone segmentation and landmark identification"이라고 적는다. 즉 ASO + AREG + AMASSS + ALI를 실제 조건에서, 수술받은 Class III 환자 17명에게 사용했다.
  • NA-MIC Project Week 페이지, DOI 없음: PW38 2023 Gran Canaria — ASO_CBCT (Anchling, Hutin, Gillot, Baquero, Bianchi, Ruellas, Miranda, Barone, Gurgel, Yatabe, Al Turkestani, Joshi, Cevidanes, Prieto). 한 번도 연결되지 않은 "테스트 중" 사전 방향 정렬기가 설명된 곳이다. 그리고 PW38 — Automatic Standardize Orientation IOS (Hutin, Anchling, Gurgel, Miranda, Al Turkestani, Barone, Cevidanes, Prieto). 전체 ASO_IOS 파이프라인에 대한 유일한 서면 설명이다. 대구치와 절치에 의한 사전 방향 정렬, 중심점 3개에 대한 ICP, ALI_IOS 랜드마크, occlusion 모드.
  • 코드 저장소, DOI 없음: lucanchling/ASO, DCBIA-OrthoLab/ASO, DCBIA-OrthoLab/SlicerAutomatedDentalTools.

찾아보았지만 찾지 못한 것

  • PMC 외의 곳에 있는 LNCS 장의 오픈 액세스 저자 판: Deep Blue(University of Michigan), HAL/DUMAS, Unpaywall, OpenAlex. 없음.
  • ASO_IOS 자체 논문, 그리고 ALI_IOS 논문(ASO_IOS가 사용하는 IOS 랜드마크 검출기): Europe PMC, Crossref, OpenAlex 어디에도 없음. 본 페이지의 내용을 뒷받침한다.
  • 방향 정렬만을 따로 다룬 임상 검증(IADR / AADOCR / AAO 포스터, ASO 재현성 논문): 색인된 것 없음. ASO에 대해 발표된 수치는 여전히 LNCS 장의 것이다(전문가 대비 < 3°, < 2 mm). IADR 초록에는 DOI가 없으므로, 있다면 IADR 초록 아카이브에서 찾아야 한다.
  • DenseNet 사전 방향 정렬기를 설명한 출판물: PW38 Project Week 페이지의 한 단락 외에는 없음.

전문을 받은 방법

이 장은 Springer에서 유료지만, NIH에 기탁된 저자 원고는 오픈 액세스다. 이에 대해 두 방법은 실패하고 하나는 성공한다. 같은 과정을 다시 밟지 않도록 여기에 적어 둔다.

경로이 PMCID에 대한 결과
pmc.ncbi.nlm.nih.gov/.../pdf/봇 차단 HTML
BioC API pmcoa.cgi"No result can be found" — open access subset만 제공한다
eutils.ncbi.nlm.nih.gov/entrez/eutils/efetch.fcgi?db=pmc&id=<number>본문을 포함한 전체 JATS
 
curl -sL "https://eutils.ncbi.nlm.nih.gov/entrez/eutils/efetch.fcgi?db=pmc&id=11104011"
