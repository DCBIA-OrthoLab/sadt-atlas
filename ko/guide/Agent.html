Agent — 로컬 어시스턴트에게 도구 선택 맡기기

Agent는 전적으로 사용자 컴퓨터에서 실행되는 대화형 어시스턴트입니다. 하고 싶은 일을 평범한 말로 설명하면, 선택한 모드에 따라 확장의 도구 하나를 매개변수까지 채워서 제안하거나, 그냥 답변만 합니다.

영상
  • AI Agent directly in 3D Slicer to help you learn dental and cranofacial imaging 30초 (개요) · DCBIA Videos 채널
사용해 보기 전에 읽어 주십시오

현재 저장소 상태로는 Agent가 실행하려는 도구를 찾지 못합니다. 직접 설정하지 않는 한, 도구를 실행하려는 시도는 모두 실패합니다. 아무것도 실행하지 않고 답변만 하는 모드는 영향을 받지 않으며 정상적으로 동작합니다.

언제 쓰는가

확장의 어느 모듈이 필요한 작업에 맞는지 찾아다니거나 명령줄을 직접 만들고 싶지 않을 때 씁니다. "이 CBCT들을 방향 정렬해 줘", "이 스캔들을 분할해 줘"처럼 작업을 설명하면, Agent가 요청에서 이해한 매개변수와 함께 도구를 제안합니다. 아무것도 실행할 필요가 없는 질문에는 "Ask" 모드에서 단순한 상담 창구로도 쓸 수 있습니다.

먼저 설치할 것

Agent는 사용자 컴퓨터에서 로컬로 실행되는 언어 모델 서버인 Ollama에 의존합니다. 아직 설치되어 있지 않다면 모듈이 대신 다운로드하고 실행해 주겠다고 제안합니다. 어느 쪽이든 첫 질문을 하기 전에 첫 실행에서 수 기가바이트를 다운로드한다고 생각하십시오. 언어 모델만 해도 5 GB가 조금 넘습니다.

Slicer 쪽에서 직접 설치할 것은 없습니다

필요한 Python 패키지는 첫 실행 시 Slicer 자체의 Python 안에 자동으로 설치됩니다.

필요한 것, 얻는 것

준비할 것

  • 영어 또는 프랑스어로, 평범한 말로 쓴 요청
  • 원하는 모드: 실제로 무언가를 실행하려면 Agent (Automated), 대화만 하려면 Ask (Interactive)
  • 해당되는 경우, 관련 폴더를 드롭 영역에 끌어다 놓기

얻는 것

  • Agent 모드: 선택된 도구, 그 매개변수, 확인 대화상자, 그리고 승인하면 실행
  • Ask 모드: 자유 서술형 답변, 아무것도 실행되지 않음
  • 도구가 실패하면 최대 두 번의 자동 복구 시도, 매번 별도의 확인을 거침

사용 절차

  1. Ollama가 실행 중인지 확인합니다. 필요하면 Agent가 설치하고 실행하도록 맡기고, 첫 실행 시 모델 다운로드가 끝날 때까지 기다립니다.
  2. 모드를 고릅니다. 도구를 실제로 실행하려면 "Agent (Automated)", 답변만 받으려면 "Ask (Interactive)".
  3. 원하는 것을 설명합니다. 동료에게 설명하듯 평범한 말로 씁니다.
  4. 요청에 특정 데이터가 관련되면 관련 폴더를 드롭 영역에 놓습니다. Agent가 어느 폴더가 무엇인지 추측하려 합니다.
  5. 메시지를 보냅니다. Agent 모드에서는 도구와 매개변수가 제안되고, Ask 모드에서는 바로 답변이 돌아옵니다.

확인 대화상자 읽기

Agent 모드에서는 사용자가 "Yes"를 누르지 않으면 아무것도 실행되지 않습니다. 대화상자에는 결정된 모든 매개변수가 key=value 쌍으로 나열됩니다. 도구가 실제로 시작되기 전에, 잘못 추측된 폴더나 의도와 다른 값을 잡아낼 수 있는 곳은 여기뿐입니다.

모든 줄을 꼼꼼히 읽으십시오

대부분의 도구에서, Agent가 전달한다고 믿는 것과 도구가 실제로 기대하는 것 사이의 대응이 맞지 않습니다. 따라서 사전에 아무 오류 경고 없이 잘못된 값으로 실행이 시작될 수 있습니다. 확인 대화상자가 유일한 실질적 점검 수단입니다.

승인하면 실행된 도구가 끝날 때까지 Slicer 인터페이스가 멈춥니다. 정상적인 동작이며, 기다리는 것 외에 할 일은 없습니다.

문제가 생기면

"아무것도 실행되지 않거나, 오류가 이해되지 않습니다"

현재 저장소 상태로는 Agent가 실행하려는 스크립트를 스스로 찾지 못합니다. 위치를 직접 알려 주지 않으면 실행은 시작되기도 전에 실패합니다. 이어지는 자동 복구 단계로는 이를 고칠 수 없습니다. 문제는 매개변수가 아니라 스크립트 경로에 있기 때문입니다.

잘못된 값으로 시작되는 실행

위를 참고하십시오. 승인하기 전에 항상 확인 대화상자를 점검하십시오. 매개변수 불일치는 보통 오류 메시지가 아니라 그 대화상자에서 눈으로만 확인할 수 있습니다.

그래픽 카드가 없으면 모든 것이 느립니다

모델 서버가 GPU 없이 실행 중이라면 답변 하나에 대략 1분 30초가 걸린다고 생각하십시오. 주고받는 대화는 몇 초가 아니라 몇 분 단위로 쌓입니다.

Agent 자체에 관한 문헌

  • NA-MIC Project Week 45, Boston 2026 — AI-Agent for SlicerAutomatedDentalTools. 프로젝트 보고서입니다. 에이전트가 무엇을 하도록 설계되었는지, 작업이 어디까지 진행되었는지 다룹니다.

방법론 관련 문헌

  • Qwen Team, arXiv 2025 — Qwen3 Technical Report. 어느 도구로 안내할지 결정하고 그 도구의 매개변수를 추출하는 모델입니다.
  • Reimers & Gurevych, EMNLP 2019 — Sentence-BERT: Sentence Embeddings using Siamese BERT-Networks. 질문을 색인된 문서와 어떻게 비교하는지 설명합니다. 에이전트가 답하기 전에 무엇을 보게 될지 결정하는 단계입니다.
  • Nogueira & Cho, arXiv 2019 — Passage Re-ranking with BERT. 검색된 구절에 이어서 적용하는 재순위화로, 상위에 오르는 결과를 크게 개선합니다.

이 도구의 전체 참고문헌 — 찾아낸 것과 찾아봤지만 없었던 것 — 은 출처 페이지에 있습니다.
