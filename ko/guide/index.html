사용 가이드

각 도구가 무엇을 하는지, 무엇을 넣어야 하는지, 무엇을 돌려주는지 — 코드는 다루지 않습니다. 내부 동작이 궁금하다면 아틀라스로 넘어가십시오.

이 가이드의 대상

3D Slicer에서 SlicerAutomatedDentalTools를 열고 사용하려는 모든 분 — 임상의, 연구자, 학생 — 을 위한 가이드입니다. 코드를 읽을 줄 알거나 신경망이 무엇인지 알 필요는 없습니다. 내부 동작 — 어떤 모델이 언제, 어떤 데이터로 호출되는지 — 이 궁금하다면 아틀라스를 보십시오. 두 섹션은 같은 20개 모듈을 서로 반대쪽에서 다룹니다.

왜 만들었는가

이 확장 기능은 서로 다른 팀이 서로 다른 시기에 작성한 20개 모듈을 모아 놓은 것입니다. 문서는 경우에 따라 README 몇 줄, 프로젝트 페이지 하나, 혹은 아예 없습니다. 여러 모듈이 논문에 기술된 것과 다르게 동작합니다. 논문이 설명하는 버전을 코드가 더 이상 실행하지 않기 때문입니다.

이 가이드는 각 모듈의 문서가 아니라 코드를 읽고 작성했습니다. 따라서 클릭했을 때 도구가 실제로 무엇을 하는지, 불편한 부분까지 그대로 적었습니다. 경고 79건과 버그 4건을 실제로 부딪히기 쉬운 바로 그 지점에 표시해 두었습니다. 여기서 고친 것은 없습니다 — 그 때문에 하루를 허비하지 않게 하는 것이 목적입니다.

각 페이지의 구성

모든 페이지가 같은 구성을 따르므로 전부 다시 읽지 않고도 찾을 곳을 알 수 있습니다.

  • 언제 쓰는가 — 도구가 해결하는 문제와, 쓸모가 없는 경우.
  • 필요한 것, 얻는 것 — 필요한 입력과 그 형식, 그리고 최종 결과물.
  • 사용 절차 — 순서대로, 항목 하나하나.
  • 문제가 생기면 — 자주 일어나는 실패와 그 원인.
  • 더 읽을거리 — 도구의 바탕이 된 논문(있는 경우)과 아틀라스 페이지로 가는 링크.

어디서 시작할까

찾는 도구를 이미 알고 있다면 아래 목록에서 고르십시오. 그렇지 않다면 하려는 일에서 출발하십시오.

  • 같은 환자의 두 검사를 시간에 따라 비교 → 정합

  • 형상으로부터 측정·분류·예측 → 분석
  • 일괄 크롭 또는 행렬 적용 → 유틸리티
