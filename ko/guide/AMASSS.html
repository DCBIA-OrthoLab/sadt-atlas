AMASSS: CBCT에서 구조 분할하기

AMASSS는 두개악안면 CBCT의 해부학적 구조(하악, 상악, 두개저, 상기도, 경추, 피부)를 자동으로 분할하며, 각각은 그 구조만을 위해 학습된 네트워크가 예측합니다. 대비나 윈도잉을 손으로 조정할 필요가 없으며, 모듈이 스스로 처리합니다.

영상
  • AMASSS - Automatic Multi-Anatomical Skull Structure Segmentation4분 11초 · DCBIA Videos 채널
  • AMASSS RC Seg tutorial5분 08초 · DCBIA Videos 채널
이 페이지의 레거시 모듈

이 페이지는 레거시 Slicer 모듈을 설명합니다. VISOR 서버로 사용하는 방법은 VISOR와 함께와 VISOR 사용하기를 보십시오.

언제 쓰는가

CBCT에서 뼈, 기도, 피부 분할이 필요할 때는 언제든 쓸 수 있으며, 환자 한 명에도 배치 전체에도 쓸 수 있습니다. AMASSS는 다른 두 도구의 뒤에서도 돌아갑니다. AREG_CBCT는 같은 환자의 CBCT 스캔 두 개를 정합하는 데, VFACE는 비대칭 분석에 이를 사용합니다. 이 둘 중 하나를 쓴다면, 이 모듈을 열지 않아도 AMASSS의 작업 일부는 이미 대신 이루어지고 있습니다.

분할할 수 있는 것

공개된 번들에 학습된 모델이 있는 구조는 여섯 가지입니다.

각 구조는 그 구조 하나만 아는 네트워크가 예측합니다. 하악과 상악을 분할하면 서로 독립적인 계산 두 번이 실행되며, 여러 구조를 한꺼번에 다루는 단일 모델이 아닙니다. 일부 설정 목록에는 그 밖의 항목(치아, 치근관, 하악관)이 나오지만 공개된 번들에는 학습된 모델이 없습니다. 이를 체크해도 아무것도 분할되지 않습니다(아래에 자세히 설명).

필요한 것, 얻는 것

준비할 것

  • CBCT 한 개, 또는 여러 CBCT 스캔이 든 폴더. .nii, .nii.gz, .nrrd, .nrrd.gz 형식
  • 학습된 모델 (한 번만 다운로드)
  • 원하는 구조 (목록에서 체크)

나오는 것

  • 구조마다 이진 마스크 하나, 또는 구조마다 고유한 값을 가진 병합 맵 하나
  • 요청하면 구조별로 색이 입혀진 3D 표면(.vtk)이 바로 표시할 수 있는 상태로 나옵니다
  • 원본 스캔은 건드리지 않습니다

단계별 안내

  1. 모델을 다운로드합니다. "Download latest models" 버튼이 모델 아카이브(약 2 GB)를 한 번 다운로드하고 모델 폴더를 대신 채워 줍니다. 아카이브가 이미 풀려 있는 폴더를 모듈에 직접 지정할 수도 있습니다.
  2. 입력을 지정합니다. CBCT 하나 또는 폴더 전체. AMASSS는 하위 폴더 안에 있는 스캔도 찾습니다.
  3. 목록에서 원하는 구조를 체크합니다.
  4. 출력 형식을 고릅니다. 개별 분할, 병합, 또는 둘 다. 장면에서 바로 표시할 수 있는 .vtk 메시를 원하면 표면 생성도 체크하십시오.
  5. 출력 폴더를 지정하고 "Predict" 버튼으로 실행합니다. 아직 없는 의존성이 설치되는 것은 모듈을 열 때가 아니라 바로 이때입니다.

소요 시간

AMASSS는 그래픽 카드 없이도 실행되지만, 현실적이라기보다는 이론상 그렇습니다. 스캔 배치에서는 (GPU 없이) 영상 리샘플링 단계 하나만으로도 네트워크 자체 비용의 대략 일곱 배가 듭니다. GPU가 있으면 구조와 스캔마다 적당한 계산량을 예상하면 되지만, 없으면 환자 여러 명의 배치는 금세 비현실적이 됩니다. 한 가지는 유리하게 작용합니다. 모델은 스캔마다가 아니라 구조마다 한 번만 로드되므로, 폴더 전체를 한 번에 처리하는 비용이 구조별로 CBCT 하나를 처리하는 비용보다 조금 더 들 뿐입니다.

막혔을 때

"Small FOV"는 계산에 아무 영향도 주지 않습니다 (레거시 모듈 전용)

"고해상도" 목록(치아, 치근관, 하악관 포함)으로 전환하는 체크박스는 화면에 표시되는 체크박스만 바꿉니다. 시야나 계산 해상도를 줄이지 않으므로, 더 빨리 실행되거나 더 정밀한 결과가 나오기를 기대하지 마십시오. VISOR 패널에는 이런 체크박스가 없습니다.

치근관이 기본으로 체크되어 있지만 모델이 없습니다 (레거시 모듈 전용)

"Root canal"은 구조 목록에서 기본으로 체크되어 있지만, 공개된 모델 번들에는 이에 대한 모델이 없습니다. 체크해도 오류도 분할도 나오지 않습니다. 조용히 실패하며, 해당 구조가 결과에서 그냥 빠집니다. VISOR에서는 "Root canal"이 아예 제공되지 않습니다.

DICOM 불러오기 (VISOR에서도 마찬가지)

인터페이스는 입력 유형으로 "DICOM Files"를 제공하지만, 계산이 실행되기 전에 DICOM 변환은 실제로 이루어지지 않습니다. DICOM 입력은 아무 결과도 내지 않습니다. 대신 .nii.gz 또는 .nrrd 파일을 사용하십시오. VISOR 패널에도 DICOM 입력 유형은 없으니 볼륨 파일을 지정하십시오.

두 모듈을 동시에 실행하지 마십시오 (레거시 모듈 전용)

AMASSS는 시작할 때마다 임시 작업 폴더를 무조건 비웁니다. 이 폴더는 AMASSS를 뒤에서 호출하는 AREG_CBCT와 VFACE가 함께 씁니다. 이 모듈들 중 둘을 같은 컴퓨터에서 동시에 실행하면 하나가 다른 하나의 작업 폴더를 실행 도중에 지울 수 있습니다. 하나의 계산이 끝난 뒤에 다른 것을 시작하십시오. VISOR에서는 실행마다 서버의 자체 작업 폴더를 쓰므로 이런 일이 일어날 수 없습니다.

그 이후

생성된 분할에는 자동 정리가 적용되지 않습니다. 구멍 메우기도, 가장 큰 연결 성분만 남기기도 없으므로, 얻는 것은 네트워크의 원본 출력입니다. 측정이나 정합에 쓰기 전에 확인하십시오. 표면 생성을 체크한 단일 파일 입력에서는 계산이 끝나면 .vtk 메시가 장면에 바로 로드됩니다.

인용 방법

아래 논문은 이 모듈의 UNETR 버전을 설명합니다. 현재 실행되는 것은 nnU-Net으로 전환한 버전이며, 이 전환은 어디에도 발표되지 않았습니다. 이 논문을 인용해 현재의 AMASSS를 설명하면 더 이상 존재하지 않는 구조를 설명하는 셈입니다.
