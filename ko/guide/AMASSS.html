AMASSS — CBCT에서 구조물 분할하기

AMASSS는 두개안면 CBCT의 해부학적 구조물 — 하악골, 상악골, 두개저, 상기도, 경추, 피부 — 을 자동으로 분할(segmentation)합니다. 각 구조물은 그 구조물 하나만을 위해 학습된 신경망이 예측합니다. 대비나 윈도잉을 손으로 조정할 필요가 없습니다. 모듈이 알아서 처리합니다.

영상
  • AMASSS - Automatic Multi-Anatomical Skull Structure Segmentation 4분 11초 · DCBIA Videos 채널
  • AMASSS RC Seg tutorial 5분 08초 · DCBIA Videos 채널

언제 쓰는가

CBCT에서 뼈, 기도, 피부의 분할이 필요할 때 사용합니다. 환자 한 명이든 여러 명을 일괄로 처리하든 상관없습니다. AMASSS는 다른 두 도구의 내부에서도 동작합니다. AREG_CBCT는 같은 환자의 CBCT 두 개를 정합할 때, VFACE는 비대칭 분석에 AMASSS를 씁니다. 이 둘 중 하나를 사용한다면, 이 모듈을 열지 않아도 AMASSS가 하는 일의 일부가 이미 이루어지고 있습니다.

분할할 수 있는 구조물

공개된 모델 묶음에 학습된 모델이 있는 구조물은 여섯 가지입니다.

각 구조물은 그 구조물 하나만 아는 신경망이 예측합니다. 하악골과 상악골을 분할하면 다중 구조물 모델 하나가 아니라 독립된 계산 두 번이 실행됩니다. 일부 설정 목록에는 다른 항목(치아, 근관, 하악관)도 보이지만 공개된 모델 묶음에는 학습된 모델이 없습니다. 체크해도 아무것도 분할되지 않습니다(자세한 내용은 아래 참고).

필요한 것, 얻는 것

준비할 것

  • CBCT 하나 또는 여러 CBCT가 든 폴더. 형식은 .nii, .nii.gz, .nrrd, .nrrd.gz
  • 학습된 모델(한 번만 내려받으면 됨)
  • 목록에서 체크한 원하는 구조물

결과물

  • 구조물마다 이진 마스크 하나, 또는 구조물마다 고유한 값을 갖는 통합 맵 하나
  • 요청하면 구조물별로 색이 입혀진 3D 표면(.vtk). 바로 표시할 수 있습니다
  • 원본 스캔은 건드리지 않습니다

사용 절차

  1. 모델을 내려받습니다. "Download latest models" 버튼은 브라우저에서 GitHub 릴리스 페이지를 엽니다. AREG_CBCT나 VFACE와 달리 AMASSS는 스스로 아무것도 내려받지 않습니다. 압축 파일을 직접 받아 설치해야 합니다.
  2. 입력을 지정합니다. CBCT 하나 또는 폴더 전체. AMASSS는 하위 폴더 안의 스캔까지 찾아냅니다.
  3. 목록에서 원하는 구조물을 체크합니다.
  4. 출력 형식을 고릅니다. 개별 분할, 통합, 또는 둘 다. 장면에 바로 표시할 .vtk 메시가 필요하면 표면 생성도 체크합니다.
  5. 출력 폴더를 지정하고 실행합니다. "Predict" 버튼을 누릅니다. 아직 설치되지 않은 의존성은 모듈을 열 때가 아니라 이때 설치됩니다.

소요 시간

AMASSS는 그래픽 카드 없이도 돌아가지만, 이는 실용적이라기보다 이론적인 이야기입니다. 여러 스캔을 처리할 때 (GPU 없이) 영상 리샘플링 단계 하나만으로 신경망 자체 비용의 약 일곱 배가 듭니다. GPU가 있으면 구조물당, 스캔당 계산 시간은 적당한 수준입니다. GPU가 없으면 여러 환자를 일괄 처리하는 것은 금세 비현실적이 됩니다. 유리한 점도 하나 있습니다. 모델은 스캔마다가 아니라 구조물마다 한 번만 로드되므로, 폴더 전체를 한 번에 처리해도 구조물 단위로 보면 CBCT 하나를 처리하는 것보다 크게 더 들지 않습니다.

문제가 생기면

"Small FOV"는 계산에 아무 영향이 없다

"고해상도" 목록(치아, 근관, 하악관 포함)으로 바꾸는 이 체크박스는 화면에 표시되는 체크박스만 바꿉니다. 계산의 촬영 범위(FOV)나 해상도를 줄이지 않으므로, 더 빨리 돌거나 더 세밀한 결과가 나오리라 기대하지 마십시오.

근관은 모델이 없는데도 기본으로 체크되어 있다

구조물 목록에서 "Root canal"(근관)이 기본으로 체크되어 있지만, 공개된 모델 묶음에는 해당 모델이 없습니다. 체크해도 오류도 분할 결과도 나오지 않습니다. 실패가 조용히 일어나고, 결과에서 그 구조물만 빠집니다.

DICOM 가져오기

인터페이스는 입력 유형으로 "DICOM Files"를 제공하지만, 계산 전에 실제로 DICOM 변환이 일어나지 않습니다. DICOM 입력으로는 아무것도 나오지 않습니다. 대신 .nii.gz나 .nrrd 파일을 쓰십시오.

두 모듈을 동시에 실행하지 마십시오

AMASSS는 시작할 때마다 무조건 임시 작업 폴더를 비웁니다. 이 폴더는 내부에서 AMASSS를 호출하는 AREG_CBCT, VFACE와 공유됩니다. 같은 컴퓨터에서 이 모듈 중 두 개를 동시에 실행하면 한쪽이 실행 도중 다른 쪽의 작업 폴더를 지울 수 있습니다. 한 계산이 끝난 뒤 다음 계산을 시작하십시오.

그다음

생성된 분할 결과에는 자동 정리가 적용되지 않습니다. 구멍 메우기도, 가장 큰 연결 성분만 남기기도 없습니다. 받는 것은 신경망의 원시 출력입니다. 계측이나 정합에 쓰기 전에 확인하십시오. 단일 파일 입력에 표면 생성을 체크했다면, 계산이 끝나는 대로 .vtk 메시가 장면에 바로 로드됩니다.

더 읽을거리

아래 논문은 이 모듈의 UNETR 버전을 설명합니다. 현재 실행되는 것은 nnU-Net으로 전환한 버전이며, 이 전환은 어디에도 발표되지 않았습니다. 이 논문을 인용해 현재의 AMASSS를 설명하면 더 이상 존재하지 않는 구조를 설명하는 셈입니다.

AMASSS 자체에 관한 문헌

  • Gillot et al., PLOS ONE 2022 — Automatic multi-anatomical skull structure segmentation of cone-beam computed tomography scans using 3D UNETR. 분할하는 구조물, 학습 데이터, 측정된 정확도를 다룹니다. 오픈 액세스입니다.

방법론 관련 문헌

  • Isensee et al., Nature Methods 2021 — nnU-Net: a self-configuring method for deep learning-based biomedical image segmentation. 현재 버전의 토대입니다. 데이터셋을 보고 구조와 설정을 스스로 고르는 방법입니다.
  • Hatamizadeh et al., WACV 2022 — UNETR: Transformers for 3D Medical Image Segmentation. PLOS ONE 논문의 구조, 즉 이 모듈의 초기 버전 구조입니다.

이 도구의 전체 참고문헌 — 찾아낸 것과 찾아봤지만 없었던 것 — 은 출처 페이지에 있습니다.
