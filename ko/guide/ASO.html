ASO — 스캔의 방향을 자동으로 정렬하기

ASO는 스캔을 회전시켜 기준 환자의 좌표계에 맞춥니다. 두 시점을 서로 비교하지 않으며, 아무것도 분할하지 않습니다. CBCT(볼륨)와 구강 스캔(표면)을 모두 다루며, 하나의 창 뒤에서 서로 다른 두 엔진이 동작합니다.

영상
  • Automated Standardized Orientation (ASOCBCT) - Tutorial 7분 09초 · DCBIA Videos 채널

언제 쓰는가

사실상 대부분의 정합 전에 씁니다. 정합은 두 입력이 처음부터 어느 정도 일관된 방향에 놓여 있다고 가정합니다. 그렇지 않으면 올바른 출발점이 없습니다. 예를 들어 AREG_IOS는 자체 행렬을 만들기 위해 ASO가 생성한 변환 파일을 직접 찾습니다. 스캔이 ASO로 방향 정렬된 적이 없다면 찾을 파일이 없습니다. 정합을 위해 스캔을 준비할 때, 종단 시계열을 중첩할 때, 또는 단순히 코호트 전체를 같은 좌표계로 가져오고 싶을 때 ASO를 실행하십시오.

모드 선택

두 가지 데이터 유형, 두 가지 작업 방식

먼저 어떤 종류의 파일인지 ASO에 알려 줍니다. 볼륨이면 CBCT, 구강 스캔이면 IOS입니다. 각각에 두 가지 모드가 있습니다. Fully-Automated(완전 자동)는 원본 스캔만 요구합니다. ASO가 필요한 랜드마크를 직접 배치하거나(CBCT의 경우 신경망 사용) 치아를 분할한(스캔의 경우) 뒤 방향을 정렬합니다. Semi-Automated(반자동)는 이 예측 단계를 건너뛰고 이미 식별해 둔 랜드마크나 치아로 바로 작업합니다. 더 빠르지만, 그 준비 작업이 이미 되어 있다고 가정합니다.

CBCT 반자동 모드: 단독으로 실행하지 마십시오

CBCT에서 반자동 모드는 자동 모드만 생성하는 변환 파일이 필요합니다. 이 파일은 자동 모드의 재중심화 단계에서 만들어집니다. ASO가 한 번도 처리하지 않은 스캔에 반자동 모드를 바로 실행하면 환자마다 차례로 실패합니다. 실제로 CBCT에서 반자동 모드는 두 번째 실행으로만 의미가 있습니다. 예를 들어 이미 자동 모드를 한 번 거친 시리즈의 방향 정렬을 다시 할 때입니다.

필요한 것, 얻는 것

준비할 것

  • CBCT: .nii.gz 형식의 볼륨(DICOM도 받지만 덜 안정적입니다. 가능하면 .nii.gz를 쓰십시오). 반자동 모드에서는 이미 배치해 둔 자신의 랜드마크와 위에서 설명한 변환 파일도 필요합니다
  • 구강 스캔(IOS): 일반적인 형식의 메시(처리 중에 .vtk로 변환됩니다). 반자동 모드에서는 악궁에서 체크할 기준 치아 3개 또는 4개가 필요하고, 자동 모드에서는 더 필요한 것이 없습니다. 치아 분할이 아직 되어 있지 않으면 자동으로 실행됩니다
  • 기준 환자("gold"): 한 번만 내려받는 데이터셋으로, 모든 방향 정렬의 목표가 됩니다

결과물

  • 방향이 재정렬된 스캔: CBCT는 입력 형식과 관계없이 항상 .nii.gz, 구강 스캔은 .vtk
  • 변환 파일: 후속 정합 모듈(대표적으로 AREG_IOS)이 자동으로 찾습니다
  • 함께 방향이 재정렬된 랜드마크 또는 기준 치아

사용 절차

  1. 기준 환자와 모델을 내려받습니다. 한 번만 하면 됩니다. 모든 스캔이 방향을 맞출 목표입니다.
  2. 데이터 유형과 모드를 선택합니다. CBCT 또는 IOS를 고른 뒤, 이미 가지고 있는 자료에 따라 Fully-Automated 또는 Semi-Automated를 고릅니다.
  3. 입력 폴더를 지정합니다. ASO는 폴더 전체를 한 번에 처리합니다.
  4. 반자동 모드의 구강 스캔이라면 기준 치아를 체크합니다(3개 또는 4개). 방향 정렬은 이 치아를 기준으로 맞춰집니다. 반자동 모드의 CBCT라면 랜드마크가 gold와 공유하는 점을 최소 4개 포함하는지 확인하십시오. 인터페이스는 3개 체크도 받아들이지만, 4개 미만이면 방향 정렬이 실패합니다.
  5. 상하악이 모두 있으면 "occlusion"을 체크합니다. 이 경우 한쪽 악궁이 방향 정렬을 결정하고, 같은 회전이 다른 쪽에도 적용되어 교합 관계가 그대로 유지됩니다.
  6. 출력 폴더를 지정한 뒤 실행합니다.

문제가 생기면

CBCT 랜드마크 파일이 사라졌습니다

반자동 모드에서 ASO는 먼저 입력 폴더에서 찾은 모든 랜드마크 파일을 하나의 파일로 병합한 뒤 원본을 삭제합니다. 작업을 실행하기 전에 .mrk.json 파일의 사본을 다른 곳에 보관하십시오. 특히 입력 폴더에 그 랜드마크의 유일한 사본이 있다면 반드시 그렇게 하십시오.

Occlusion: 파일 이름에 Upper / Lower를 분명히 표시하십시오

Occlusion 모드는 파일 이름으로 상악과 하악 악궁을 짝짓습니다 (Upper/_U_ 또는 Lower/_L_). 이 표시가 전혀 없는 파일은 오류 메시지 없이 조용히 하악 악궁으로 처리됩니다. 이 옵션을 켜기 전에 파일 이름을 확인하십시오.

이미 출력이 있는 폴더에 다시 실행하면 아무 일도 일어나지 않습니다

예상되는 이름의 출력 파일이 이미 있으면 ASO는 파일을 다시 쓰지 않으면서도 성공을 보고합니다. 설정을 고친 뒤에는 같은 폴더에 다시 실행하지 말고 빈 출력 폴더를 지정하십시오.

그다음

ASO로 방향 정렬한 스캔이 해부학적으로 완벽하다는 보장은 없습니다. 방향 정렬은 기하학적 추정이지 정답(ground truth)이 아닙니다. 정합에 넣기 전에 Slicer에서 결과를 열어 기준 환자와 눈으로 비교하십시오. 변환 파일을 생성하는 이유가 바로 이 후속 사용입니다. 다음 모듈들은 이 파일로 원본 스캔부터 정합 결과까지 이어지는 전체 행렬을 다시 구성합니다.

더 읽을거리

ASO 자체에 관한 문헌

  • Anchling et al., LNCS 14242, 2023 — Automated Orientation and Registration of Cone-Beam Computed Tomography Scans. ASO/AREG 계열의 논문입니다. 자동 방향 설정을 어떻게 얻는지, 수동 방향 설정과 얼마나 차이가 나는지 다룹니다. 무료 전문.

방법론 관련 문헌

  • Ruellas et al., AJODO 2016 — Common 3-dimensional coordinate system for assessment of directional changes. 자동 방향 설정이 재현하려는 좌표계입니다. “올바른 방향”이 무엇인지를 이 좌표계가 정의합니다.
  • Gillot et al., Orthod Craniofac Res 2023 — Automatic landmark identification in cone-beam computed tomography. ASO가 방향을 잡을 때 쓰는 랜드마크가 여기서 나옵니다.
