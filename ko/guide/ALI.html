ALI — 랜드마크 자동 배치

ALI는 스캔 위에 해부학적 랜드마크를 대신 찍어 줍니다. CBCT(볼륨)에서도 구강 스캔(표면)에서도 똑같이 잘 동작하며, 하나의 창 뒤에서 서로 다른 두 엔진을 사용합니다.

영상
  • ALICBCT 3분 49초 · DCBIA Videos 채널
  • ALIIOS 2분 52초 · DCBIA Videos 채널

언제 쓰는가

랜드마크가 필요한데 손으로 찍기에는 시간이 너무 걸릴 때 언제든 쓸 수 있습니다. 환자 한 명에 점 열두 개 정도는 감당할 만하지만, 마흔 명 규모의 연구라면 더 이상 그렇지 않습니다. ALI는 다른 여러 모듈에 랜드마크를 공급하기도 합니다. 자동 방향 정렬이나 정합을 실행하면, 따로 열지 않아도 ALI가 이미 뒤에서 돌아가고 있을 수 있습니다.

두 엔진, 하나의 창

모듈은 데이터에 따라 알맞은 엔진을 스스로 고릅니다. 볼륨에는 CBCT, 구강 스캔에는 IOS 엔진입니다. 사용자는 파일 종류와 원하는 점만 지정하면 됩니다.

필요한 것, 얻는 것

준비할 것

  • 스캔 폴더 하나 — CBCT는 .nii.gz, 구강 스캔은 .vtk
  • 원하는 점 그룹 (목록에서 체크)
  • 학습된 모델 (한 번만 다운로드)

나오는 것

  • 스캔별·그룹별 랜드마크 파일 하나, Slicer 형식 (.mrk.json)
  • 장면(scene)에 바로 열리며, 점은 마우스로 끌어 옮길 수 있습니다
  • 원본 스캔은 건드리지 않습니다

사용 절차

  1. 모델을 다운로드합니다. "Download latest models"(최신 모델 다운로드) 버튼이 학습된 가중치를 받아옵니다. 한 번만 하면 되지만 반드시 필요합니다. 가중치가 없으면 모듈은 예측할 근거가 없습니다.
  2. 데이터 종류를 고릅니다. CBCT 또는 구강 스캔. 이 선택으로 어떤 엔진을 쓸지 정해집니다.
  3. 입력 폴더를 지정합니다. ALI는 폴더 전체를 한 번에 처리하므로 환자별로 따로 실행할 필요가 없습니다.
  4. 원하는 점을 체크합니다. 점은 부위별로 묶여 있습니다. 실제로 필요한 것만 체크하십시오. 점 하나마다 계산 시간이 늘어납니다.
  5. 출력 폴더를 지정한 뒤 실행합니다. 진행 표시줄이 환자별 처리 상황을 보여 줍니다.

소요 시간

그래픽 카드가 있으면 환자당 점 하나에 약 15초, 없으면 최대 1분을 예상하십시오. 점 열 개, 환자 서른 명이면 이 차이는 무시할 수 없습니다. 대략 1시간 대 5시간입니다. 모듈은 GPU 없이도 잘 돌아가지만, 큰 연구라면 밤새 돌릴 계획을 세우십시오.

문제가 생기면

"아무것도 나오지 않거나, 점 위치가 이상합니다"

먼저 모델이 실제로 다운로드되었는지 확인하고, 그다음 체크한 데이터 종류가 파일과 맞는지 확인하십시오. CBCT를 구강 스캔으로 처리하면 쓸 만한 결과가 나오지 않습니다.

구강 스캔: 치아 식별이 먼저 필요합니다

구강 스캔에서 엔진은 치아별로 측정 위치를 잡습니다. 파일에 아직 치관(crown) 식별이 없으면 ALI가 도중에 이를 자동으로 실행합니다. 첫 시도에서는 시간이 더 걸린다고 예상하십시오.

DICOM 불러오기

대신 .nii.gz 파일을 사용하십시오. 모듈의 DICOM 경로는 자동 모드에서 동작하지 않습니다.

디스크 공간

임시 폴더는 처리 후 비워지지 않습니다. 긴 연구에서는 가끔 정리해 주십시오.

그다음

얻은 랜드마크는 출발점이지 정답(ground truth)이 아닙니다. 측정이나 정합에 쓰기 전에 Slicer에서 열어 확인하십시오. 다른 마크업과 마찬가지로 마우스로 끌어 옮길 수 있습니다.

더 읽을거리

ALI 자체에 관한 문헌

  • Gillot et al., Orthod Craniofac Res 2023 — Automatic landmark identification in cone-beam computed tomography. CBCT 경로의 기반 논문입니다. 에이전트가 볼륨 안을 이동해 랜드마크에 도달합니다. 측정 오차를 랜드마크별로 보고합니다.
  • Baquero et al., CLIP 2022 (LNCS 13746) — Automatic Landmark Identification on IntraOralScans. 메시 경로의 기반 논문입니다. 표면을 여러 시점에서 촬영하고, 각 픽셀이 랜드마크에 투표합니다.

방법론 관련 문헌

  • Alansary et al., Medical Image Analysis 2019 — Evaluating reinforcement learning agents for anatomical landmark detection. 이동하는 에이전트라는 아이디어의 출처와, 좌표를 직접 회귀하는 방식에 비해 치르는 비용을 다룹니다.
  • Boubolo et al., SPIE Medical Imaging 2021 — FlyBy CNN: a 3D surface segmentation framework. 메시 경로가 기반으로 하는 다중 시점 렌더링입니다.

이 도구의 전체 참고문헌 — 찾아낸 것과 찾아봤지만 없었던 것 — 은 출처 페이지에 있습니다.
