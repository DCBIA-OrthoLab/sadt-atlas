MedX: 보고서를 요약한 뒤 대시보드 만들기

이름과 달리 MedX는 영상을 전혀 보지 않습니다. 서면 임상 보고서(.pdf, .docx, .txt)를 읽고, 로컬 언어 모델이 각각을 구조화된 요약으로 바꾸게 한 다음, 그 요약들로 이루어진 코호트 전체를 그림 한 페이지로 모아 줍니다. 시작하기 전에 알아 둘 만한, 서로 구분되는 두 단계입니다.

레거시 모듈 페이지

이 페이지는 2026-09-17에 레거시 확장에서 제거되기 전의 모듈을 설명합니다. 현재 버전에는 더 이상 없습니다. VISOR 서버로는 사용할 수 있었던 적이 없습니다. VISOR의 MedX와 VISOR 사용하기를 참조하십시오.

언제 쓰는가

임상 검사, 방사선 검사, 상담 노트 같은 자유 형식 보고서 더미가 있고, 하나하나 손으로 읽지 않고 거기서 임상 지표(나이, 통증, 수면, 입 벌림 등)를 뽑아내고 싶을 때 사용합니다. 요약을 얻고 나면 MedX의 후반부가 코호트 전체를 한눈에 보게 해 줍니다. 연령대별 분포, 동반 질환, 평균 점수입니다.

서로 독립된 두 경로

MedX에는 탭 둘, 버튼 둘이 있으며 둘을 자동으로 이어 주는 것은 없습니다. Summarize는 문서를 읽어 환자마다 요약 파일 하나를 씁니다. Dashboard는 그 요약을 다시 읽어 그림 페이지를 만듭니다. 요약이 끝나면 탭을 바꿔 대시보드를 직접 실행하는 것은 사용자의 몫이며, 저절로 시작되지 않습니다.

필요한 것, 얻는 것

Summarize 경로

준비할 것

  • .pdf, .docx, .txt 보고서의 평평한 폴더(하위 폴더 없음)
  • 첫 번째 “_” 앞의 모든 것이 환자 ID인 파일 이름: 그 ID를 공유하는 여러 파일은 묶여서 함께 요약됩니다
  • 요약 모델, 한 번만 다운로드

나오는 것

  • 환자마다 자유 형식 텍스트로 된 <patient-id>_summary.txt 파일 하나
  • 원본 문서는 건드리지 않습니다

대시보드 경로

준비할 것

  • Summarize 경로가 만든 요약 폴더(파일 이름이 _summary.txt로 끝나야 함)

나오는 것

  • dashboard.png 이미지: 코호트 전체의 나이, 수면, 관절과 근육 통증, 입 벌림
  • 환자마다 한 행인 patient_data.csv 표

단계

보고서 요약하기

  1. 모델을 다운로드합니다. 한 번만 필요하며, 없으면 Summarize 경로에는 작업할 바탕이 없습니다.
  2. 보고서 폴더를 지정합니다. 첫 번째 “_” 앞에 환자 ID를 붙여 이름을 정해야 합니다.
  3. 출력 폴더를 지정한 뒤 실행합니다. 진행 표시줄이 환자가 처리되는 대로 따라갑니다.
  4. 의지하기 전에 얻은 요약을 끝까지 읽어 보십시오. 아래를 참조하십시오.

대시보드 만들기

  1. Dashboard 탭으로 전환합니다. 요약이 끝난 뒤에 저절로 일어나지 않습니다.
  2. 이전 단계의 요약 폴더를 입력으로 지정합니다.
  3. 출력 폴더를 지정한 뒤 실행합니다. 처음 실행하면 Slicer가 Python 패키지 몇 개(pandas, matplotlib)의 설치를 물을 수 있습니다. 수락하십시오.
  4. 대시보드 이미지를 장면의 뷰에서 바로 열고 싶으면 “Load in 3D Slicer”를 체크합니다.

결과 읽기

각 보고서의 요약은 생성 모델에서 나옵니다. 보장된 형식이 아니라 자유 형식 텍스트를 씁니다. 대시보드가 기대하는 key: value 형식은 모델이 익힌 습관이지 강제된 규칙이 아닙니다. 형식이 잘못된 줄은 그냥 버려지며, 대시보드에서 조용히 빠집니다. 모델은 출력의 일부를 샘플링하기도 하므로, 같은 문서에 요약을 다시 실행해도 똑같은 텍스트가 두 번 나오지 않습니다. 이 두 가지 이유로 MedX가 생성한 요약은 끝까지 읽어 보아야 할 출발점이지 검증된 보고서가 아닙니다. 임상 판단에 그대로 쓰지 마십시오.

문제가 생기면

모델 다운로드 버튼이 아무것도 하지 않음

다운로드 버튼을 누르면 예상한 폴더는 만들어지지만 그 안에 파일은 넣어지지 않습니다. 필드는 비어 있고 경고 메시지가 나타납니다. SlicerAutomatedDentalTools 저장소의 GitHub 릴리스 페이지(“MedX” 릴리스의 BART.zip 파일)에서 모델 압축 파일을 직접 받아 풀고, 그 폴더를 모듈에 지정하십시오.

대시보드 진행 표시줄이 움직이지 않음

Summarize 경로와 달리 Dashboard 진행 표시줄은 실행하는 내내 멈춰 있습니다. 멈췄다는 신호가 아닙니다. 그대로 두고 출력 폴더에 dashboard.png가 나타나기를 기다리십시오.

빈 입력 폴더가 모듈을 충돌시킴

쓸 만한 문서가 없는 폴더에서 어느 경로를 실행하든 깔끔한 메시지 대신 오류가 발생합니다. 실행하기 전에 고른 폴더에 실제로 파일이 있는지 확인하십시오.

두 번 실행하면 요약이 서로 다름

모델은 결정론적이지 않습니다. 똑같은 문서에 Summarize 경로를 다시 실행해도 이전 요약이 한 단어도 틀리지 않고 재현되지는 않습니다. 시간에 따른 결과를 비교해야 한다면 다시 생성하지 말고 이미 가진 _summary.txt 파일을 보관하십시오.
