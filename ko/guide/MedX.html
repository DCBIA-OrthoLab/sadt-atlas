MedX — 보고서를 요약하고 대시보드 만들기

이름과 달리 MedX는 영상을 전혀 보지 않습니다. 작성된 임상 보고서(.pdf, .docx, .txt)를 읽고, 로컬 언어 모델로 각 보고서를 구조화된 요약으로 바꾸며, 그다음 코호트 전체의 요약을 한 페이지의 그림으로 모을 수 있습니다. 서로 다른 두 단계이므로 시작하기 전에 알아 두시기 바랍니다.

언제 쓰는가

임상 검사, 방사선 검사, 상담 기록 같은 자유 텍스트 보고서가 잔뜩 있고, 하나하나 직접 읽지 않고 임상 지표(나이, 통증, 수면, 개구량 등)를 뽑아내고 싶을 때 사용합니다. 요약을 얻고 나면 MedX의 두 번째 부분으로 코호트 전체를 한눈에 볼 수 있습니다. 연령 분포, 동반 질환, 평균 점수 등입니다.

서로 독립된 두 경로

MedX에는 탭 두 개와 버튼 두 개가 있으며, 이들을 자동으로 이어 주는 것은 없습니다. Summarize(요약)는 문서를 읽어 환자마다 요약 파일 하나를 씁니다. Dashboard(대시보드)는 그 요약을 다시 읽어 그림 페이지를 만듭니다. 요약이 끝나면 직접 탭을 바꾸고 대시보드를 실행해야 합니다. 저절로 시작되지 않습니다.

필요한 것, 얻는 것

Summarize 경로

준비할 것

  • .pdf, .docx, 또는 .txt 보고서가 들어 있는 평면 폴더(하위 폴더 없음)
  • 첫 번째 "_" 앞부분이 모두 환자 ID인 파일 이름. 같은 ID를 가진 여러 파일은 묶여서 함께 요약됩니다
  • 한 번만 내려받으면 되는 요약 모델

결과물

  • 환자마다 자유 텍스트로 된 <patient-id>_summary.txt 파일 하나
  • 원본 문서는 건드리지 않습니다

Dashboard 경로

준비할 것

  • Summarize 경로가 만든 요약 폴더(파일 이름이 _summary.txt로 끝나야 합니다)

결과물

  • dashboard.png 이미지: 코호트 전체의 나이, 수면, 관절 및 근육 통증, 개구량
  • 환자마다 한 행인 patient_data.csv 표

사용 절차

보고서 요약

  1. 모델을 내려받습니다. 한 번만 하면 됩니다. 모델이 없으면 Summarize 경로는 작업할 수 없습니다.
  2. 보고서 폴더를 지정합니다. 파일 이름은 첫 번째 "_" 앞에 환자 ID가 와야 합니다.
  3. 출력 폴더를 지정한 뒤 실행합니다. 진행 표시줄이 처리되는 환자를 따라 움직입니다.
  4. 결과로 나온 요약을 꼼꼼히 읽은 뒤에 활용하십시오. 아래를 참조하십시오.

대시보드 만들기

  1. Dashboard 탭으로 바꿉니다. 요약이 끝난 뒤 자동으로 바뀌지 않습니다.
  2. 이전 단계의 요약 폴더를 입력으로 지정합니다.
  3. 출력 폴더를 지정한 뒤 실행합니다. 처음 실행할 때 Slicer가 Python 패키지 몇 개(pandas, matplotlib)를 설치하겠느냐고 물을 수 있습니다. 수락하십시오.
  4. "Load in 3D Slicer"를 체크하면 대시보드 이미지가 장면의 뷰에서 바로 열립니다.

결과 읽기

각 보고서의 요약은 생성 모델에서 나옵니다. 모델은 정해진 양식이 아니라 자유 텍스트를 씁니다. 대시보드가 기대하는 key: value 형식은 모델이 학습한 습관일 뿐 강제되는 규칙이 아닙니다. 형식이 맞지 않는 줄은 그냥 버려지고, 대시보드에서 아무 표시 없이 빠집니다. 또한 모델은 출력의 일부를 샘플링합니다. 같은 문서에 요약을 다시 실행해도 똑같은 텍스트가 두 번 나오지 않습니다. 이 두 가지 이유로, MedX가 생성한 요약은 검증된 보고서가 아니라 꼼꼼히 읽어야 할 출발점입니다. 임상 결정에 그대로 사용하지 마십시오.

문제가 생기면

모델 다운로드 버튼이 아무 일도 하지 않습니다

다운로드 버튼을 누르면 예상된 폴더는 만들어지지만 파일은 전혀 들어가지 않습니다. 필드는 비어 있고 경고 메시지가 나타납니다. SlicerAutomatedDentalTools 저장소의 GitHub 릴리스 페이지에서 모델 아카이브를 직접 받으십시오 ("MedX" 릴리스 아래의 BART.zip 파일). 압축을 푼 뒤 모듈에 그 폴더를 지정하십시오.

대시보드 진행 표시줄이 움직이지 않습니다

Summarize 경로와 달리 Dashboard 진행 표시줄은 실행 내내 멈춰 있습니다. 멈춘 것이 아닙니다. 그대로 두고 출력 폴더에 dashboard.png가 나타날 때까지 기다리십시오.

입력 폴더가 비어 있으면 모듈이 충돌합니다

사용할 수 있는 문서가 없는 폴더에서 어느 경로를 실행하든 깔끔한 메시지 대신 오류가 발생합니다. 실행하기 전에 고른 폴더에 실제로 파일이 있는지 확인하십시오.

두 번 실행하면 요약도 두 가지

모델은 결정론적이지 않습니다. 똑같은 문서에 Summarize 경로를 다시 실행해도 이전 요약이 한 글자도 다르지 않게 재현되지는 않습니다. 시간에 따라 결과를 비교해야 한다면, 다시 생성하지 말고 이미 가지고 있는 _summary.txt 파일을 보관하십시오.

더 읽을거리

MedX 자체에 관한 문헌

  • Gaydamour et al., CLIP 2025 (LNCS 16126) — AI-Driven Multimodal TMJ Patient Modeling: From Unstructured Notes to Precision Treatment. MedX가 텍스트 처리 단계를 맡는 파이프라인의 논문입니다. 자유 형식 보고서를 활용 가능한 데이터로 바꾸는 과정을 다룹니다.

방법론 관련 문헌

  • Lewis et al., ACL 2020 — BART: Denoising Sequence-to-Sequence Pre-training for Natural Language Generation, Translation, and Comprehension. MedX가 미세조정하는 원본 모델입니다. 요약기가 무엇을 할 수 있는지, 그리고 문장을 바꿔 쓰기 때문에 없는 내용을 지어낼 수 있다는 점을 설명합니다.
  • Bianchi et al., Seminars in Orthodontics 2021 — Decision Support Systems in Temporomandibular Joint Osteoarthritis. 임상적 맥락을 다룹니다. 추출된 데이터가 어떤 결정을 돕기 위한 것인지 설명합니다.

이 도구의 전체 참고문헌 — 찾아낸 것과 찾아봤지만 없었던 것 — 은 출처 페이지에 있습니다.

실제 동작 방식 → 아틀라스 페이지: 보고서를 조각(chunk)으로 나누는 방식, 미세 조정된 BART-large-CNN 모델, 대시보드의 집계기, 코드에서 발견된 그 밖의 함정.
