CLIC — CBCT에서 매복 견치 찾아 분류하기

CLIC는 CBCT를 슬라이스 단위로 훑어 매복 견치를 표시하고, 각 견치가 골에 대해 어디에 위치하는지 알려 줍니다: 협측(buccal), 양측 피질골(bicortical), 구개측(palatal). 원시 볼륨에서 바로 시작하므로 사전 분할이나 랜드마크 지정이 필요 없습니다.

진행 표시줄이 움직이지 않습니다. 정상입니다

도구가 실행되는 동안 진행 표시줄은 0에 머물고, 처리가 끝난 뒤에도 Slicer 장면에는 아무것도 나타나지 않습니다. 충돌이 아닙니다. 결과 파일은 어쨌든 출력 폴더에 저장됩니다. 직접 찾아서 불러와야 합니다. 저장 위치는 아래를 참고하십시오.

언제 쓰는가

매복 견치가 하나 이상 있는 CBCT가 있고, 견치를 하나하나 눈으로 살펴보지 않고도 각 견치가 피질골의 어느 쪽에 있는지 알고 싶을 때 사용합니다. CLIC는 다른 모듈에 의존하지 않습니다. AMASSS, ASO, ALI를 먼저 실행할 필요가 없습니다.

필요한 것, 얻는 것

준비할 것

  • .nii 또는 .nii.gz 형식의 CBCT 스캔 폴더
  • 학습된 모델(한 번만 내려받으면 됩니다)
  • 명시적으로 지정한 출력 폴더

결과물

  • 스캔마다 하위 폴더 하나, 그 안에 .nii.gz 레이블 맵
  • 가능한 복셀 값 세 가지: 협측, 양측 피질골, 구개측
  • 정합 없이 원본 스캔 위에 바로 겹쳐 볼 수 있음
허용되지만 실제로는 동작하지 않는 형식

파일 선택 창에는 .nrrd, .mha, .mhd도 표시됩니다. 사용하지 마십시오. 처리 단계는 .nii/.nii.gz만 읽을 수 있으며, 선택 창이 허용했더라도 다른 형식에서는 실패합니다.

Linux 전용

README에 뭐라고 쓰여 있든, 이 모듈은 Windows에서 동작하는 경로가 없습니다. Linux용 Slicer 설치본에서 실행하십시오.

사용 절차

  1. 모델을 내려받습니다. 전용 버튼이 학습된 신경망을 가져옵니다. 한 번만 하면 됩니다.
  2. 입력 폴더를 지정합니다. 하위 폴더가 든 폴더가 아니라 .nii.gz 파일이 바로 들어 있는 평평한 폴더여야 합니다.
  3. 출력 폴더를 고릅니다. 이 단계는 필수입니다. 출력 폴더가 없으면 처리가 시작되기도 전에 실패합니다.
  4. 실행합니다. 첫 실행에서는 계산 환경도 함께 설정하므로 이후 실행보다 오래 걸립니다.
  5. 화면에서 아무것도 움직이지 않더라도 끝날 때까지 기다립니다. 처리는 스캔 단위로 진행되며, 중간에 시각적 피드백이 없습니다.

결과는 어디에 있나

처리가 끝나면 지정한 출력 폴더를 여십시오. 처리된 스캔마다 하위 폴더가 하나 있고, 각 폴더 안에 .nii.gz 파일이 있습니다. 파일 이름에는 인터페이스에 표시된 접미사(기본값 seg)가 붙어 있습니다. 이 파일을 분할 볼륨으로 Slicer에 직접 불러오십시오. 이미 원본 스캔에 맞춰져 있으므로 정합이 필요 없습니다. 값 1, 2, 3은 각각 협측, 양측 피질골, 구개측에 해당합니다.

문제가 생기면

Cancel이 아무 효과가 없습니다

실행 중인 계산도, 그 아래의 프로세스도 멈추지 않습니다. 정말로 중단해야 한다면 Slicer를 닫으십시오.

첫 실행에는 인터넷 연결이 필요합니다

신경망을 구성할 때 학습된 모델을 적용하기 전에 범용 사전 학습 가중치를 먼저 내려받습니다. 첫 시도에서 연결이 없으면 처리가 실패합니다.

폴더에 모델 파일이 두 개 있음

모델 폴더에 모델 파일이 둘 이상 있으면, 알파벳순으로 가장 앞선 이름의 파일이 경고 없이 사용됩니다. 혼동을 피하려면 이 폴더에 .pth 파일을 하나만 두십시오.

더 읽을거리

이 모듈은 아직 논문이 없습니다. 유일한 공개 설명은 NA-MIC 프로젝트 페이지입니다.

CLIC 자체에 관한 문헌

  • NA-MIC Project Week 43, Montréal 2025 — Interpretable Deep Learning for the Detection and Classification of Impacted Canines and severity of root resorption. 프로젝트 보고서입니다. 목표, 데이터, 그리고 당시의 작업 진행 상황을 다룹니다.

방법론 관련 문헌

  • He et al., ICCV 2017 — Mask R-CNN. 이 모듈이 실행하는 구조입니다. 객체를 검출하는 동시에 그 마스크를 생성합니다.
  • Swaity et al., Scientific Reports 2023 — Deep learning driven segmentation of maxillary impacted canine on cone beam computed tomography images. 다른 연구팀이 같은 문제를 다룬 연구로, 독립된 증례군에서 측정한 오차를 제시합니다.
  • Pirayesh et al., BMC Oral Health 2024 — A hierarchical deep learning approach for diagnosing impacted canine-induced root resorption. 치근 흡수 측면을 다룹니다. 심각도를 어떻게 등급화하는지, 그리고 사람 관찰자와 비교하면 어떤지 보여 줍니다.
