Interpretable Deep Learning for the Detection and Classification of Impacted Canines and severity of root resorption

NA-MIC Project Week 43 프로젝트 페이지(몬트리올, 2025). CLIC를 기존 구성 요소로 삼아, 인접 치아의 치근 흡수(root resorption) 중증도를 분류하는 확장 기능을 시제품으로 만든다.

프로젝트 설명

CLIC 모듈은 Mask R-CNN 분할 모델로 CBCT 스캔에서 매복 견치의 위치를 찾고 분류한다.
이 프로젝트는 매복 견치에 인접한 치아의 치근 흡수 중증도를 자동으로 분류하는 지도 학습 모델을 개발해 CLIC를 확장한다.

목표

  1. 기존 CLIC 모듈로 매복 견치를 분할한다.
  2. 분석을 위해 인접 치아 볼륨을 추출한다.
  3. 임상의가 매긴 흡수 중증도 점수가 달린 인접 치아의 주석 데이터셋을 구축한다.
  4. 분할된 볼륨에서 치근 흡수 중증도를 예측하는 분류 모델을 학습한다.
  5. 분할 결과와 중증도 점수를 3D Slicer 안에서 통합하고 시각화한다.

접근 방법과 계획

  1. CBCT 데이터셋 전체에 CLIC를 실행해 매복 견치를 분리한다.
  2. CLIC 마스크를 조합해 인접 치아의 볼륨을 추출한다.
  3. 추출한 각 치아 볼륨에 중증도 레이블(경도, 중등도, 중증)을 주석으로 단다.
  4. 각 볼륨에서 기하학적·형태학적 특징 집합을 추출한다.
  5. 이 특징으로 분류기를 학습한다.
  6. 실시간 중증도 분류를 위해 CLIC를 확장하거나 새 Slicer 모듈을 만든다.
  7. 모델 성능(정확도, 재현율, 정밀도)을 검증하고 3D 시각화 워크플로에 통합한다.

진행 상황과 다음 단계

완료:

  • CLIC 모듈 검증 완료.
  • 인접 치아 추출을 위한 시제품 파이프라인 구축.

다음 단계:

  • 추출된 치아 볼륨에 대한 임상의 주석.
  • 특징 설계와 모델 학습.
  • Slicer에서 중증도 점수를 표시할 UI 설계.
  • 성능 평가와 최종 문서화.
