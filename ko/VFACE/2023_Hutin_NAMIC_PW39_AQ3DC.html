Automatic Quantification 3D Components (AQ3DC)

NA-MIC Project Week 39(몬트리올, 2023) 프로젝트 보고서. 자동 계측용 Slicer 확장 AQ3DC를 설명한다. VFACE는 거리와 각도를 계산할 때 AQ3DC의 로직(functionaq3dc.py)을 재사용한다.

프로젝트 설명

Automatic Quantification 3D Components(AQ3DC)는 Namic-project 37에서 개발되었으며, 현재 Slicer Q3DC 확장에 포함되어 있다.

AQ3DC의 목표는 정량적 영상 분석 특징을 추출하는 데 드는 사용자 시간을 줄여 주는, 사용하기 쉬운 자동화 도구를 제공하는 것이다. AQ3DC는 사용자가 선택한 계측 목록을 단일 증례 또는 연구 표본 전체에 대해, 하나 이상의 시점에서 자동으로 계산하는 Slicer 확장이다. 현재 구현은 점 사이의 거리(AP, RL, SI), 점과 선 사이 거리, 두 점의 중점, 각도(Pitch, Roll, Yaw) 같은 3D 성분의 자동 계산과 방향성 해석을 목표로 하며, 원하는 어떤 계산/정량 영상 분석으로도 확장할 수 있다. 사용자 인터페이스는 현재 두개안면의 치아, 골격, 연조직 구조의 정량화를 목표로 설계되어 있다.
