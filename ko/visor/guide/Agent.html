VISOR로 Agent 사용하기

VISOR 확장의 Agent 패널이 무엇이며 왜 VISOR 서버를 사용하지 않는지를 다룬다. 레거시 모듈은 별도의 페이지가 있다.

VISOR 레거시 페이지 아틀라스 (VISOR)

VISOR 확장에는 Agent 패널이 들어 있지만, 서버 도구가 아니라 같은 로컬 어시스턴트다. 여전히 사용자의 컴퓨터에 Ollama가 필요하고, 여전히 사용자의 컴퓨터에서 실행되며, VISOR 서버에는 아무것도 보내지 않는다(AutomatedDentalToolsRemote README.md:28-30, 커밋 19b95e8). 어시스턴트가 고른 도구를 서버에서 실행해 달라고 요청하지도 않는다.

레거시 가이드와 달라지는 점: 눈에 보이는 것은 없다. 패널은 레거시 패널의 사본(AgentRemote/AgentRemote.py)이며 그 한계도 그대로다. 확인 대화상자, 수리 시도, 작업이 실행되는 동안 멈추는 Slicer, 그리고 설정하지 않으면 찾지 못하는 스크립트 폴더(AGENT_CLI_TOOLS_DIR, Agent_CLIRemote/Agent_CLIRemote_utils/utils.py:154). 도구 목록에도 MedX가 더 이상 존재하지 않는데 MedX 항목 둘이 여전히 들어 있다(Agent_CLIRemote/manifest.yaml:491,509).

서버 쪽 Agent는 존재하지만, 이를 제공하는 패널은 없다

VISOR 서버는 요청에 대해 어떤 서버 도구를 실행할지 제안하고, 요청받았을 때만 실행하는 Agent 도구를 호스팅할 수 있다. 이를 위해서는 관리자가 따로 설정한 Ollama 서버가 필요하며, 클라이언트의 어떤 패널도 이를 호출하지 않는다(SADT-VISOR tools/Agent, 커밋 6ba2a78). 동작 방식은 Agent의 VISOR 아틀라스 페이지를 참고한다.
