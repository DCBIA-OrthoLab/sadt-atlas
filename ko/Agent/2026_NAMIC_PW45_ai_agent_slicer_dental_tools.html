AI-Agent for SlicerAutomatedDentalTools

프로젝트 보고서 — 45th NA-MIC Project Week, Boston, 2026. 분류: Infrastructure.

상태가 아니라 의도의 표명

이 보고서는 llama3:latest를 언급하지만 코드는 qwen3:8b를 하드코딩하며, 보고서의 "다음 단계"(LLM 통합, Slicer 내부 배포)는 저장소에서 이미 완료되어 있다. 현재 모듈에 대한 기술이 아니라, 특정 시점의 의도 표명으로 읽어야 한다. 실제 상태는 파이프라인 페이지를 참고할 것.

프로젝트 설명

문제: Slicer Automated Dental Tools 확장은 강력한 두개안면 분석 기능을 제공하지만, 복잡한 모듈 선택과 매개변수 조정 때문에 사용자의 학습 곡선이 가파르다.

해결책: 이 프로젝트는 워크플로를 간소화하기 위해 3D Slicer에 통합된 AI Agent와 챗봇 UI를 도입한다. 드래그 앤 드롭 입력과 자연어 프롬프트를 통해, 사용자는 복잡한 작업(예: CBCT/IOS의 분할, 랜드마크 지정, 방향 정렬)을 쉽게 요청할 수 있다. 에이전트는 이 요청을 자율적으로 동작으로 변환하여, 적절한 도구를 선택하고 매개변수를 자동으로 설정해 워크플로를 실행한다.

목표

  • 로컬 LLM 통합: Ollama를 사용해 경량 로컬 모델(현재 llama3:latest)을 실행한다.
  • Cross-Encoder 검색: 시스템은 Cross-Encoder를 활용한다. 사용자 질의와 도구 사용 사례 간의 의미적 관련성에 직접 점수를 매겨 가장 적합한 모듈 상위 3개를 검색한다.
  • 자율 실행: LLM이 검색된 맥락을 분석하고, 최적의 도구를 선택하고, 사용자 텍스트에서 필요한 매개변수를 추출한 뒤, Slicer 안에서 실행을 자동으로 시작한다.

접근 방법과 계획

  • Cross-Encoder 검색 모델과 로컬 LLM을 통합하는 핵심 백엔드 파이프라인을 구축한다.
  • 파이프라인을 3D Slicer 안에 배포하고 사용자용 챗봇 UI에 연결한다.
  • 자율 피드백 루프를 구현한다. 모델은 선택된 Slicer 도구가 성공적으로 실행되었는지 오류가 발생했는지 확인하고, 사용자에게 실시간 피드백을 제공한다.

진행 상황과 다음 단계

현재 진행 상황
백엔드 검색 시스템은 완전히 작동한다. Cross-Encoder 모델은 자연어 입력에서 적절한 Slicer 도구를 안정적으로 식별하고 선택한다.

다음 단계

  • LLM 통합: 로컬 LLM이 사용자 프롬프트를 해석하고, 필요한 매개변수를 자동으로 채우고, 도구 실행을 시작하는 로직을 구현한다.
  • Slicer 배포: 대화형 UI를 내장하고 전체 AI 파이프라인을 3D Slicer 환경 안에 직접 연결한다.
