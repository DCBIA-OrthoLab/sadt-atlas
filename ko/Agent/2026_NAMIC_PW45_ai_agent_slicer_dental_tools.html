AI-Agent for SlicerAutomatedDentalTools

프로젝트 보고서: 제45회 NA-MIC Project Week, 보스턴, 2026. 분류: Infrastructure.

상태가 아니라 의도의 선언

이 보고서는 llama3:latest를 내세우지만 코드에는 qwen3:8b가 하드코딩되어 있으며, "다음 단계"(LLM 통합, Slicer 안에서의 배포)는 저장소에서 이미 달성되었다. 모듈의 현재 모습이 아니라 날짜가 박힌 의도의 선언으로 읽어야 한다. 실제 상태는 파이프라인 페이지를 참조.

프로젝트 설명

문제: Slicer Automated Dental Tools 확장은 견고한 두개안면 분석을 제공하지만, 복잡한 모듈 선택과 매개변수 조정 때문에 사용자의 학습 곡선이 가파르다.

해결: 이 프로젝트는 3D Slicer에 통합된 AI Agent와 챗봇 UI를 도입하여 워크플로를 간소화한다. 드래그 앤 드롭 입력과 자연어 프롬프트를 허용함으로써, 사용자는 복잡한 작업(예: CBCT/IOS에서의 분할, 랜드마크 지정, 방향 정렬)을 쉽게 요청할 수 있다. 에이전트는 이 요청을 자율적으로 동작으로 옮겨 알맞은 도구를 고르고 매개변수를 자동으로 구성하여 워크플로를 실행한다.

목표

  • Local LLM Integration: Ollama를 써서 가벼운 로컬 모델(현재 llama3:latest)을 실행한다.
  • Cross-Encoder Retrieval: 시스템은 Cross-Encoder를 활용한다. 사용자 질의와 도구 사용 사례 사이의 의미적 관련도를 직접 점수화하여 가장 적합한 모듈 3개를 가져온다.
  • Autonomous Execution: LLM이 가져온 맥락을 분석하고 최적의 도구를 고른 뒤 사용자의 텍스트에서 필요한 매개변수를 추출하여 Slicer 안에서 실행을 자동으로 시작한다.

접근 방식과 계획

  • Cross-Encoder 검색 모델과 로컬 LLM을 통합한 핵심 백엔드 파이프라인을 구축한다.
  • 파이프라인을 3D Slicer 안에 배포하고 사용자 쪽 챗봇 UI에 연결한다.
  • 자율 피드백 루프를 구현한다. 모델이 선택된 Slicer 도구가 성공적으로 실행되었는지 오류를 만났는지 확인하고, 사용자에게 실시간 피드백을 제공한다.

진행 상황과 다음 단계

현재 진행 상황
백엔드 검색 시스템은 완전히 작동한다. Cross-Encoder 모델이 자연어 입력에서 알맞은 Slicer 도구를 안정적으로 식별하고 고른다.

다음 단계

  • LLM Integration: 로컬 LLM이 사용자의 프롬프트를 파싱하고, 필요한 매개변수를 자동으로 채우며, 도구 실행을 시작하는 로직을 구현한다.
  • Slicer Deployment: 대화형 UI를 내장하고 전체 AI 파이프라인을 3D Slicer 환경 안에서 직접 연결한다.
