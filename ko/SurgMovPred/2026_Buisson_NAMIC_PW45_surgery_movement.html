New 3D Slicer Module to predict surgery movement for maxillofacial surgery

NA-MIC Project Week 45 프로젝트 페이지(Boston, 2026): SurgMovPred에 대해 찾은 유일한 1차 보고로, 동료 심사를 거친 출판물이 아니라 진행 보고서다.

프로젝트 설명

가상 수술 계획 소프트웨어에서 수술 이동과 골 변위 벡터를 예측하는 일은 여전히 전문가의 노력이 많이 드는 작업으로, 외과의가 골절단술을 시뮬레이션하고 골 분절을 손으로 조정해야 한다. 이 단계를 자동화하기 위해 통계적 형상 모델과 딥러닝 회귀 신경망이 연구되었지만, 이들은 조밀한 변형장을 출력하며 임상적·수술적 결정을 이끄는 데 필요한 기하학적 해석 가능성이 부족하다.

이 프로젝트는 1,496명의 환자로 이루어진 견고한 데이터셋으로 학습한 머신러닝 스태킹(Stacking) 모델로 구동되는 전용 3D Slicer 모듈을 소개한다. 이 모듈은 사용자가 입력 파일 (예: 임상 매개변수를 담은 Excel/CSV)을 올리면 필요한 악안면 골 이동에 대한 정확한 데이터 기반 예측을 즉시 받을 수 있게 하여 임상 워크플로를 단순화한다.

목표

  • 사전 학습된 스태킹 ML 모델을 3D Slicer 환경에 탑재하여 다수 환자의 수술 데이터를 활용한다.
  • 입력 파일(Excel/CSV)을 매끄럽게 파싱하여 환자별 특징을 추출할 수 있게 한다.
  • 모델의 추론을 바탕으로 정밀한 골 이동 권고를 Slicer 인터페이스 안에서 직접 생성하고 표시한다.

접근 방법과 계획

  • 모델을 위해 환자 데이터를 정리하고 준비하는 입력 파일 파서(Excel/CSV)를 개발한다.
  • 사전 학습된 스태킹 ML 모델을 Python 기반 3D Slicer 스크립트 모듈에 통합한다.
  • 임상의가 환자 파일을 불러오고, 예측을 실행하고, 권고된 골 변위를 시각화할 수 있는 사용하기 쉬운 Slicer UI를 설계한다.

진행 상황과 다음 단계

핵심 스태킹 ML 모델은 1,496건의 환자 사례 데이터셋으로 학습과 검증을 성공적으로 마쳤다.

프로젝트 위크 동안 3D Slicer 안에 대화형 UI와 백엔드 파이프라인을 구축하여 파일 입력을 처리하고 모델의 예측 파이프라인을 실행할 것이다. 또한 Slicer 환경 안에서 출력의 정확도를 검증하고, 예측된 이동을 사용자에게 직관적으로 보여 주는 방법을 모색할 것이다.
