# AutoMatrix — sources

**Non publié, et rien ne le cite.** Aucun article, abstract, poster, thèse ou
rapport de Project Week ne porte sur AutoMatrix, et aucun ne le nomme non plus.
C'est un utilitaire d'application en lot écrit pour le laboratoire (Gaëlle Leroux,
UoM/DCBIA) : le contenu scientifique est entièrement dans les modules qui
**produisent** les matrices — AREG, ASO, MRI2CBCT, FlexReg — et se lit dans leurs
fiches respectives.

## Récupéré dans ce dossier

Rien. Il n'y a rien à récupérer.

## À consulter en ligne (pas librement téléchargeable)

Rien.

## Voisinage

Pour la convention de transformation, la référence à jour est une documentation,
pas un article. Aucune de ces ressources **ne décrit AutoMatrix**.

- [Transforms — Slicer user guide](https://slicer.readthedocs.io/en/latest/user_guide/modules/transforms.html)
  — sens fixed→moving, RAS de Slicer contre LPS d'ITK. C'est la seule chose qu'un
  repreneur doit avoir lue avant de toucher à ce module.
- [Coordinate systems — Slicer developer guide](https://slicer.readthedocs.io/en/latest/user_guide/coordinate_systems.html)
- [SimpleITK — Transforms and Resampling](https://simpleitk.readthedocs.io/en/master/link_ImageRegistrationMethod1_docs.html)
- [DCBIA-OrthoLab/SlicerAutomatedDentalTools](https://github.com/DCBIA-OrthoLab/SlicerAutomatedDentalTools)
  — le dépôt du module.
- [GaelleLeroux/DCBIA_Apply_matrix](https://github.com/GaelleLeroux/DCBIA_Apply_matrix)
  — dépôt d'origine, qui héberge encore la matrice miroir et les jeux de test
  cités par le README.
