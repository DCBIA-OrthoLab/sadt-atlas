SurgMovPred — sources

SurgMovPred bibliography: no article describes the tool, only a NA-MIC project page constitutes a primary source.

bibliography Tool page

No article describes SurgMovPred. But the page can be filled out on one point: there is a NA-MIC Project Week 45 project page (Boston, 2026) devoted exactly to this module — New 3D Slicer Module to predict surgery movement for maxillofacial surgery — retrieved in this folder. It names the authors (Alexandre Buisson, Paul Dumont, Juan Carlos Prieto, Lucia Cevidanes, Steve Pieper, UNC Chapel Hill; Mauro I. Dominguez), confirms the model (Machine Learning Stacking model, Excel/CSV input of clinical parameters, output = predicted bone displacements), gives the size of the training set — 1,496 patients — and the funding source, NIDCR R01DE024450. It is a project report, not a publication: no detailed method, no validation, no performance figures.

Nothing else. Searches on the module's name, on AUTH:"Buisson A" and AUTH:"Dumont P" in Europe PMC (the homonyms found are gastroenterologists), and on the IADR/AADOCR abstract archives: no published work on the prediction of surgical movements by this group. Paul Dumont's UNC/IADR 2026 poster is about the synthesis of TMD clinical notes (CNE/MedX module), not this module; Alexandre Buisson's is about VFACE.

Neighboring resources

These works do not describe the SurgMovPred code nor the 112 model packages shipped with it.

  • The exact problem, another team. Ma 2022 (IJMRCAS) predicts post-operative skeletal changes from pre-operative measurements, using tabular machine learning. This is the closest formulation to SurgMovPred's, but nothing links this work to the embedded weights.
  • Same goal, deep learning. Cheng 2023 (BMC Oral Health) predicts the surgical plan from a 3D cephalometric analysis; Kim 2025 (Nature Communications) goes further and synthesizes the post-operative lateral cephalogram via a graph network + diffusion. SurgMovPred, meanwhile, is a classic tabular model (145 features → 112 stacked regressors) that reads no image at all.
  • Opposite direction. Bao 2026 (arXiv) predicts the facial outcome from planned skeletal movements. SurgMovPred predicts the movements themselves from pre-operative measurements: the two are complementary, not interchangeable.
  • Same team, different target. Oliveira 2024 (OCR, with Cevidanes and Bianchi) predicts the need for orthognathic surgery from lateral cephalograms — a binary classification, not a regression of displacements.
