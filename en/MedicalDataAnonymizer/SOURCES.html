Neighboring work

None of these works describes this module.

  • Microsoft Presidio — the detection and anonymisation engine. No paper: the documentation is the authoritative reference, with the exact list of predefined recognizers and operators (replace, redact, hash, mask, encrypt — the latter, reversible with a key, is not offered by the module). microsoft.github.io/presidio · github.com/microsoft/presidio
  • spaCy — the English NER en_core_web_lg used by default. No paper either; cite the software record: Honnibal M., Montani I., Van Landeghem S., Boyd A. spaCy: Industrial-strength Natural Language Processing in Python. Zenodo, 2020, 10.5281/zenodo.1212303. Models: spacy.io/models/en.
  • Alrazihi 2025 (retrieved above): evaluates Presidio "bare," on neurosurgery reports, with a list of entities and a preprocessing that are not those of this module. The figures are therefore not directly transferable — but it is the only published order of magnitude available.
  • HIPAA Safe Harbor, 45 CFR §164.514(b)(2): the 18 categories of identifiers to remove. A reading grid for §7 of the page — file names, medical record identifiers, and image identifiers appear there, and this module does not handle them. hhs.gov — De-identification
  • DICOM anonymisers, to remove the ambiguity in the module's name: these are separate tools, in other extensions, unrelated to this code — SlicerBatchAnonymize (NA-MIC PW37 and PW38 reports) and the SlicerUltrasound DICOM Anonymizer (PW43).
