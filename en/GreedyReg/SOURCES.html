GreedyReg — sources

GreedyReg's bibliography: what is deposited in this folder, what is available to read online, and its neighborhood — work that describes the engine or the borrowed components, never this module itself.

2 documents retrieved ← Pipeline page

The module itself is not published anywhere. No paper, no abstract, no Project Week report is about GreedyReg. What is published is the engine it drives — greedy, the tool by Paul Yushkevich (PICSL, University of Pennsylvania, shipped with ITK-SNAP) — and the network it borrows for "Distant Registration" mode, ALI_CBCT. Both of these works are neighborhood material: they describe components, not this code, and the distinction matters here (see below: GreedyReg uses none of the methods the greedy paper highlights).

Neighborhood

None of the works below describe GreedyReg. They describe the engine or the borrowed components.

  • The greedy paper (Venet 2019, retrieved) describes what GreedyReg does not use. It presents a two-stage diffeomorphic registration: an initializing affine step, followed by estimating a deformation field. GreedyReg only ever calls the first one: greedy -a with -dof 6 or -dof 12, and greedy -rf/-rm for resampling. The deformation field, the "greedy" in the tool's name, the diffeomorphic NCC metric — none of that is ever executed. Citing this paper to describe GreedyReg would amount to describing a method the module does not employ.
  • ITK-SNAP (Yushkevich 2006, above): the module is a transposition into Slicer of ITK-SNAP's Registration panel — manual pre-alignment, then intensity-based affine with a mask. That is the only lineage the code can claim, and it is architectural, not methodological.
  • ALI_CBCT (Gillot 2023, retrieved): virtual agents navigating a multi-scale volumetric space, 1.54 ± 0.87 mm across 32 landmarks. Actually called by GreedyReg, but only in "Distant Registration" mode, to produce the landmarks the module then aligns via Kabsch. The paper says nothing about this use. Original repository: Maxlo24/ALI_CBCT.
  • Foundations of diffeomorphic registration cited by the greedy website, with no bearing on what GreedyReg actually executes: Joshi S., Davis B., Jomier M., Gerig G., Unbiased diffeomorphic atlas construction for computational anatomy, NeuroImage 23:S151-S160, 2004 (10.1016/j.neuroimage.2004.07.068); Avants B.B., Epstein C.L., Grossman M., Gee J.C., Symmetric diffeomorphic image registration with cross-correlation, Medical Image Analysis 12(1):26-41, 2008 (10.1016/j.media.2007.06.004); Avants B.B. et al., A reproducible evaluation of ANTs similarity metrics, NeuroImage 54(3):2033-2044, 2011 (10.1016/j.neuroimage.2010.09.025).
  • Documentation and code: greedy.readthedocs.io, sites.google.com/view/greedyreg (greedy's official website — beware the name clash: this is not this module), github.com/pyushkevich/greedy.
