AMASSS — sources

Bibliography for this tool: what is deposited in this folder, what is meant to be read online, and the neighborhood.

Bibliography Back to the page

AMASSS is published once, open access (PLOS ONE 2022), but the paper describes a dead version of the module: a UNETR MONAI model with a 128³ sliding window, whereas the code that runs today is an nnU-Net v2 (one binary network per structure, PlainConvUNet architecture coming from the weights' plans.json). The switch dates to commit 61bbb15 "ENH: AMASSS with nnunet" (2025-07-30); commit 109e1ed (2026-09-09) later replaced the subprocess call with nnU-Net's Python API.

Code / paper divergence

No publication describes the nnU-Net version. Citing the PLOS ONE paper to describe the module as it runs today amounts to describing an architecture that is no longer executed.

Neighborhood

These works do not describe AMASSS; they document its environment or its building blocks.

  • nnU-Net (Isensee et al. 2021, above): the foundation of the module's current version. It describes the self-configuring method, not the AMASSS model or its weights, whose training is documented nowhere.
  • UNETR (Hatamizadeh et al. 2022): the architecture of the PLOS ONE paper, so of the historical version of the CLI. Unrelated to what runs today.
  • Maxlo24/AMASSS_CBCT — the original repository cited by the paper; research code, not the Slicer module.
  • DCBIA-OrthoLab/SlicerAutomatedDentalTools — the module's repository; no DOI, no extension paper.

What was searched for and found nowhere

Europe PMC (AMASSS, AUTH:"Gillot M"), OpenAlex and web search for: SPIE Medical Imaging / MICCAI proceedings by Gillot, Prieto or Cevidanes on multi-structure skull segmentation; a publication describing AMASSS's nnU-Net switch or the training of its weights. Nothing. The other Gillot/Cevidanes results concern other tools (ALI, ASO/AREG, ShapeAXI).
