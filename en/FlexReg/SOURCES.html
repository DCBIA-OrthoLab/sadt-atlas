FlexReg — sources

FlexReg's bibliography: what is deposited in this folder, what remains to be read online, and the neighboring work that does not describe this code.

SOURCES.md FlexReg page

FlexReg is not described by any publication. Verification done: nothing in Crossref, OpenAlex, Europe PMC, arXiv, HAL, nor in the forty-three weeks of the NA-MIC project. The name appears publicly only in the README of SlicerAutomatedDentalTools. The MGL variant (mucogingival line) is not published either, and the figures quoted in its code (4.2 mm vs 1.2 mm on 364 predictions) are not sourced anywhere outside the comments.

The published foundation is that of AREG_IOS, of which FlexReg is the interactive counterpart: AReg IOS (ShapeMI 2023, LNCS 14350) describes the palatal ROI predicted by a network; FlexReg has it drawn by the operator instead. That variant is not in any paper. The AReg IOS paper is paywalled and has no author's version deposited anywhere.

Fly-by-CNN and DentalModelSeg describe the network that FlexReg calls upstream (CrownSegmentationcli / dentalmodelseg, §4.1 of the page) to set the Universal_ID array that the canonical orientation and the butterfly patch depend on. DentalModelSeg is the successor to Fly-by-CNN: same team, same multi-view principle, architecture moved from RUNET to UNET/MONAI.

The other three do not describe FlexReg. They justify the area the operator draws: they compare palatal regions usable as a stable superimposition reference and measure their reliability. The last two are from the same group (Cevidanes / Ruellas) and are cited by the AReg IOS paper.

Neighboring work

Related work that does not describe this code.

  • NA-MIC Project Week 39 (Montreal, 2023), « Automatic Registration Intra Oral Scan » (Hutin, Anchling, Cevidanes, Prieto et al.): project page. Describes AREG_IOS (network on the palate + ICP), never the hand-drawn patch.
  • NA-MIC Project Week 36 (2022), « ALIIOS — Automatic Landmarks Identification for Intra Oral Scans » (Baquero, Gillot, Cevidanes, Prieto): project page. This is the network that supplies the 13 mucogingival landmarks for FlexReg's MGL path. ALI_IOS has no publication of its own; this page is its only public description and cites no reference.
  • Prieto JC et al., ShapeAXI (Proc. SPIE Medical Imaging 2024, PMC11085013): the pip package that today bundles dentalmodelseg and its latest weights. Describes an explainable shape-analysis pipeline, not the segmentation model used here.
