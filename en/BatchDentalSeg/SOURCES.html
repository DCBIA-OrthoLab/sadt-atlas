BatchDentalSeg — sources

What is published, what is not, and what has been retrieved in this folder.

bibliography Back to the page

The module is partially published: of the four models it bundles, only DentalSegmentator has a paper, and on that model the code and the paper agree. PediatricDentalSegmentator, UniversalLabDentalSegmentator, and NasoMaxillaDentSegmentator are not attached to any publication — a search was done, and nothing turned up (details at the end of this file). The module itself (queuing, memory management, batch UI) is described nowhere.

The three variants: nothing published

No publication. What was searched, with no result:

  • Europe PMC, queries PediatricDentalSegmentator, UniversalLabDentalSegmentator, NasoMaxillaDentSegmentator, pediatric dental segmentator mixed dentition CBCT nnU-Net: 0 results every time.
  • OpenAlex on the same names: nothing, other than the EJWF conference abstract above.
  • Web search on each model name and on "Cevidanes / DCBIA + pediatric CBCT + primary teeth + 513": the only hits were the repository's own README and work from other, unrelated teams (e.g. Baraka et al., Multi-Architecture deep learning for CBCT segmentation of dental hard tissues and pulp in mixed dentition, J Dent 166:106344, 2026, 10.1016/j.jdent.2026.106344 — an unrelated team, 151 scans, other structures: this is not the model used by this module).

The "513 scans" figure remains unsourced — and contradicts itself

Pitfall

The repository's README announces 513 CBCT scans in mixed dentition for PediatricDentalSegmentator and for UniversalLabDentalSegmentator, and 135 for NasoMaxillaDentalSegmentator, with no reference and no test set. No source carries this figure. Worse, the dataset.json files published with the weights on the repository's GitHub releases contradict it:

ModelnumTraining announced by the bundleREADMELabels
PediatricDentalSegmentator3805136 (background + 5 structures, like DentalSegmentator)
UniversalLabDentalSegmentator46251356 (background + 55 teeth, Universal numbering)
NasoMaxillaDentSegmentator1351357 (the 5 from DentalSegmentator + separate maxilla)

Only NasoMaxilla is consistent. Figures reconfirmed directly from the releases:

curl -sL https://github.com/DCBIA-OrthoLab/SlicerAutomatedDentalTools/releases/download/<TAG>/dataset.json
# PEDIATRICDENTALSEG_MODEL  -> numTraining 380, 6 labels
# UNIVERSALLAB_MODEL        -> numTraining 462, 56 labels
# NASOMAXILLADENTSEG_MODEL  -> numTraining 135, 7 labels

The nuance to keep in mind: numTraining is the number of cases in the dataset as prepared for nnU-Net, which is not necessarily the number of scans collected. A corpus of 513 scans, some of which are discarded during preparation or set aside for a test set, could legitimately yield 380. So this is not necessarily an error — but it is a gap that nothing documents, across two models, with the same figure announced for two different corpora (380 and 462). The question to put to the authors is: does 513 refer to the corpus collected before preparation, and where is the split described?

Until that answer comes, do not copy "513" into a scientific text without having it confirmed.

Adjacent work

These works do not describe this module; they evaluate DentalSegmentator from the outside, or provide its foundation.

  • nnU-Net (Isensee et al. 2021): the foundation of all four models. Describes the self-configuring method, not these models or their weights.
  • Sinard et al. 2025 (file 2025_Sinard_DL_impacted_teeth_CBCT.xml): compares four segmentation methods, including DentalSegmentator, on CBCT scans of patients with multiple impacted teeth. An external evaluation of the original model; says nothing about the three variants nor about the batch module. The corresponding thesis is open access on DUMAS: dumas-05471245.
  • Gkantidis N., Ghamri M., Dot G. Accuracy and generalizability of an open-source deep learning model for facial bone segmentation on CT and CBCT scans: An ex vivo study. Journal of Dentistry 170:106663, 2026, 10.1016/j.jdent.2026.106663 — another external evaluation of DentalSegmentator (medRxiv preprint 10.64898/2025.12.28.25343101).
  • gaudot/SlicerDentalSegmentator — upstream extension and source of the DentalSegmentator weights.
  • KitwareMedical/SlicerNNUnet — the required NNUNet extension.
  • MIC-DKFZ/nnUNet.
