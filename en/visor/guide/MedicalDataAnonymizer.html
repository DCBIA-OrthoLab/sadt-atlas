MedicalDataAnonymizer: local only with VISOR

The VISOR extension ships this module as a local copy: it never runs on a VISOR server, and it does not protect what other panels upload. The legacy module has its own page.

VISOR: local copy only Legacy page Atlas (VISOR)

The VISOR extension includes a Medical Data Anonymizer panel. It is an older copy of the same module that runs on your computer, installs the same Presidio and spaCy packages in Slicer, and sends nothing to the server (AutomatedDentalToolsRemote README.md:28-30, commit 19b95e8). It works on text documents only, with the same limits as described in the legacy guide: English only, a mapping file written next to your documents, and a failure that can look like a success.

It does not de-identify what VISOR uploads

When you run a tool on a VISOR server, your image files are sent as they are on disk, with their names and DICOM headers (AutomatedDentalToolsRemote README.md:32-35). This module does not touch them, and the client has no de-identification step at the moment; the extension says so once for each remote server, with the message "Files are uploaded unmodified". Read De-identification in VISOR before sending patient data to a server.
