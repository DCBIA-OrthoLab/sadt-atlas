Agent with VISOR

What the Agent panel of the VISOR extension is, and why it does not use the VISOR server. The legacy module has its own page.

VISOR Legacy page Atlas (VISOR)

The VISOR extension includes an Agent panel, but it is the same local assistant, not a server tool. It still needs Ollama on your own computer, it still runs on your computer, and it sends nothing to the VISOR server (AutomatedDentalToolsRemote README.md:28-30, commit 19b95e8). It does not ask the server to run the tools it picks.

What is different from the legacy guide: nothing you see. The panel is a copy of the legacy one (AgentRemote/AgentRemote.py) and keeps its limits: the confirmation dialog, the repair attempts, Slicer frozen while a job runs, and the script folder it cannot find unless you configure it (AGENT_CLI_TOOLS_DIR, Agent_CLIRemote/Agent_CLIRemote_utils/utils.py:154). Its list of tools also still names two MedX entries, although MedX no longer exists (Agent_CLIRemote/manifest.yaml:491,509).

A server-side Agent exists, but no panel offers it

The VISOR server can host an Agent tool that proposes which server tool to run for a request, and runs it only if asked to. It needs an Ollama server that the administrator has set up separately, and no panel in the client calls it (SADT-VISOR tools/Agent, commit 6ba2a78). For how it works, see the VISOR Atlas page for Agent.
