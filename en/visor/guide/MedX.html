MedX: not available with VISOR

MedX cannot be run through a VISOR server, and it is no longer in the legacy extension either. The archived module has its own page.

VISOR: not ported, module removed Legacy page Atlas (VISOR)

MedX is not available with VISOR, and not in the current legacy extension either. It was dropped from SlicerAutomatedDentalTools on 2026-09-17 and kept on a separate archive branch. The VISOR server has no MedX tool and the VISOR client has no MedX module (commit 19b95e8).

The VISOR client describes its CNE module as the successor of MedX (AutomatedDentalToolsRemote README.md:208). That is a similar use, not the same result: CNE extracts structured findings from each clinical note with a different language model and does not build a dashboard. See CNE with VISOR.
