MedX: not ported to VISOR

MedX does not exist in VISOR, and it is no longer in the current legacy extension either. This page says exactly what is left of it in the VISOR repositories. The archived module is described on its legacy page.

CNE is the successor in use, not in method

The client README calls CNE the "Successor of the former MedX module" (AutomatedDentalToolsRemote README.md:208,601). That describes a use, not an equivalent algorithm. MedX ran a fine-tuned BART summarisation model to write one summary per patient, then built a figure panel from the cohort (legacy page, section 4 and section 5). The VISOR tool CNE runs a quantised GGUF language model through llama.cpp and writes, per note, the structured findings as JSON and the same findings as key : value text (SADT-VISOR tools/CNE/README.md:1-22); its README mentions no dashboard. The models and the outputs differ: see CNE on VISOR.

None of the findings on the legacy page can be checked against VISOR code, since there is none: they describe the archived code on archive/medx.
