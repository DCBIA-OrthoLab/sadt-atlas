AREG_CBCT — sources

Bibliography for AREG_CBCT: what is archived in this folder, what is still to be checked online, and the neighboring work that does not describe the code.

1 MICCAI proceedings chapter, paywalled at the publisher, free on PMC Pipeline page

AREG_CBCT is published only once, in a MICCAI workshop proceedings chapter (LNCS 14242, 2023) that it shares with ASO: the same text describes orientation (ASO) and registration (AREG). This chapter is paywalled at Springer, but the author manuscript is freely readable on PMC (PMC11104011); PMC, however, blocks automated PDF download, so it could not be archived here (see "To check online").

Trap

The code has diverged from the paper on three points: the paper describes a two-pass voxel-based registration (full image then masked image, 10,000 iterations) where the code now runs only one masked pass at 1500 iterations, it reports SimpleElastix where the code uses itk-elastix, and it gets its masks from AMASSS in its UNETR/MONAI version whereas AMASSS is today a nnU-Net v2. Reading the chapter as a description of the module as it currently runs would therefore be a mistake.

No publication describes the review pauses or batch navigation: internal development.

Neighboring work

These works do not describe AREG_CBCT; they underpin or surround the method.

  • Cevidanes 2005 (DMFR) and Nada 2011 (PLOS ONE): voxel-based superimposition on the anterior cranial base. Note: contrary to what the AREG_CBCT.md page might suggest, the 2011 PLOS ONE paper is not from the Cevidanes lab: it is signed by Nada, Maal, Kuijpers-Jagtman et al. (Radboud UMC, Nijmegen). It is an independent validation of the method, which makes it more useful, not less.
  • Ruellas 2016 (mandible) and Ruellas 2016 (maxilla): the two papers that established the reference regions used by regional registration — mandibular body/symphysis on one side, the palatal region on the other. These are what justify the masks passed to AREG, not the LNCS chapter.
  • Ponce-Garcia 2020 (Head & Face Medicine): measurement error and reproducibility of three 3D superimposition methods in growing patients. Does not test any tool from this repository; gives the order of magnitude of the error to compare AREG against.
  • Gillot 2022 (AMASSS): the segmenter that produces the reference-region masks consumed by AREG. Describes the UNETR version, not the one currently running (nnU-Net v2 today) — see ../AMASSS/SOURCES.md.
  • Barone 2024 (AJODO): Class III orthognathic surgery, voxel-based analysis; the paper explicitly states that "automated deep-learning-based tools were used for orientation, registration, bone segmentation and landmark identification" of the CBCTs in 3D Slicer. This is a clinical use of the ASO + AREG + AMASSS + ALI pipeline, not a validation of the tool.
  • NA-MIC Project Week pages, no DOI, useful for dating the milestones: PW39 2023 Montreal — Automated Registration of CBCT (Anchling, Hutin, Gurgel, Barone, Miranda, Roberts, Prieto, Cevidanes) and PW40 2024 Gran Canaria — maintenance (Claret, Leroux, Caleme, Mattos, Cevidanes, Prieto).
  • Code repositories, no DOI: lucanchling/AREG, DCBIA-OrthoLab/SlicerAutomatedDentalTools.

How the full text was retrieved

The chapter is paywalled at Springer, but the author manuscript deposited with the NIH is freely accessible. Two approaches fail on it and one works — noted here to avoid retracing the whole search:

RouteResult on this PMCID
pmc.ncbi.nlm.nih.gov/.../pdf/anti-bot HTML
BioC API pmcoa.cgi"No result can be found" — it only serves the open access subset
eutils.ncbi.nlm.nih.gov/entrez/eutils/efetch.fcgi?db=pmc&id=<number>full JATS, body included
 
curl -sL "https://eutils.ncbi.nlm.nih.gov/entrez/eutils/efetch.fcgi?db=pmc&id=11104011"

This is how the .xml and .txt files in this folder were obtained. The publisher-formatted PDF itself still has to be read on the Springer site or on PMC.
