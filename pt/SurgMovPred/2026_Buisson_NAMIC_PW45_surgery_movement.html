Descrição do projeto

Predizer os movimentos cirúrgicos e os vetores de deslocamento ósseo em softwares de planejamento cirúrgico virtual continua sendo uma tarefa que exige muito do especialista, pois obriga os cirurgiões a simular as osteotomias e a ajustar manualmente os segmentos ósseos. Embora modelos estatísticos de forma e redes de regressão por deep learning tenham sido explorados para automatizar essa fase, eles produzem campos de deformação densos que não têm a interpretabilidade geométrica necessária para orientar decisões clínicas ou cirúrgicas.

Este projeto apresenta um módulo dedicado do 3D Slicer, movido por um modelo de Machine Learning por Stacking, treinado em um conjunto de dados robusto de 1.496 pacientes. O módulo simplifica o fluxo de trabalho clínico ao permitir que o usuário envie um arquivo de entrada (p. ex., Excel/CSV com parâmetros clínicos) e receba instantaneamente predições precisas, baseadas em dados, dos movimentos ósseos maxilofaciais necessários.

Objetivo

  • Incorporar um modelo de ML por Stacking pré-treinado ao ambiente do 3D Slicer para aproveitar dados cirúrgicos de múltiplos pacientes.
  • Permitir a leitura fluida de arquivos de entrada (Excel/CSV) para extrair as features específicas de cada paciente.
  • Gerar e exibir recomendações precisas de movimento ósseo diretamente na interface do Slicer, com base na inferência do modelo.

Abordagem e plano

  • Desenvolver o parser de arquivos de entrada (Excel/CSV) para limpar e preparar os dados dos pacientes para o modelo.
  • Integrar o modelo de ML por Stacking pré-treinado a um módulo scripted do 3D Slicer em Python.
  • Projetar uma UI do Slicer amigável, que permita aos clínicos carregar os arquivos dos pacientes, disparar a predição e visualizar os deslocamentos ósseos recomendados.

Andamento e próximos passos

O modelo central de ML por Stacking foi treinado e validado com sucesso em um conjunto de dados de 1.496 casos de pacientes.

Durante a Project Week, construiremos uma UI interativa e um pipeline de backend no 3D Slicer para tratar os arquivos de entrada e executar o pipeline de predição do modelo. Também verificaremos a precisão das saídas no ambiente do Slicer e exploraremos formas intuitivas de exibir ao usuário os movimentos preditos.
