Descrição do projeto

O módulo CLIC usa um modelo de segmentação Mask R-CNN para localizar e classificar caninos impactados em exames de CBCT.
Este projeto estende o CLIC desenvolvendo um modelo supervisionado para classificar automaticamente a gravidade da reabsorção radicular nos dentes adjacentes aos caninos impactados.

Objetivo

  1. Segmentar os caninos impactados usando o módulo CLIC existente.
  2. Extrair os volumes dos dentes adjacentes para análise.
  3. Montar um conjunto de dados anotado de dentes adjacentes com escores de gravidade da reabsorção fornecidos por clínicos.
  4. Treinar um modelo de classificação para predizer a gravidade da reabsorção radicular a partir dos volumes segmentados.
  5. Integrar e visualizar a segmentação e os escores de gravidade no 3D Slicer.

Abordagem e plano

  1. Rodar o CLIC em todo o conjunto de dados de CBCT para isolar os caninos impactados.
  2. Combinar as máscaras do CLIC para extrair os volumes dos dentes adjacentes.
  3. Anotar cada volume dentário extraído com um rótulo de gravidade (leve, moderada, grave).
  4. Extrair conjuntos de características geométricas e morfológicas de cada volume.
  5. Treinar um classificador sobre essas características.
  6. Estender o CLIC ou criar um novo módulo do Slicer para classificação da gravidade em tempo real.
  7. Validar o desempenho do modelo (acurácia, sensibilidade, precisão) e integrá-lo ao fluxo de visualização 3D.

Progresso e próximos passos

Concluído:

  • Módulo CLIC validado.
  • Pipeline protótipo de extração dos dentes adjacentes estabelecido.

Próximos passos:

  • Anotação clínica dos volumes dentários extraídos.
  • Engenharia de características e treinamento do modelo.
  • Design da interface para exibição do escore de gravidade no Slicer.
  • Avaliação de desempenho e documentação final.
