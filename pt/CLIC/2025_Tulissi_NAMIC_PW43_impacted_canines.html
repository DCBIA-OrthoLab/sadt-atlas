Descrição do projeto

O módulo CLIC usa um modelo de segmentação Mask R-CNN para localizar e classificar caninos retidos em scans CBCT.
Este projeto estende o CLIC desenvolvendo um modelo supervisionado para classificar automaticamente a gravidade da reabsorção radicular nos dentes adjacentes aos caninos retidos.

Objetivo

  1. Segmentar os caninos retidos com o módulo CLIC existente.
  2. Extrair os volumes dos dentes adjacentes para análise.
  3. Montar um dataset anotado dos dentes adjacentes com escores de gravidade da reabsorção fornecidos por clínicos.
  4. Treinar um modelo de classificação para predizer a gravidade da reabsorção radicular a partir dos volumes segmentados.
  5. Integrar e visualizar a segmentação mais os escores de gravidade no 3D Slicer.

Abordagem e plano

  1. Executar o CLIC sobre o dataset de CBCT para isolar os caninos retidos.
  2. Combinar as máscaras do CLIC para extrair os volumes dos dentes adjacentes.
  3. Anotar cada volume de dente extraído com um rótulo de gravidade (leve, moderada, grave).
  4. Extrair conjuntos de características geométricas e morfológicas de cada volume.
  5. Treinar um classificador sobre essas características.
  6. Estender o CLIC ou criar um novo módulo Slicer para classificação de gravidade em tempo real.
  7. Validar o desempenho do modelo (acurácia, recall, precisão) e integrá-lo ao fluxo de visualização 3D.

Progresso e próximos passos

Completed:

  • Módulo CLIC validado.
  • Pipeline protótipo de extração de dentes adjacentes estabelecido.

Próximos passos:

  • Anotação clínica dos volumes de dentes extraídos.
  • Engenharia de características e treino do modelo.
  • Design da interface para exibir o escore de gravidade no Slicer.
  • Avaliação de desempenho e documentação final.
