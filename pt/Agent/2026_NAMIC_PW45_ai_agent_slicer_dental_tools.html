Descrição do projeto

Problema: A extensão Slicer Automated Dental Tools oferece uma análise craniofacial robusta, mas a escolha dos módulos e o ajuste dos parâmetros, complexos, criam uma curva de aprendizado íngreme para os usuários.

Solução: Este projeto introduz um agente de IA e uma interface de chatbot integrados ao 3D Slicer para simplificar o fluxo de trabalho. Com entradas por arrastar e soltar e prompts em linguagem natural, os usuários podem solicitar facilmente tarefas complexas (por exemplo, segmentação, marcação de landmarks ou orientação em CBCT/IOS). O agente traduz autonomamente essas solicitações em ações, escolhendo as ferramentas certas e configurando automaticamente os parâmetros para executar o fluxo de trabalho.

Objetivo

  • Integração de LLM local: usa o Ollama para executar um modelo local leve (atualmente llama3:latest).
  • Recuperação por Cross-Encoder: o sistema utiliza um Cross-Encoder. Ele pontua diretamente a relevância semântica entre a consulta do usuário e os casos de uso das ferramentas para recuperar os 3 módulos mais adequados.
  • Execução autônoma: o LLM analisa o contexto recuperado, escolhe a ferramenta ideal, extrai os parâmetros necessários do texto do usuário e dispara automaticamente a execução dentro do Slicer.

Abordagem e plano

  • Construir o pipeline central de backend integrando o modelo de recuperação Cross-Encoder e o LLM local.
  • Implantar o pipeline dentro do 3D Slicer e conectá-lo à interface de chatbot voltada ao usuário.
  • Implementar um ciclo de retorno autônomo. O modelo verificará se as ferramentas do Slicer selecionadas foram executadas com sucesso ou encontraram um erro, e dará um retorno em tempo real ao usuário.

Progresso e próximos passos

Progresso atual
O sistema de recuperação do backend está totalmente operacional. O modelo Cross-Encoder identifica e seleciona de forma confiável a ferramenta do Slicer adequada a partir de uma entrada em linguagem natural.

Próximos passos

  • Integração do LLM: implementar a lógica para que o LLM local analise o prompt do usuário, preencha automaticamente os parâmetros necessários e dispare a execução da ferramenta.
  • Implantação no Slicer: incorporar a interface interativa e conectar todo o pipeline de IA diretamente ao ambiente do 3D Slicer.
