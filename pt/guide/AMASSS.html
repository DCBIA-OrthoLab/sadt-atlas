AMASSS — segmentar estruturas a partir de uma CBCT

O AMASSS segmenta automaticamente as estruturas anatômicas de uma CBCT craniofacial — mandíbula, maxila, base do crânio, via aérea superior, vértebra cervical, pele —, cada uma predita por uma rede treinada apenas para essa estrutura. Você não ajusta contraste nem janelamento manualmente: o próprio módulo cuida disso.

Quando usar

Sempre que você precisar de segmentações de osso, via aérea ou pele a partir de uma CBCT — para um único paciente ou para um lote inteiro de uma vez. O AMASSS também roda nos bastidores de duas outras ferramentas: o AREG_CBCT o usa para registrar duas CBCTs do mesmo paciente, e o VFACE o usa para sua análise de assimetria. Se você usa uma delas, parte do trabalho do AMASSS já está sendo feita para você, sem abrir este módulo.

O que ele consegue segmentar

Seis estruturas têm um modelo treinado disponível no pacote publicado:

Cada estrutura é predita por uma rede que só conhece essa estrutura: segmentar a mandíbula e a maxila executa dois cálculos independentes, e não um único modelo multiestrutura. Algumas outras entradas aparecem em certas listas de configuração (dentes, canal radicular, canal mandibular), mas não têm modelo treinado no pacote publicado — marcá-las não segmenta nada (detalhes abaixo).

O que você precisa, o que você obtém

A fornecer

  • Uma CBCT, ou uma pasta com várias CBCTs, em .nii, .nii.gz, .nrrd ou .nrrd.gz
  • Os modelos treinados, a baixar uma única vez
  • As estruturas desejadas, marcadas na lista

O que sai

  • Uma máscara binária por estrutura, ou um único mapa mesclado em que cada estrutura tem seu próprio valor
  • Se solicitado, superfície(s) 3D (.vtk) coloridas por estrutura, prontas para exibição
  • Suas tomografias originais não são alteradas

Passo a passo

  1. Baixe os modelos. O botão "Download latest models" abre uma página de release do GitHub no seu navegador: ao contrário do AREG_CBCT ou do VFACE, o AMASSS não baixa nada sozinho — você mesmo busca e instala o arquivo compactado.
  2. Indique a entrada. Uma única CBCT ou uma pasta inteira; o AMASSS encontra as tomografias mesmo dentro de subpastas.
  3. Marque as estruturas desejadas na lista.
  4. Escolha o formato de saída. Segmentações separadas, mescladas ou ambas; marque também a geração de superfícies se quiser malhas .vtk prontas para exibir na cena.
  5. Defina uma pasta de saída e execute com o botão "Predict". É nesse momento que as dependências são instaladas, se ainda estiverem faltando — e não quando o módulo é aberto.

Quanto tempo leva

O AMASSS roda sem placa de vídeo, mas isso é mais teórico do que prático: em um lote de tomografias, só a etapa de reamostragem das imagens (sem GPU) custa cerca de sete vezes o custo da própria rede. Com GPU, espere um cálculo razoável por estrutura e por tomografia; sem ela, um lote de vários pacientes rapidamente se torna inviável. Um ponto joga a seu favor: os modelos são carregados uma vez por estrutura, não uma vez por tomografia — processar uma pasta inteira de uma vez custa pouco mais do que processar uma única CBCT, estrutura por estrutura.

Se algo der errado

"Small FOV" não muda nada no cálculo

A caixa que alterna para uma lista de "alta definição" (incluindo dentes, canal radicular e canal mandibular) só muda quais caixas aparecem na tela. Ela não reduz o campo de visão nem a resolução do cálculo — não espere que rode mais rápido nem que produza um resultado mais fino.

Canal radicular vem marcado por padrão, sem modelo

"Root canal" (canal radicular) vem marcado por padrão na lista de estruturas, mas o pacote de modelos publicado não tem modelo para ele. Marcá-lo não produz nem erro nem segmentação: a falha é silenciosa, a estrutura simplesmente não aparece no resultado.

Importação DICOM

A interface oferece "DICOM Files" como tipo de entrada, mas nenhuma conversão DICOM acontece de fato antes do cálculo: uma entrada DICOM não produz nada. Use arquivos .nii.gz ou .nrrd.

Não execute dois módulos ao mesmo tempo

O AMASSS apaga incondicionalmente sua pasta de trabalho temporária toda vez que inicia. Essa mesma pasta é compartilhada com o AREG_CBCT e o VFACE, que chamam o AMASSS nos bastidores. Se você executar dois desses módulos ao mesmo tempo na mesma máquina, um pode apagar a pasta de trabalho do outro no meio da execução — deixe um cálculo terminar antes de iniciar outro.

E depois

Nenhuma limpeza automática é aplicada às segmentações produzidas — nenhum preenchimento de buracos, nenhuma manutenção apenas do maior componente conexo: o que você obtém é a saída bruta da rede. Confira-a antes de usá-la para uma medição ou um registro. Para uma entrada de arquivo único com a geração de superfícies marcada, as malhas .vtk são carregadas diretamente na cena ao final do cálculo.

Para saber mais

O artigo abaixo descreve a versão UNETR do módulo. O que roda hoje é uma migração para nnU-Net que ninguém publicou: citá-lo para descrever o AMASSS como ele roda é descrever uma arquitetura que não existe mais.

Sobre o próprio AMASSS

  • Gillot et al., PLOS ONE 2022 — Automatic multi-anatomical skull structure segmentation of cone-beam computed tomography scans using 3D UNETR. As estruturas segmentadas, os dados de treinamento e a acurácia medida. Acesso aberto.

Em torno do método

  • Isensee et al., Nature Methods 2021 — nnU-Net: a self-configuring method for deep learning-based biomedical image segmentation. A base da versão atual: um método que escolhe sozinho a arquitetura e as configurações a partir do conjunto de dados.
  • Hatamizadeh et al., WACV 2022 — UNETR: Transformers for 3D Medical Image Segmentation. A arquitetura do artigo da PLOS ONE, ou seja, da versão histórica do módulo.
