Guia de uso

O que cada ferramenta faz, o que fornecer a ela, o que ela devolve — sem entrar no código. Para os mecanismos internos, passe para o Atlas.

Para quem é este guia

Para quem abre o SlicerAutomatedDentalTools no 3D Slicer e quer usá-lo: clínicos, pesquisadores, estudantes. Ele não pressupõe saber ler código nem saber o que é uma rede neural. Se o que interessa é o funcionamento interno — qual modelo é chamado, quando, sobre quais dados — é o Atlas que você procura: as duas seções cobrem os mesmos 20 módulos, cada uma por uma ponta.

Por que ele existe

A extensão reúne 20 módulos escritos por equipes diferentes, em épocas diferentes. A documentação deles se resume, conforme o caso, a algumas linhas de README, a uma página de projeto, ou a nada. Vários se comportam de forma diferente do que a publicação descreve: o artigo documenta uma versão que o código não executa mais.

Este guia foi escrito lendo o código de cada módulo, não a sua documentação. Ele diz, portanto, o que a ferramenta faz de fato quando você clica, inclusive quando isso incomoda: 79 avisos e 4 bugs são assinalados no ponto exato em que você corre o risco de tropeçar neles. Nada é corrigido aqui — o objetivo é que você não perca um dia com isso.

O que você encontra em cada página

Todas seguem o mesmo plano, para que você saiba onde olhar sem reler tudo:

  • Quando usar — a que problema a ferramenta responde, e os casos em que ela não serve para nada.
  • O que você precisa, o que você obtém — as entradas esperadas, o formato delas, e o que sai no fim.
  • Passo a passo — as etapas em ordem, campo por campo.
  • Se algo der errado — as falhas frequentes e o que as provoca.
  • Para saber mais — as publicações por trás da ferramenta, quando existem, e o link para a página do Atlas.

Por onde começar

Se você sabe qual ferramenta procura, escolha-a na lista abaixo. Senão, parta do que você precisa fazer:

  • Comparar dois exames do mesmo paciente ao longo do tempo → Registro
  • Isolar estruturas em um CBCT → Segmentação
  • Posicionar pontos de referência anatômicos, ou reorientar um exame → Landmarks e orientação
  • Medir, classificar ou prever a partir de uma forma → Análise
  • Recortar ou aplicar uma matriz, em lote → Utilitários
  • Extrair ou anonimizar texto clínico → Texto e linguagem
