Agent — deixe um assistente local escolher a ferramenta

O Agent é um assistente conversacional que roda inteiramente na sua máquina. Você descreve o que quer fazer, em linguagem natural, e ele propõe uma ferramenta da extensão já preenchida com seus parâmetros — ou simplesmente responde, dependendo do modo que você escolher.

  • AI Agent directly in 3D Slicer to help you learn dental and cranofacial imaging 30 s (apresentação) · canal DCBIA Videos
Leia isto antes de experimentar

No estado atual do repositório, o Agent não consegue localizar as ferramentas que quer executar. A menos que você o configure manualmente, qualquer tentativa de executar uma ferramenta falha. O modo que apenas responde, sem executar nada, não é afetado e funciona normalmente.

Quando usar

Use-o quando não quiser procurar qual módulo da extensão corresponde ao que você precisa, nem montar uma linha de comando à mão: você descreve a tarefa — "orient these CBCTs", "segment these scans" — e o Agent propõe uma ferramenta com os parâmetros que entendeu do seu pedido. Ele também funciona como simples consultor, no modo "Ask", para perguntas que não exigem executar nada.

O que instalar antes

O Agent depende de um servidor de modelo de linguagem rodando localmente na sua máquina, o Ollama. Se ele ainda não estiver presente, o módulo se oferece para baixá-lo e iniciá-lo para você. Em qualquer caso, espere que a primeira execução baixe vários gigabytes — só o modelo de linguagem tem pouco mais de 5 GB — antes de você poder fazer sua primeira pergunta.

Nada para instalar à mão do lado do Slicer

Os pacotes Python necessários se instalam automaticamente na primeira execução, dentro do próprio Python do Slicer.

O que você precisa, o que você obtém

O que fornecer

  • Um pedido escrito em linguagem natural, em inglês ou francês
  • O modo desejado: Agent (Automated) para realmente executar algo, Ask (Interactive) para apenas conversar
  • Se for o caso, as pastas envolvidas, soltas na área de arrastar e soltar

O que sai

  • No modo Agent: uma ferramenta escolhida, seus parâmetros, uma caixa de confirmação, depois a execução se você aprovar
  • No modo Ask: uma resposta em texto livre, nada é executado
  • Se a ferramenta falhar, até duas tentativas automáticas de reparo, cada uma com sua própria confirmação

Passo a passo

  1. Verifique se o Ollama está rodando. Se necessário, deixe o Agent instalá-lo e iniciá-lo para você, e aguarde o download do modelo na primeira execução.
  2. Escolha um modo. "Agent (Automated)" para realmente executar uma ferramenta, "Ask (Interactive)" para obter apenas uma resposta.
  3. Descreva o que você quer, em linguagem natural, como você explicaria a um colega.
  4. Solte as pastas pertinentes na área de arrastar e soltar se o seu pedido envolve dados específicos — o Agent tentará adivinhar qual é qual.
  5. Envie a mensagem. No modo Agent, uma ferramenta e seus parâmetros são propostos; no modo Ask, a resposta volta diretamente.

Como ler a caixa de confirmação

No modo Agent, nada é executado sem um "Yes" seu, em uma caixa de diálogo que lista cada parâmetro escolhido, na forma de pares key=value. É o único momento em que você pode detectar uma pasta adivinhada errado ou um valor que não corresponde ao que você queria, antes que a ferramenta realmente comece.

Leia cada linha, com atenção

Para a maioria das ferramentas, a correspondência entre o que o Agent acredita estar passando e o que a ferramenta realmente espera está errada. Uma execução pode, portanto, começar com valores errados sem que nenhum erro avise você antes — a caixa de confirmação é sua única verificação real.

Depois que você aprova, a interface do Slicer congela até que a ferramenta executada termine: isso é esperado, não há nada a fazer além de esperar.

Se algo der errado

"Nada é executado, ou o erro não faz sentido"

No estado atual do repositório, o Agent não encontra sozinho os scripts que quer executar: a menos que você mesmo indique onde eles estão, a execução falha antes mesmo de começar. A etapa de reparo automático que se segue não consegue corrigir isso — o problema não está nos parâmetros, está no caminho do script.

Uma execução que começa com valores errados

Veja acima: sempre confira a caixa de confirmação antes de aprovar. Uma incompatibilidade de parâmetros geralmente só aparece a olho, nessa caixa — não em uma mensagem de erro.

Tudo fica lento sem placa de vídeo

Se o servidor do modelo estiver rodando sem GPU, espere que cada resposta leve cerca de um minuto e meio. Uma conversa de ida e volta soma minutos, não segundos.

Em torno do método

  • Qwen Team, arXiv 2025 — Qwen3 Technical Report. O modelo que decide para qual ferramenta enviar você e extrai os parâmetros dela.
  • Reimers & Gurevych, EMNLP 2019 — Sentence-BERT: Sentence Embeddings using Siamese BERT-Networks. Como uma pergunta é comparada com a documentação indexada: a etapa que decide o que o agente tem diante de si antes de responder.
  • Nogueira & Cho, arXiv 2019 — Passage Re-ranking with BERT. A reclassificação aplicada em seguida aos trechos recuperados, que melhora nitidamente o que aparece no topo.
