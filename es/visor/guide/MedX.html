MedX: no disponible con VISOR

MedX no se puede ejecutar a través de un servidor VISOR, y tampoco está ya en la extensión legacy. El módulo archivado tiene su propia página.

VISOR: sin port, módulo retirado Página legacy Atlas (VISOR)

MedX no está disponible con VISOR, ni tampoco en la extensión legacy actual. Se retiró de SlicerAutomatedDentalTools el 2026-09-17 y se conservó en una rama de archivo aparte. El servidor VISOR no tiene ninguna herramienta MedX y el cliente VISOR no tiene ningún módulo MedX (commit 19b95e8).

El cliente VISOR describe su módulo CNE como el sucesor de MedX (AutomatedDentalToolsRemote README.md:208). Es un uso parecido, no el mismo resultado: CNE extrae hallazgos estructurados de cada nota clínica con un modelo de lenguaje distinto y no construye un dashboard. Véase CNE con VISOR.
