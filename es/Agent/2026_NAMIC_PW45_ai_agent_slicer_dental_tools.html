Descripción del proyecto

Problema: La extensión Slicer Automated Dental Tools ofrece un análisis craneofacial robusto, pero la complejidad de elegir módulos y ajustar parámetros crea una curva de aprendizaje empinada para los usuarios.

Solución: Este proyecto introduce un agente de IA y una interfaz de chatbot integrados en 3D Slicer para agilizar el flujo de trabajo. Al permitir entradas por arrastrar y soltar e instrucciones en lenguaje natural, los usuarios pueden solicitar con facilidad tareas complejas (p. ej., segmentación, landmarks u orientación sobre CBCT/IOS). El agente traduce estas peticiones en acciones de forma autónoma, eligiendo las herramientas adecuadas y configurando automáticamente los parámetros para ejecutar el flujo de trabajo.

Objetivo

  • Integración de un LLM local: Usa Ollama para ejecutar un modelo local ligero (actualmente llama3:latest).
  • Recuperación con Cross-Encoder: el sistema aprovecha un Cross-Encoder. Puntúa directamente la relevancia semántica entre la consulta del usuario y los casos de uso de las herramientas para recuperar los 3 módulos más adecuados.
  • Ejecución autónoma: El LLM analiza el contexto recuperado, selecciona la herramienta óptima, extrae los parámetros necesarios del texto del usuario y activa automáticamente la ejecución dentro de Slicer.

Enfoque y plan

  • Construir el pipeline de backend principal que integre el modelo de recuperación Cross-Encoder y el LLM local.
  • Desplegar el pipeline dentro de 3D Slicer y conectarlo a la interfaz de chatbot de cara al usuario.
  • Implementar un bucle de retroalimentación autónomo. El modelo comprobará si las herramientas de Slicer seleccionadas se ejecutaron con éxito o si encontraron un error, y dará información en tiempo real al usuario.

Progreso y próximos pasos

Progreso actual
El sistema de recuperación del backend es plenamente operativo. El modelo Cross-Encoder identifica y selecciona de forma fiable la herramienta de Slicer adecuada a partir de la entrada en lenguaje natural.

Próximos pasos

  • Integración del LLM: Implementar la lógica para que el LLM local analice la instrucción del usuario, rellene los parámetros necesarios y active la ejecución de la herramienta.
  • Despliegue en Slicer: Incorporar la interfaz interactiva y conectar todo el pipeline de IA directamente dentro del entorno de 3D Slicer.
