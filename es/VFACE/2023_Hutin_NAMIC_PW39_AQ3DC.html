Automatic Quantification 3D Components (AQ3DC)

Informe de proyecto de la NA-MIC Project Week 39 (Montreal, 2023) que describe AQ3DC, la extensión de Slicer para medición automática cuya lógica (functionaq3dc.py) reutiliza VFACE para calcular distancias y ángulos.

Descripción del proyecto

El Automatic Quantification 3D Components (AQ3DC) se desarrolló durante el Namic-project 37 y ya está disponible en la extensión Q3DC de Slicer.

El Automatic Quantification 3D Components (AQ3DC) pretende ofrecer una herramienta automatizada y fácil de usar que reduzca el tiempo del usuario para extraer características cuantitativas del análisis de imagen. AQ3DC es una extensión de Slicer que calcula automáticamente listas de mediciones seleccionadas por los usuarios para un solo caso o para toda una muestra de estudio, en uno o varios momentos. La implementación actual está orientada al cálculo automático de componentes 3D como distancias (AP, RL y SI) entre puntos, de puntos a una recta, el punto medio entre dos puntos o ángulos (Pitch, Roll y Yaw), la interpretación de la direccionalidad, que puede ampliarse a cualquier tipo de cálculo o análisis cuantitativo de imagen deseado. El diseño de la interfaz de usuario está orientado actualmente a la cuantificación de estructuras craneofaciales dentales, esqueléticas y de tejidos blandos.

Enlace del proyecto : https://github.com/DCBIA-OrthoLab/Q3DCExtension

Nota

Este informe de la NA-MIC Project Week es la descripción escrita original de AQ3DC. VFACE incluye una copia integrada del mismo (VFACE/VFACE_utils/functionaq3dc.py, 2484 líneas), de la cual solo se usa realmente la clase AQ3DCLogic; véase la sección «El núcleo algorítmico, las mediciones» de la página de VFACE.
