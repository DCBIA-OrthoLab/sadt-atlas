Descripción del proyecto

Predecir los movimientos quirúrgicos y los vectores de desplazamiento óseo en un software de planificación quirúrgica virtual sigue siendo una tarea que exige mucha pericia, pues obliga a los cirujanos a simular osteotomías y ajustar manualmente los segmentos óseos. Aunque se han explorado modelos estadísticos de forma y redes de regresión de aprendizaje profundo para automatizar esta fase, estos producen campos de deformación densos que carecen de la interpretabilidad geométrica necesaria para orientar decisiones clínicas o quirúrgicas.

Este proyecto presenta un módulo específico de 3D Slicer impulsado por un modelo de Machine Learning Stacking, entrenado con un conjunto de datos sólido de 1496 pacientes. El módulo simplifica el flujo de trabajo clínico al permitir cargar un archivo de entrada (por ejemplo, Excel/CSV con parámetros clínicos) y recibir al instante predicciones precisas, basadas en datos, de los movimientos óseos maxilofaciales necesarios.

Objetivo

  • Incorporar un modelo de ML Stacking preentrenado en el entorno de 3D Slicer para aprovechar datos quirúrgicos de múltiples pacientes.
  • Permitir el análisis fluido de archivos de entrada (Excel/CSV) para extraer características específicas de cada paciente.
  • Generar y mostrar recomendaciones precisas de movimiento óseo directamente en la interfaz de Slicer a partir de la inferencia del modelo.

Enfoque y plan

  • Desarrollar el analizador de archivos de entrada (Excel/CSV) para limpiar y preparar los datos de los pacientes para el modelo.
  • Integrar el modelo de ML Stacking preentrenado en un módulo con scripts de Python de 3D Slicer.
  • Diseñar una interfaz de Slicer fácil de usar que permita a los clínicos cargar archivos de pacientes, activar la predicción y visualizar los desplazamientos óseos recomendados.

Progreso y próximos pasos

El modelo central de ML Stacking se ha entrenado y validado con éxito con un conjunto de datos de 1496 casos de pacientes.

Durante la Project Week construiremos una interfaz interactiva y un pipeline de backend dentro de 3D Slicer para gestionar los archivos de entrada y ejecutar el pipeline de predicción del modelo. También verificaremos la exactitud de las salidas en el entorno de Slicer y exploraremos formas intuitivas de mostrar al usuario los movimientos predichos.
