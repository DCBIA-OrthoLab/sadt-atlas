Description du projet

Problème : l'extension Slicer Automated Dental Tools offre une analyse craniofaciale robuste, mais le choix complexe des modules et le réglage des paramètres imposent aux utilisateurs une courbe d'apprentissage raide.

Solution : ce projet introduit un agent IA et une interface de chatbot intégrés à 3D Slicer pour simplifier le flux de travail. Grâce au glisser-déposer des entrées et à des requêtes en langage naturel, les utilisateurs peuvent demander facilement des tâches complexes (par exemple segmentation, placement de landmarks ou orientation sur CBCT/IOS). L'agent traduit ces demandes en actions de façon autonome, choisit les bons outils et configure automatiquement les paramètres pour exécuter le flux de travail.

Objectif

  • Intégration d'un LLM local : utilise Ollama pour faire tourner un modèle local léger (actuellement llama3:latest).
  • Récupération par cross-encoder : le système s'appuie sur un cross-encoder. Il note directement la pertinence sémantique entre la requête de l'utilisateur et les cas d'usage des outils pour récupérer les 3 modules les plus appropriés.
  • Exécution autonome : le LLM analyse le contexte récupéré, choisit l'outil optimal, extrait les paramètres requis du texte de l'utilisateur et déclenche automatiquement l'exécution dans Slicer.

Approche et plan

  • Construire le pipeline backend central intégrant le modèle de récupération par cross-encoder et le LLM local.
  • Déployer le pipeline dans 3D Slicer et le relier à l'interface de chatbot destinée à l'utilisateur.
  • Mettre en place une boucle de rétroaction autonome. Le modèle vérifiera si les outils Slicer choisis se sont exécutés correctement ou ont rencontré une erreur, et donnera un retour en temps réel à l'utilisateur.

Avancement et prochaines étapes

Avancement actuel
Le système de récupération backend est entièrement opérationnel. Le modèle cross-encoder identifie et sélectionne de façon fiable l'outil Slicer approprié à partir d'une entrée en langage naturel.

Prochaines étapes

  • Intégration du LLM : mettre en œuvre la logique permettant au LLM local d'analyser la requête de l'utilisateur, de remplir automatiquement les paramètres requis et de déclencher l'exécution de l'outil.
  • Déploiement dans Slicer : intégrer l'interface interactive et relier tout le pipeline d'IA directement dans l'environnement 3D Slicer.
