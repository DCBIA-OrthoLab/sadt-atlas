CLIC : trouver et classer les canines incluses sur un CBCT

CLIC parcourt un CBCT coupe par coupe et signale les canines incluses, en indiquant pour chacune sa position par rapport à l'os : vestibulaire, bicorticale ou palatine. Vous partez du volume brut : aucune segmentation ni pose de landmarks préalable n'est nécessaire.

Deux façons de le lancer

Cette page décrit le module Slicer legacy. Pour l'utiliser via un serveur VISOR : voir CLIC avec VISOR et, pour le flux de travail général, Utiliser VISOR.

La barre de progression ne bouge pas : c'est normal

Pendant l'exécution de l'outil, la barre de progression reste à zéro et rien n'apparaît dans la scène Slicer, même une fois le traitement terminé. Ce n'est pas un plantage : le fichier de résultat est écrit sur le disque dans le dossier de sortie dans tous les cas. Il faut aller le chercher et le charger vous-même : voir plus bas où il atterrit.

Quand s'en servir

Quand vous avez un CBCT avec une ou plusieurs canines incluses et que vous voulez savoir, sans inspecter chacune à l'œil, de quel côté de l'os cortical elle se situe. CLIC ne dépend d'aucun autre module : inutile d'avoir lancé AMASSS, ASO ou ALI avant.

Ce qu'il vous faut, ce que vous obtenez

Vous fournissez

  • Un dossier de CBCT en .nii ou .nii.gz
  • Le modèle entraîné, téléchargé une seule fois
  • Un dossier de sortie, choisi explicitement

Vous obtenez

  • Un sous-dossier par scan, contenant une carte de labels .nii.gz
  • Trois valeurs de voxel possibles : vestibulaire, bicorticale, palatine
  • Directement superposable au scan source, sans recalage
Des formats acceptés qui ne fonctionnent pas vraiment

Le sélecteur de fichiers liste aussi .nrrd, .mha et .mhd. Ne les utilisez pas : le traitement ne sait lire que .nii/.nii.gz et échoue sur les autres formats, quoi que le sélecteur ait permis.

Linux uniquement

Le module n'a aucun chemin qui fonctionne sous Windows, quoi que dise le README. Lancez-le sur une installation Slicer sous Linux.

Étapes

  1. Téléchargez le modèle. Le bouton dédié récupère le réseau entraîné. À faire une seule fois.
  2. Désignez le dossier d'entrée. Un dossier plat de fichiers .nii.gz, pas un dossier de sous-dossiers.
  3. Choisissez un dossier de sortie. Cette étape est obligatoire : sans lui, le traitement échoue avant même de démarrer.
  4. Lancez. Le premier lancement installe aussi l'environnement de calcul, donc il est plus long que les suivants.
  5. Patientez, même si rien ne bouge à l'écran. Le traitement se fait scan par scan sans aucun retour visuel entre les deux.

Où trouver le résultat

Une fois le traitement terminé, ouvrez le dossier de sortie que vous avez choisi : il contient un sous-dossier par scan traité, et dans chacun un fichier .nii.gz portant le suffixe affiché dans l'interface (seg par défaut). Chargez vous-même ce fichier dans Slicer comme volume de segmentation : il est déjà aligné sur le scan source, aucun recalage n'est nécessaire. Les valeurs 1, 2 et 3 correspondent respectivement à vestibulaire, bicorticale et palatine.

Si ça coince

Annuler ne fait rien

Il n'arrête ni le calcul en cours ni le processus sous-jacent. Si vous devez vraiment arrêter, fermez Slicer.

Le premier lancement nécessite un accès à internet

La construction du réseau télécharge des poids préentraînés génériques avant que le modèle entraîné soit appliqué par-dessus. Sans connexion lors de la première tentative, le traitement échoue.

Deux fichiers de modèle dans le dossier

Avec plus d'un fichier de modèle dans le dossier des modèles, celui dont le nom arrive en premier par ordre alphabétique est utilisé, sans avertissement. Gardez un seul fichier .pth dans ce dossier pour éviter toute ambiguïté.

Comment citer

Le module n'a pas encore de publication : sa seule description publique est une page de projet NA-MIC.

Si vous avez utilisé CLIC dans un travail de recherche, citez :

Tulissi E, Cevidanes L, Prieto J, Bianchi J. Interpretable Deep Learning for the Detection and Classification of Impacted Canines and severity of root resorption. Project page, NA-MIC Project Week 43, Montreal, 2025.

projectweek.na-mic.org. Le rapport de projet : l'objectif, les données, et où en était le travail à ce moment-là.

Contexte, à ne pas citer pour l'outil

  • He et al., ICCV 2017: Mask R-CNN. L'architecture que le module exécute : détecter des objets et en produire le masque en même temps.
  • Swaity et al., Scientific Reports 2023: Deep learning driven segmentation of maxillary impacted canine on cone beam computed tomography images. Le même problème traité par une autre équipe, avec les écarts mesurés sur une série indépendante.
  • Pirayesh et al., BMC Oral Health 2024: A hierarchical deep learning approach for diagnosing impacted canine-induced root resorption. Côté résorption radiculaire : comment la sévérité est graduée, et ce que ça vaut face à un observateur humain.

La bibliographie complète de l'outil, ce qui a été trouvé, et ce qui a été cherché sans rien trouver, est dans ses sources.
