ASO : orienter vos scans automatiquement

ASO fait pivoter un scan pour l'amener dans le repère d'un patient de référence : il ne compare pas deux instants entre eux, et il ne segmente rien. Il traite aussi bien un CBCT (un volume) qu'une empreinte optique (une surface), avec deux moteurs différents derrière une seule fenêtre.

Page legacy

Cette page décrit le module Slicer legacy. Pour l'utiliser via un serveur VISOR : voir ASO avec VISOR et Utiliser VISOR.

Quand s'en servir

Avant la plupart des recalages, en réalité. Un recalage suppose que ses deux entrées partent déjà d'une orientation raisonnablement cohérente ; sans cela, il n'a pas de bon point de départ. AREG_IOS, par exemple, cherche directement le fichier de transformation que produit ASO pour construire sa propre matrice : si vos scans n'ont jamais été orientés par ASO, il n'y a rien à trouver. Lancez ASO chaque fois que vous préparez des scans pour un recalage, pour superposer une série longitudinale, ou simplement pour amener toute une cohorte dans le même repère.

Choisir un mode

Deux types de données, deux façons de travailler

Vous indiquez d'abord à ASO quel genre de fichiers vous avez : CBCT pour un volume, IOS pour une empreinte optique. Pour chacun, deux modes sont disponibles. Fully-Automated ne demande que vos scans bruts : ASO place lui-même les landmarks dont il a besoin (via un réseau, pour un CBCT) ou segmente les dents (pour un scan) avant d'orienter. Semi-Automated saute cette étape de prédiction et travaille directement sur des landmarks ou des dents que vous avez déjà identifiés : plus rapide, mais cela suppose que ce travail préparatoire existe déjà.

CBCT semi-automatique : ne le lancez pas seul

Sur un CBCT, le mode semi-automatique a besoin d'un fichier de transformation que seul le mode automatique produit, dans son étape de recentrage. Si vous lancez le mode semi directement sur des scans qu'ASO n'a jamais traités, il échoue patient après patient. En pratique, pour un CBCT, le semi-automatique n'a de sens qu'en seconde passe : par exemple pour refaire l'orientation d'une série déjà passée une fois par le mode automatique.

Ce qu'il vous faut, ce que vous obtenez

À fournir

  • CBCT : le volume en .nii.gz (le DICOM est accepté mais moins fiable, préférez .nii.gz quand vous le pouvez). En mode semi-automatique, aussi vos propres landmarks déjà placés et le fichier de transformation décrit plus haut
  • Empreinte optique (IOS) : le maillage, dans un format courant (converti en .vtk au passage). En mode semi-automatique, les 3 ou 4 dents de référence à cocher sur l'arcade ; en mode automatique, rien de plus : la segmentation des dents se lance toute seule si elle n'a pas déjà été faite
  • Le patient de référence (le "gold") : un jeu de données téléchargé une fois, que toute orientation vise

Ce qui sort

  • Le scan réorienté : toujours en .nii.gz pour un CBCT quel que soit le format d'entrée, en .vtk pour une empreinte optique
  • Un fichier de transformation, que les modules de recalage en aval (AREG_IOS en tête) recherchent automatiquement
  • Les landmarks ou les dents de référence, réorientés eux aussi

Marche à suivre

  1. Téléchargez le patient de référence et les modèles. Une étape unique : c'est la cible vers laquelle chacun de vos scans s'orientera.
  2. Choisissez le type de données et le mode. CBCT ou IOS, puis Fully-Automated ou Semi-Automated selon ce que vous avez déjà sous la main.
  3. Désignez le dossier d'entrée. ASO traite tout le dossier en une seule exécution.
  4. Pour une empreinte optique en mode semi-automatique, cochez les dents de référence (3 ou 4) sur lesquelles l'orientation s'alignera. Pour un CBCT en mode semi-automatique, assurez-vous que vos landmarks couvrent au moins 4 points communs avec le gold : l'interface en accepte 3 cochés, mais l'orientation échoue en dessous de 4.
  5. Cochez "occlusion" si vous avez les deux arcades. Une arcade pilote alors l'orientation, et la même rotation est appliquée à l'autre pour garder intacte la relation d'occlusion.
  6. Indiquez un dossier de sortie, puis lancez.

Si quelque chose se passe mal

Vos fichiers de landmarks CBCT ont disparu

En mode semi-automatique, ASO commence par fusionner tous les fichiers de landmarks qu'il trouve dans votre dossier d'entrée en un seul fichier, puis supprime les originaux. Gardez une copie de vos fichiers .mrk.json ailleurs avant de lancer un traitement, surtout si le dossier d'entrée est aussi l'endroit où vous gardez votre seule copie de ces landmarks.

Occlusion : nommez vos fichiers Upper / Lower sans ambiguïté

Le mode occlusion apparie les arcades supérieure et inférieure par nom de fichier (Upper/_U_ ou Lower/_L_). Un fichier dont le nom ne porte aucun de ces marqueurs est traité en silence comme une arcade inférieure : sans message d'erreur. Vérifiez vos noms de fichiers avant d'activer cette option.

Relancer sur un dossier qui contient déjà une sortie ne fait rien

Si un fichier de sortie existe déjà sous le nom attendu, ASO ne le réécrit pas et annonce quand même un succès. Après avoir corrigé un réglage, désignez un dossier de sortie vide plutôt que de relancer sur le même.

Et après

Un scan orienté par ASO n'est pas garanti d'être anatomiquement parfait : l'orientation est une estimation géométrique, pas une vérité de terrain. Ouvrez le résultat dans Slicer et comparez-le visuellement au patient de référence avant de l'injecter dans un recalage. C'est précisément pour cet usage en aval que le fichier de transformation est produit : les modules suivants s'en servent pour reconstruire la matrice complète, du scan brut jusqu'au résultat recalé.

Comment citer

Si vous avez utilisé ASO dans un travail de recherche, citez :

Anchling L, Hutin N, Huang Y, Barone S, Roberts S, Miranda F, Gurgel M, Al Turkestani N, Tinawi S, Bianchi J, Yatabe M, Ruellas A, Prieto JC, Cevidanes L. Automated Orientation and Registration of Cone-Beam Computed Tomography Scans. In: Clinical Image-Based Procedures (CLIP 2023), held with MICCAI 2023, Lecture Notes in Computer Science vol. 14242, Springer Cham, 2023, p. 43-58.

doi:10.1007/978-3-031-45249-9_5. Le papier de la famille ASO/AREG : comment l'orientation automatique est obtenue, et de combien elle s'écarte d'une orientation manuelle. texte intégral libre.

Contexte, à ne pas citer pour l'outil

  • Ruellas et al., AJODO 2016: Common 3-dimensional coordinate system for assessment of directional changes. Le système de coordonnées que l'orientation automatique cherche à reproduire. C'est lui qui définit ce que « bien orienté » veut dire.
  • Gillot et al., Orthod Craniofac Res 2023: Automatic landmark identification in cone-beam computed tomography. Les landmarks sur lesquels ASO s'appuie pour s'orienter viennent de là.

La bibliographie complète de l'outil, ce qui a été trouvé, et ce qui a été cherché sans rien trouver, est dans ses sources.
