MedX : indisponible avec VISOR

MedX ne peut pas être lancé via un serveur VISOR, et il n'est plus non plus dans l'extension legacy. Le module archivé a sa propre page.

VISOR : non porté, module retiré Page legacy Atlas (VISOR)

MedX n'est pas disponible avec VISOR, ni dans l'extension legacy actuelle. Il a été retiré de SlicerAutomatedDentalTools le 2026-09-17 et conservé sur une branche d'archive séparée. Le serveur VISOR n'a pas d'outil MedX et le client VISOR n'a pas de module MedX (commit 19b95e8).

Le client VISOR décrit son module CNE comme le successeur de MedX (AutomatedDentalToolsRemote README.md:208). C'est un usage voisin, pas le même résultat : CNE extrait des constats structurés de chaque note clinique avec un autre modèle de langage et ne construit pas de tableau de bord. Voir CNE avec VISOR.
