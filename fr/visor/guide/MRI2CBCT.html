MRI2CBCT : indisponible avec VISOR

MRI2CBCT ne peut pas être lancé via un serveur VISOR aujourd'hui. Cette page dit ce que cela signifie pour vous. Le module legacy a sa propre page.

VISOR : non porté Page legacy Atlas (VISOR)

MRI2CBCT n'est pas disponible avec VISOR. Le serveur n'a pas d'outil MRI2CBCT, et le client VISOR ne livre pas le module : sa description dit qu'il est « temporarily not shipped until it is ported to the server » (AutomatedDentalToolsRemote CMakeLists.txt:10,31-32, commit 19b95e8). La version actuelle, la réécriture à un seul bouton décrite dans le guide legacy, n'est portée nulle part. L'extension VISOR n'a aucun panneau MRI2CBCT.

Pour recaler une IRM sur un CBCT, utilisez l'extension legacy sur votre propre ordinateur. Vos fichiers restent alors sur votre machine. Voir Quand garder les modules legacy.
