MedX : non porté sur VISOR

MedX n'existe pas dans VISOR, et il n'est plus non plus dans l'extension legacy actuelle. Cette page dit exactement ce qu'il en reste dans les dépôts VISOR. Le module archivé est décrit sur sa page legacy.

VISOR : non porté, module supprimé Page legacy Guide (VISOR)

CNE est le successeur en usage, non en méthode

Le README du client appelle CNE le « Successor of the former MedX module » (AutomatedDentalToolsRemote README.md:208,601). Cela décrit un usage, non un algorithme équivalent. MedX faisait tourner un modèle de résumé BART affiné pour écrire un résumé par patient, puis construisait un panneau de figures à partir de la cohorte (page legacy, section 4 et section 5). L'outil VISOR CNE fait tourner un modèle de langage GGUF quantifié via llama.cpp et écrit, par note, les constats structurés en JSON et les mêmes constats sous forme de texte key : value (SADT-VISOR tools/CNE/README.md:1-22) ; son README ne mentionne aucun tableau de bord. Les modèles et les sorties diffèrent : voir CNE sur VISOR.

Aucun des constats de la page legacy ne peut être vérifié contre du code VISOR, puisqu'il n'y en a pas : ils décrivent le code archivé sur archive/medx.
