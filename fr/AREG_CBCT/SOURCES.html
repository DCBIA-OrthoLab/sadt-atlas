AREG_CBCT : sources

Bibliographie d'AREG_CBCT : ce qui est archivé dans ce dossier, ce qui reste à vérifier en ligne, et les travaux voisins qui ne décrivent pas le code.

1 chapitre d'actes MICCAI, payant chez l'éditeur, libre sur PMC Page du pipeline

AREG_CBCT n'est publié qu'une seule fois, dans un chapitre d'actes d'atelier MICCAI (LNCS 14242, 2023) qu'il partage avec ASO : le même texte décrit l'orientation (ASO) et le recalage (AREG). Ce chapitre est payant chez Springer, mais le manuscrit auteur est lisible librement sur PMC (PMC11104011) ; PMC bloque toutefois le téléchargement automatisé des PDF, si bien qu'il n'a pas pu être archivé ici (voir « À vérifier en ligne »).

Piège

Le code a divergé de l'article sur trois points : l'article décrit un recalage voxel à deux passes (image entière puis image masquée, 10 000 itérations) là où le code n'exécute plus qu'une seule passe masquée à 1500 itérations, il rapporte SimpleElastix là où le code utilise itk-elastix, et il obtient ses masques d'AMASSS dans sa version UNETR/MONAI alors qu'AMASSS est aujourd'hui un nnU-Net v2. Lire le chapitre comme une description du module tel qu'il tourne actuellement serait donc une erreur.

Aucune publication ne décrit les pauses de revue ni la navigation dans le lot : développement interne.

Travaux voisins

Ces travaux ne décrivent pas AREG_CBCT ; ils sous-tendent ou entourent la méthode.

  • Cevidanes 2005 (DMFR) et Nada 2011 (PLOS ONE) : superposition voxel à voxel sur la base antérieure du crâne. Note : contrairement à ce que la page AREG_CBCT.md pourrait laisser croire, l'article PLOS ONE de 2011 n'est pas du laboratoire Cevidanes : il est signé Nada, Maal, Kuijpers-Jagtman et al. (Radboud UMC, Nimègue). C'est une validation indépendante de la méthode, ce qui la rend plus utile, pas moins.
  • Ruellas 2016 (mandibule) et Ruellas 2016 (maxillaire) : les deux articles qui ont établi les régions de référence utilisées par le recalage régional, corps et symphyse mandibulaires d'un côté, région palatine de l'autre. Ce sont eux qui justifient les masques passés à AREG, pas le chapitre LNCS.
  • Ponce-Garcia 2020 (Head & Face Medicine) : erreur de mesure et reproductibilité de trois méthodes de superposition 3D chez des patients en croissance. Ne teste aucun outil de ce dépôt ; donne l'ordre de grandeur de l'erreur auquel comparer AREG.
  • Gillot 2022 (AMASSS) : le segmenteur qui produit les masques de région de référence consommés par AREG. Décrit la version UNETR, pas celle qui tourne actuellement (nnU-Net v2 aujourd'hui) : voir ../AMASSS/SOURCES.md.
  • Barone 2024 (AJODO) : chirurgie orthognathique de classe III, analyse voxel à voxel ; l'article indique explicitement que « des outils automatisés fondés sur l'apprentissage profond ont été utilisés pour l'orientation, le recalage, la segmentation osseuse et l'identification des landmarks » des CBCT dans 3D Slicer. C'est un usage clinique du pipeline ASO + AREG + AMASSS + ALI, pas une validation de l'outil.
  • Pages NA-MIC Project Week, sans DOI, utiles pour dater les jalons : PW39 2023 Montréal, Automated Registration of CBCT (Anchling, Hutin, Gurgel, Barone, Miranda, Roberts, Prieto, Cevidanes) et PW40 2024 Gran Canaria, maintenance (Claret, Leroux, Caleme, Mattos, Cevidanes, Prieto).
  • Dépôts de code, sans DOI : lucanchling/AREG, DCBIA-OrthoLab/SlicerAutomatedDentalTools.

Cherché, rien trouvé

  • Une version auteur en accès libre du chapitre LNCS ailleurs que sur PMC : Deep Blue (Université du Michigan), HAL/DUMAS (aucune entrée Anchling en imagerie médicale), Unpaywall et OpenAlex ne connaissent que la copie PMC.
  • Posters ou résumés IADR / AADOCR / AAO portant précisément sur AREG CBCT : rien d'indexé dans Europe PMC, Crossref ou OpenAlex. Les résumés IADR ne sont pas déposés avec un DOI ; s'il en existe un, il faudrait passer par l'archive des résumés de l'IADR, hors de portée d'une recherche automatisée.
  • La thèse de Luc Anchling : rien sur HAL, DUMAS ou Deep Blue.
  • Une publication décrivant le passage de SimpleElastix à itk-elastix, la suppression de la seconde passe de recalage, ou les pauses de revue : rien.

Comment le texte intégral a été récupéré

Le chapitre est payant chez Springer, mais le manuscrit auteur déposé auprès du NIH est librement accessible. Deux approches échouent dessus et une fonctionne, notées ici pour éviter de refaire toute la recherche :

VoieRésultat sur ce PMCID
pmc.ncbi.nlm.nih.gov/.../pdf/HTML anti-bot
API BioC pmcoa.cgi« No result can be found » : elle ne sert que le sous-ensemble open access
eutils.ncbi.nlm.nih.gov/entrez/eutils/efetch.fcgi?db=pmc&id=<number>JATS complet, corps inclus
 
curl -sL "https://eutils.ncbi.nlm.nih.gov/entrez/eutils/efetch.fcgi?db=pmc&id=11104011"

C'est ainsi qu'ont été obtenus les fichiers .xml et .txt de ce dossier. Le PDF mis en forme par l'éditeur doit encore être lu sur le site de Springer ou sur PMC.
