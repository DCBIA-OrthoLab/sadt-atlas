Agent: fonti

Non pubblicato. Nessun articolo copre questo modulo o il suo approccio. C'è però un documento ufficiale che andava trovato: un rapporto di progetto NA-MIC.

Il rapporto descrive l'intento, non lo stato

È stato recuperato qui un rapporto NA-MIC Project Week (PW45, Boston, 2026) firmato dai suoi autori. Descrive il modulo nel suo intento, non nel suo stato effettivo: annuncia llama3:latest dove il codice fissa qwen3:8b, e il suo «prossimo passo» (integrazione dell'LLM, distribuzione dentro Slicer) è già realizzato nel repository. Gli altri riferimenti utili sono puramente tecnici: il modello servito da Ollama, il cross-encoder di preselezione, e il dataset da cui proviene.

Vicinato

Nessuno dei lavori seguenti descrive questo modulo.

  • MS MARCO (Bajaj, recuperato): il reranker è stato addestrato a classificare passaggi web per query di Bing. Qui riceve schede di moduli Slicer e prompt di operatori: un dominio e un registro per cui non è stato addestrato, e per i quali non esiste alcuna valutazione nel repository.
  • Qwen3 (recuperato): il rapporto tecnico del modello generico. Né il prompt di sistema del modulo, né il suo formato di output JSON vincolato, né il suo ciclo di riparazione vi compaiono, e il codice non passa alcun temperature, seed, num_ctx o think.
  • Ollama e llama.cpp, il server e il motore di inferenza effettivamente usati: nessuna pubblicazione. ollama.com · github.com/ggml-org/llama.cpp.
  • Another agent, another project: Tu P., Dominguez M., Kikinis R., Pieper S., Kim S., Interactive Workflow Replay and Step-Back Navigation for Slicer Agent, 45th NA-MIC Project Week, Boston, 2026 (link). It covers puxuntu/Slicer_agent, an agent that generates and executes Python inside the Slicer scene: different code, a different team, presented at the same project week. Not to be confused with this module, which calls the extension's CLIs and writes no code.
  • LLM in questo laboratorio, compito diverso: Gaydamour A. et al., Cevidanes L., AI-Driven Multimodal TMJ Patient Modeling: From Unstructured Notes to Precision Treatment, CLIP 2025, LNCS vol. 16126, p. 42-52 (10.1007/978-3-032-05479-1_5). BART e DeepSeek-R1 sottoposti a fine-tuning per estrarre 56 indicatori clinici da note di pazienti. Senza relazione con l'instradamento verso moduli Slicer.

Che cosa è stato cercato e non trovato

Ricerca a testo integrale su Europe PMC e OpenAlex per SlicerAutomatedDentalTools e "Automated Dental Tools": nessun risultato su un agente LLM. Albero completo delle directory del repository NA-MIC/ProjectWeek (2.854 file, PW35 → PW45): il rapporto PW45 recuperato qui sopra è l'unica voce su questo modulo. Ricerca web su agente LLM + 3D Slicer + odontoiatria: nulla oltre alla documentazione del repository e alla letteratura generale sugli LLM in odontoiatria, senza relazione con questo codice.
