Agent con VISOR

Che cos'è il pannello Agent dell'estensione VISOR, e perché non usa il server VISOR. Il modulo legacy ha la propria pagina.

VISOR Pagina legacy Atlante (VISOR)

L'estensione VISOR include un pannello Agent, ma è lo stesso assistente locale, non uno strumento del server. Richiede ancora Ollama sul tuo computer, gira ancora sul tuo computer, e non invia nulla al server VISOR (AutomatedDentalToolsRemote README.md:28-30, commit 19b95e8). Non chiede al server di eseguire gli strumenti che sceglie.

Che cosa è diverso dalla guida legacy: nulla di ciò che si vede. Il pannello è una copia di quello legacy (AgentRemote/AgentRemote.py) e ne conserva i limiti: la finestra di conferma, i tentativi di riparazione, Slicer bloccato mentre un job gira, e la cartella degli script che non trova a meno di configurarla (AGENT_CLI_TOOLS_DIR, Agent_CLIRemote/Agent_CLIRemote_utils/utils.py:154). Il suo elenco di strumenti nomina ancora due voci MedX, anche se MedX non esiste più (Agent_CLIRemote/manifest.yaml:491,509).

Esiste un Agent lato server, ma nessun pannello lo offre

Il server VISOR può ospitare uno strumento Agent che propone quale strumento del server eseguire per una richiesta, e lo esegue solo se richiesto. Richiede un server Ollama che l'amministratore ha impostato separatamente, e nessun pannello del client lo chiama (SADT-VISOR tools/Agent, commit 6ba2a78). Per come funziona, vedi la pagina Atlante VISOR di Agent.
