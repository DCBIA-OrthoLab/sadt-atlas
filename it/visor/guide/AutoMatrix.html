AutoMatrix con VISOR

Che cosa cambia quando si esegue AutoMatrix tramite un server VISOR da 3D Slicer: che cosa fornire, che cosa resta uguale, che cosa è diverso. Il modulo legacy ha la propria pagina.

VISOR Pagina legacy Atlante (VISOR)

Tramite un server VISOR il modulo si chiama AutoMatrix Remote. In Slicer scegli i file e le trasformazioni; vengono inviati al server, che li abbina per paziente, li sposta, e rimanda i risultati in una cartella che scegli. Il pannello è costruito da ciò che il server pubblica. Nulla è installato o scaricato sul tuo computer.

Che cosa fornire

  • File da trasformare: una scansione, una segmentazione, un file di landmark (.mrk.json) o una cartella di essi. Un server può ospitare insiemi di test (da AutoMatrixRelease1 a 4) che compaiono nel menu a tendina.
  • Trasformazioni: .tfm, .mat, .h5, .hdf5 o .txt, un file o una cartella. Anche un file che contiene una semplice matrice 4×4 (quattro righe di quattro numeri, ciò che GreedyReg scrive come .mat) è letto, come matrice affine presa così com'è.
  • Stessa trasformazione per ogni paziente: selezionala quando indichi una sola trasformazione per l'intera cartella. Senza di essa, una trasformazione il cui nome non corrisponde ad alcun paziente è usata solo se c'è esattamente un paziente; con più pazienti non viene scritto nulla e l'esecuzione si ferma con un errore.
  • Include the transform name e Output suffix (Reg per impostazione predefinita, quindi P1_T1.nii.gz torna come P1_T1_Reg.nii.gz).
  • Use the mirror matrix: una spunta riempie Transforms con la matrice speculare ospitata dal server e seleziona "Same transform for every patient". È disattivata se il server non ospita quel file.

Due impostazioni sono nascoste nel pannello: come ricampionare (il server decide file per file se un volume è una labelmap, quindi non esiste più la casella di segmentazione) e il volume di riferimento.

Che cosa resta uguale

  • I volumi sono ricampionati con la trasformazione; i punti landmark si muovono attraverso la sua inversa, così una scansione e i suoi landmark mantengono lo stesso movimento.
  • Più trasformazioni per un paziente danno un output ciascuna, mai una catena. Il coordinateSystem dei landmark continua a non essere letto.
  • L'output conserva la struttura delle cartelle dell'input; fino a 12 risultati sono caricati nella scena.

Che cosa è diverso

  • Una sola regola di nomenclatura per scansioni e matrici (P1_scan.nii.gz si abbina a P1_matrix.tfm). Dove fallisce, un ripiego imita i tagli del legacy, e il report dice quali pazienti sono stati abbinati così (paired_by).
  • I file non abbinati sono segnalati in AutoMatrix_report.json.
  • Niente mesh e niente .npy; i volumi supportati sono .nii.gz .nii .nrrd .gipl e le loro forme .gz (.nrrd.gz è cercato ma non può essere letto).
  • Una trasformazione che non può essere invertita (un campo di deformazione) fa fallire il file di landmark di quel paziente; il fallimento è nel report.
La riga di stato finale è sbagliata

Il messaggio mostrato nella barra di stato di Slicer al termine dell'esecuzione dice sempre "AutoMatrix: 0 file(s) written.", e non menziona mai i file non abbinati. Legge due campi che il report non ha. Giudica l'esecuzione dalla cartella di output e da AutoMatrix_report.json (summary.files_written, without_a_transform, transforms_without_a_file).

Senza un volume di riferimento il risultato può finire accanto ai dati

Il pannello non offre alcun volume di riferimento. Senza, l'output conserva la dimensione dell'input ma prende come origine l'immagine dell'origine data dalla trasformazione. Provato il 2026-11-09 chiamando direttamente lo strumento del server con una matrice di riflessione sostitutiva su un piccolo volume centrato sull'origine: l'output era vuoto, ed era completo quando il volume era il proprio riferimento. Anche una semplice traslazione sposta il contenuto e può tagliarne una parte. È ciò che usa il riquadro speculare. Una correzione esiste su un ramo non fuso (fix/automatrix-mirrors-into-an-empty-box, commit ce4f6fb), quindi guarda il risultato prima di affidartici. Dettagli nella pagina atlante.
