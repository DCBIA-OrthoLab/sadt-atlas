VFACE กับ VISOR

สิ่งที่เปลี่ยนไปเมื่อคุณรัน VFACE ผ่านเซิร์ฟเวอร์ VISOR จาก 3D Slicer: ต้องเตรียมอะไร อะไรเหมือนเดิม อะไรต่างไป โมดูล legacy มีหน้าของตัวเอง

VISOR หน้า Legacy แอตลาส (VISOR)

เมื่อใช้ VISOR VFACE รันบนเซิร์ฟเวอร์และ Slicer เพียงแสดงแผงของมัน การวัด การจำแนก และสายของหกโมดูลคือสิ่งที่อธิบายในคู่มือ legacy สิ่งที่เปลี่ยนคือที่ที่มันรันและสิ่งที่คุณต้องเตรียม

เฉพาะบนเซิร์ฟเวอร์ที่บิลด์จากสอง feature branch

ฝั่งเซิร์ฟเวอร์ของ VFACE มีอยู่เฉพาะบน branch พัฒนา (SADT-VISOR tool/vface และ VISOR-serve conf/vface-deployment) ไม่ใช่บน main ของมัน เซิร์ฟเวอร์ VISOR ที่บิลด์จาก main ไม่เสนอ VFACE แม้ว่าแผง VFACE จะมาพร้อม extension ของ Slicer ก็ตาม ให้ถามผู้ที่ดูแลเซิร์ฟเวอร์ของคุณ

  • ไม่มีขั้นตอนดาวน์โหลด ปุ่มที่ดึงน้ำหนักโมเดลหายไปแล้ว: โมเดลการแบ่งส่วน landmark และตัวจำแนก reference การปรับทิศทาง transform กระจก และรายการการวัด ทั้งหมดอยู่บนเซิร์ฟเวอร์ และแผงไม่แสดงมัน
  • สิ่งที่คุณเลือกในแผง: volume CBCT (โฟลเดอร์ หรือสแกนทดสอบที่โฮสต์) จุดเริ่มต้น (ทั้งสายงาน ปรับทิศทางแล้ว ลงทะเบียนแล้ว) การศึกษา (การประเมินความไม่สมมาตรหรือแบบติดตามระยะยาว) สิ่งที่จะผลิต และบริเวณที่จะวัด: cranial base, mandible, maxilla การศึกษาระยะยาวขอ volume ติดตามผล การเริ่มจาก "already registered" ขอ transform ของการลงทะเบียนของคุณเอง
  • สิ่งที่คุณได้กลับมา: zip ที่คลายลงโฟลเดอร์ผลลัพธ์ ซึ่งมี ขึ้นอยู่กับสิ่งที่คุณขอ เวิร์กบุ๊กการวัดต่อบริเวณ ตารางคุณลักษณะ เวิร์กบุ๊กการจำแนก และรายงานการรันเสมอ (VFACE_report.json) หากคุณขอheat map กล่องหนึ่งจะโหลดมันลงฉากเมื่อการรันจบ ได้ครั้งละสิบสองรายการ
  • ไม่มีจุดหยุดพัก จุดหยุดตรวจทานของโมดูล legacy ที่ให้คุณตรวจผลระหว่างทางและแก้ landmark หรือการลงทะเบียนภาพ ไม่ได้ถูกพอร์ตมา (VISOR:SADT-VISOR tools/VFACE/README.md:29-32) การรันจะไปจนจบเอง และแผงไม่มีตัวเลือกให้หยุดกลางทาง
  • รายการการวัดเป็นของเซิร์ฟเวอร์ แผงไม่ถามหารายการ เครื่องมือใช้รายการเริ่มต้นที่โฮสต์อยู่บนเซิร์ฟเวอร์ (VISOR:SADT-VISOR tools/VFACE/src/sadt_vface/layout.py:54-58, dispatch.py:321-322) ต่างจากโมดูล legacy ตรงที่มันอ่านทุกชีตของรายการนั้น (aq3dc.py:122)
การตั้งค่าเซิร์ฟเวอร์ปัจจุบันไม่มี heatmap ให้

ไฟล์ของเซิร์ฟเวอร์สำหรับ VFACE ระบุว่าไม่เผยแพร่โมเดลพื้นผิว และเครื่องมือปฏิเสธคำขอ heatmap ที่ไม่มีโมเดลนั้น (VISOR:VISOR-serve server/deployment.toml:277-279; VISOR:SADT-VISOR tools/VFACE/src/sadt_vface/dispatch.py:452-458) ให้ขอการวัดและการจำแนกแทน ข้อนี้อ่านจากโค้ด ไม่ได้ลองบนเซิร์ฟเวอร์

ยังไม่ได้ตรวจกับผู้ป่วย

VFACE ฉบับ VISOR ผ่านการทดสอบกับโมดูลจำลองแล้ว แต่ยังไม่เคยรันกับโมดูลจริงทั้งหกตัว และผลลัพธ์ยังไม่ได้เทียบกับโมดูล legacy บนผู้ป่วยหรือยืนยันทางคลินิก (VISOR:SADT-VISOR tools/VFACE/README.md:184-193) ให้ถือว่าผลวินิจฉัยที่ได้ด้วยวิธีนี้ยังไม่ได้รับการยืนยัน
