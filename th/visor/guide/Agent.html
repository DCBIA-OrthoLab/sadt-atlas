Agent กับ VISOR

แผง Agent ของ extension VISOR คืออะไร และเหตุใดจึงไม่ใช้เซิร์ฟเวอร์ VISOR โมดูล legacy มีหน้าของตัวเอง

VISOR หน้า Legacy แอตลาส (VISOR)

extension VISOR มีแผง Agent แต่มันคือผู้ช่วยในเครื่องตัวเดิม ไม่ใช่เครื่องมือของเซิร์ฟเวอร์ มันยังต้องใช้ Ollama บนคอมพิวเตอร์ของคุณเอง ยังรันบนคอมพิวเตอร์ของคุณ และไม่ส่งอะไรไปยังเซิร์ฟเวอร์ VISOR (AutomatedDentalToolsRemote README.md:28-30, คอมมิต 19b95e8) มันไม่ขอให้เซิร์ฟเวอร์รันเครื่องมือที่มันเลือก

สิ่งที่ต่างจากคู่มือ legacy: ไม่มีอะไรที่คุณเห็น แผงเป็นสำเนาของแผง legacy (AgentRemote/AgentRemote.py) และคงข้อจำกัดของมัน: กล่องยืนยัน ความพยายามซ่อมแซม Slicer ค้างขณะงานรัน และโฟลเดอร์สคริปต์ที่มันหาไม่พบเว้นแต่คุณกำหนดค่า (AGENT_CLI_TOOLS_DIR, Agent_CLIRemote/Agent_CLIRemote_utils/utils.py:154) รายการเครื่องมือของมันยังระบุรายการ MedX สองรายการ ทั้งที่ MedX ไม่มีอยู่แล้ว (Agent_CLIRemote/manifest.yaml:491,509)

มี Agent ฝั่งเซิร์ฟเวอร์ แต่ไม่มีแผงใดเสนอมัน

เซิร์ฟเวอร์ VISOR โฮสต์เครื่องมือ Agent ได้ ซึ่งเสนอว่าเครื่องมือฝั่งเซิร์ฟเวอร์ตัวใดควรรันสำหรับคำขอ และรันก็ต่อเมื่อถูกขอ มันต้องใช้เซิร์ฟเวอร์ Ollama ที่ผู้ดูแลตั้งไว้แยกต่างหาก และไม่มีแผงใดในไคลเอนต์เรียกมัน (SADT-VISOR tools/Agent, คอมมิต 6ba2a78) วิธีทำงานของมัน ดูหน้าแอตลาส VISOR ของ Agent
