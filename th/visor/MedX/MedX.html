MedX: ยังไม่ได้พอร์ตไปยัง VISOR

MedX ไม่มีอยู่ใน VISOR และไม่อยู่ใน extension legacy ปัจจุบันอีกต่อไปเช่นกัน หน้านี้บอกตรง ๆ ว่าเหลืออะไรของมันในที่เก็บ VISOR โมดูลที่เก็บถาวรอธิบายอยู่ในหน้า legacy ของมัน

VISOR: ยังไม่ได้พอร์ต โมดูลถูกถอดออก หน้า Legacy Guide (VISOR)

สถานะที่ commit อ้างอิง: SADT-VISOR 6ba2a78, VISOR-serve e9a7e5d, AutomatedDentalToolsRemote 19b95e8 legacy คือ SlicerAutomatedDentalTools ที่ 3c67957 ทุกอย่างด้านล่างอ่านจากที่เก็บ ไม่มีอะไรถูกรัน

สิ่งที่มี แยกตามชั้น

ชั้นมีไหมหลักฐาน
โมดูล legacyเก็บถาวรแล้วถูกถอดออกโดย commit 34d496f (2026-09-17, "Drop MedX and SurgMovPred, kept on archive branches") เก็บไว้บนสาขา archive/medx ที่ fbfa0fb พร้อม MedX/MedX.py, MedX/MedX_Method/ และ MedX_CLI/ ไม่มีที่ 3c67957: ไม่มีไฟล์ MedX และไม่มีบรรทัด MedX ใน CMakeLists.txt
เครื่องมือเซิร์ฟเวอร์ไม่มีไม่มีโฟลเดอร์ MedX ใต้ SADT-VISOR tools/ ไม่มีส่วนใน VISOR-serve server/deployment.toml
ไฟล์โมเดลระบุไว้ แต่ไม่มีเครื่องมือมาใช้VISOR-serve scripts/data-manifest.yml:644-651: BART.zip (1 508 192 833 ไบต์) ใต้หัวข้อ "NOT PORTED YET"
โมดูลไคลเอนต์ไม่มีไม่มีโฟลเดอร์ MedX* ใน AutomatedDentalToolsRemote
ร่องรอยรายการ manifest ที่ล้าสมัยสองรายการAutomatedDentalToolsRemote Agent_CLIRemote/manifest.yaml:491,509 ยังระบุ medx_dashboard และ medx_summarize ดูAgent บน VISOR

CNE เป็นตัวสืบทอดในการใช้งาน ไม่ใช่ในวิธีการ

README ของไคลเอนต์เรียก CNE ว่า "Successor of the former MedX module" (AutomatedDentalToolsRemote README.md:208,601) นั่นอธิบายการใช้งาน ไม่ใช่อัลกอริทึมที่เทียบเท่ากัน MedX รันโมเดลสรุปความ BART ที่ fine-tune แล้วเพื่อเขียนสรุปหนึ่งฉบับต่อผู้ป่วย จากนั้นสร้างแผงภาพจาก cohort (หน้า legacy ส่วน 4 และส่วน 5) เครื่องมือ CNE ของ VISOR รันโมเดลภาษา GGUF แบบ quantised ผ่าน llama.cpp และเขียน ต่อหนึ่งบันทึก ข้อค้นพบที่มีโครงสร้างเป็น JSON และข้อค้นพบเดียวกันเป็นข้อความ key : value (SADT-VISOR tools/CNE/README.md:1-22) README ของมันไม่เอ่ยถึง dashboard โมเดลและเอาต์พุตต่างกัน: ดูCNE บน VISOR

ไม่มีข้อค้นพบใดในหน้า legacy ที่ตรวจเทียบกับโค้ด VISOR ได้ เพราะไม่มีโค้ดนั้น: ทั้งหมดอธิบายโค้ดที่เก็บถาวรบน archive/medx
