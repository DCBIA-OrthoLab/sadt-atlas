MRI2CBCT: จัดแนว MRI และ CBCT ของ TMJ

MRI2CBCT ลงทะเบียน MRI ลงบน CBCT ของข้อต่อขากรรไกร (TMJ) เพื่อให้คุณดูการตรวจทั้งสองในเฟรมเดียวกัน ตอนนี้เป็นปุ่มเดียว: เลือกโฟลเดอร์ กด Run แล้วโมดูลจะเตรียม จัดทิศทาง แบ่งส่วน และลงทะเบียนให้ผู้ป่วยทุกคน

หน้าโมดูล Legacy

หน้านี้อธิบายโมดูล Slicer แบบ legacy ไม่มีให้ใช้ผ่านเซิร์ฟเวอร์ VISOR: ดู MRI2CBCT กับ VISOR และ การใช้ VISOR

ใช้เมื่อใด

เมื่อไรก็ตามที่คุณมี MRI และ CBCT ของ TMJ ของผู้ป่วยคนเดียวกัน และอยากให้ซ้อนทับกัน: กระดูกเห็นชัดกว่าบน CBCT เนื้อเยื่ออ่อน (แผ่นรองข้อต่อ แคปซูล) เห็นชัดกว่าบน MRI และการลงทะเบียนทั้งสองให้คุณดูทั้งสองพร้อมกัน แทนที่จะเปรียบเทียบจากความจำ คุณไม่ต้องผ่านแท็บทีละแท็บอีกต่อไป: Run ครั้งเดียวทำทั้งสายโซ่ให้ผู้ป่วยทุกคนที่พบในทั้งสองโฟลเดอร์

สิ่งที่มันลงทะเบียน

โมดูลไม่ได้จับคู่ความสว่างของภาพทั้งสอง มันให้เครือข่ายหนึ่งหาฐานกะโหลกบน CBCT และอีกเครือข่ายหาบน MRI แล้วปรับพื้นผิวทั้งสองเข้าด้วยกัน ผลลัพธ์จึงดีได้เพียงเท่าเส้นขอบทั้งสองนั้น ซึ่งเป็นเหตุผลที่มันหยุดพักให้คุณตรวจได้

สิ่งที่ต้องมี สิ่งที่ได้คืน

สิ่งที่ต้องเตรียม

  • โฟลเดอร์ MRI และโฟลเดอร์ CBCT (.nii.gz, .nii หรือ .nrrd)
  • ไฟล์ที่ชื่อขึ้นต้นด้วยรหัสผู้ป่วย (P01, B038...): นี่คือวิธีจับคู่สองโฟลเดอร์ CBCT หนึ่งชุดต่อผู้ป่วย MRI หนึ่งหรือสองชุด
  • โฟลเดอร์ผลลัพธ์
  • การตั้งค่าครั้งเดียว: แพ็กเกจ Python และโมเดล ประมาณ 5 GB ดาวน์โหลดให้คุณ

สิ่งที่ได้ออกมา

  • ต่อผู้ป่วยหนึ่งคน โฟลเดอร์ที่มีข้อต่อ MRI แต่ละข้างที่ลงทะเบียนบน CBCT ต้นฉบับ มาสก์ฐานกะโหลกของมัน และไฟล์การแปลง
  • summary.csv ที่มีคำตัดสินสำหรับทุกข้อต่อ: OK, SMALL, FLAG หรือ FLIP
  • วอลุ่มสองชุดที่ซ้อนทับในฉากเดียวกันได้ ไม่ใช่ไฟล์ที่รวมกัน CBCT ไม่เคยถูกแก้ไข

สิ่งที่เกิดขึ้นเมื่อคุณกด Run

  1. การเตรียม MRI จับคู่ผู้ป่วย และตามค่าเริ่มต้น resample MRI แต่ละชุดเป็น 0.3 mm และแยกวอลุ่มที่มีทั้งสองข้อต่อออกเป็นซีกซ้ายและขวา วอลุ่มที่มีช่องว่างระหว่างสองชุดสไลซ์จะถูกสร้างใหม่โดยใช้ "acquisition slice spacing" ที่คุณตั้ง (3.0 mm เป็นค่าเริ่มต้น) ด้านของ MRI ข้อต่อเดียวอ่านจากตำแหน่งที่มันอยู่ในไฟล์
  2. การจัดทิศทาง CBCT สามขั้นตอนอัตโนมัติ (ของโมดูล ASO) วางศีรษะในทิศทางมาตรฐาน Frankfurt และ midsagittal
  3. ฐานกะโหลกบน CBCT เครือข่าย AMASSS วาดเส้นขอบของมัน
  4. ฐานกะโหลกบน MRI เครือข่ายที่สอง Dataset516 วาดเส้นขอบบนข้อต่อแต่ละข้าง ค่าเริ่มต้นใช้ห้า fold ของโมเดล หนึ่ง fold เร็วกว่าบนคอมพิวเตอร์ที่ไม่มี GPU
  5. การลงทะเบียน ปรับเส้นขอบ MRI เข้ากับเส้นขอบ CBCT ถ้าคำตอบแรกเป็น flip (หมุนผิดทาง) โมดูลจะลองเพิ่ม ได้แก่ การหมุนครึ่งรอบ อีกด้านของศีรษะ และสุดท้ายคือ MRI ที่สะท้อน ก่อนยอมแพ้และทำเครื่องหมายผลลัพธ์ว่า _FLAGGED

ตัวเลือกและการตรวจสอบ

  • Use test files ดาวน์โหลดผู้ป่วยตัวอย่าง (CBCT หนึ่งชุด MRI สองชุด) เติมโฟลเดอร์ทั้งสาม และเก็บผลลัพธ์ที่คาดหวังไว้ในโฟลเดอร์ reference เพื่อให้คุณเปรียบเทียบได้
  • Resample และ Separate left and right เปิดอยู่เป็นค่าเริ่มต้น ปิดการแยกถ้า MRI แต่ละชุดของคุณเป็นข้อต่อเดียวหรือทั้งศีรษะอยู่แล้ว
  • ขั้นสูง: วาง MRI ที่ลงทะเบียนแล้วบนกริด voxel ของ CBCT (ปิดเป็นค่าเริ่มต้น: MRI คง voxel ของตัวเองและเปลี่ยนเพียงตำแหน่ง) เก็บไฟล์ระหว่างทาง ตั้งจำนวน worker ของการลงทะเบียน
  • ทบทวน: ติ๊ก "Pause during the run" และเลือกว่าจะหยุดที่ใด ที่แต่ละจุดหยุด ภาพจะเปิดใน Slicer พร้อมเส้นขอบซ้อนทับ ที่จุดหยุดแรกคุณสลับซ้ายและขวาให้ผู้ป่วยได้ถ้าด้านผิด

ถ้าค้าง

รีสตาร์ทหลังการตั้งค่าครั้งแรก

ถ้าต้องติดตั้งหรือเปลี่ยน PyTorch ให้เหมาะกับการ์ดจอของคุณ แผงจะขอให้รีสตาร์ท Slicer แล้วกด Run อีกครั้ง บน Linux ไลบรารีการลงทะเบียนต้องใช้ระบบที่มี glibc 2.31 ขึ้นไป

ผู้ป่วยถูกข้าม

ไฟล์ที่ชื่อไม่ขึ้นต้นด้วยรหัส MRI ที่ไม่มี CBCT (หรือกลับกัน) หรือผู้ป่วยที่มี CBCT มากกว่าหนึ่งชุด จะถูกตัดออก และแผงจะแสดงรายการก่อนเริ่ม เก็บโฟลเดอร์ผลลัพธ์ของคุณนอกโฟลเดอร์ MRI และ CBCT: โฟลเดอร์ถูกอ่านแบบเรียกซ้ำ ผลลัพธ์ของการรันก่อนหน้าจึงอาจถูกหยิบไปเป็นสแกนใหม่

อ่านคำตัดสิน ไม่ใช่แค่ชื่อไฟล์

ข้อต่ออาจออกมาเป็น FLAG (ทับซ้อนอ่อน) และยังคงถูกบันทึกภายใต้ชื่อไฟล์ปกติ มีเพียง summary.csv และข้อความตอนท้ายที่บอก SMALL หมายความว่าเส้นขอบ MRI เล็กมาก ซึ่งเป็นกรณีที่ล้มเหลวบ่อยที่สุด อะไรก็ตามที่ติดป้าย _FLAGGED, FLIP หรือ _MIRRORED ควรตรวจดูก่อนพึ่งพา

ด้านผิด

ด้านของ MRI ข้อต่อเดียวมาจากตำแหน่งของมันในไฟล์ ถ้าผิด ให้สลับที่จุดหยุดแรก ถ้าคุณไม่ได้หยุด โมดูลยังกู้คืนได้ด้วยการลองอีกด้าน แต่เฉพาะเมื่อคำตอบแรกเป็น flip

ล็อกหายไป

ล็อกการรันอยู่กับไฟล์ระหว่างทาง ซึ่งถูกลบหลังการรันที่สำเร็จ เว้นแต่คุณติ๊ก "Keep the intermediate files"

หลังจากนั้น

CBCT ต้นฉบับไม่เคยถูกแก้ไข เปิด MRI ที่ลงทะเบียนแล้วและ CBCT ด้วยกันใน Slicer เพื่อตรวจการซ้อนทับก่อนใช้ในการวัดใด ๆ ถ้าคุณต้องการการแปลงสำหรับงานอื่น ให้โหลด MRI ต้นฉบับแล้วใช้ .tfm กับมัน: วิธีนี้ไม่มีอะไรถูกประมาณค่า การลงทะเบียนที่คำตัดสินระบุว่ามีข้อบกพร่อง ควรรันใหม่พร้อมจุดหยุดตรวจทานบนเส้นขอบทั้งสอง ดีกว่าปรับด้วยมือ
