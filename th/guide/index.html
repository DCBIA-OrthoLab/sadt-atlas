คู่มือการใช้งาน

เครื่องมือแต่ละตัวทำอะไร ต้องป้อนอะไรให้ และได้อะไรกลับมา — โดยไม่ลงรายละเอียดโค้ด หากต้องการเข้าใจกลไกภายใน ให้ไปที่แอตลาส

คู่มือนี้เขียนให้ใคร

สำหรับทุกคนที่เปิด SlicerAutomatedDentalTools ใน 3D Slicer แล้วต้องการใช้งาน ไม่ว่าจะเป็นทันตแพทย์ นักวิจัย หรือนักศึกษา ไม่จำเป็นต้องอ่านโค้ดเป็น หรือรู้ว่าโครงข่ายประสาทเทียมคืออะไร หากสิ่งที่สนใจคือการทำงานภายใน — โมเดลใดถูกเรียก เมื่อใด กับข้อมูลใด — ให้ดูที่ แอตลาส แทน ทั้งสองส่วนครอบคลุม 20 โมดูลเดียวกัน แต่มองจากคนละด้าน

ทำไมจึงมีคู่มือนี้

ส่วนขยายนี้รวม 20 โมดูลที่เขียนโดยทีมต่าง ๆ ในช่วงเวลาต่างกัน เอกสารของแต่ละโมดูล มีตั้งแต่ README ไม่กี่บรรทัด หน้าโครงการหนึ่งหน้า ไปจนถึงไม่มีเลย หลายโมดูลทำงานต่างจาก ที่บทความตีพิมพ์อธิบายไว้ เพราะบทความบรรยายเวอร์ชันที่โค้ดไม่ได้รันแล้ว

คู่มือนี้เขียนจากการอ่านโค้ดของแต่ละโมดูล ไม่ใช่จากเอกสาร จึงบอกสิ่งที่เครื่องมือทำจริง เมื่อคุณคลิก รวมถึงเรื่องที่ไม่สะดวกด้วย: คำเตือน 57 รายการและบั๊ก 2 รายการ ถูกระบุไว้ตรงจุดที่คุณมีโอกาสเจอ ที่นี่ไม่ได้แก้ไขอะไร — เป้าหมายคือไม่ให้คุณเสียเวลาทั้งวัน กับเรื่องเหล่านี้

ในแต่ละหน้ามีอะไรบ้าง

ทุกหน้าใช้โครงสร้างเดียวกัน เพื่อให้รู้ว่าต้องดูตรงไหนโดยไม่ต้องอ่านใหม่ทั้งหมด

  • ใช้เมื่อใด — เครื่องมือแก้ปัญหาอะไร และกรณีที่ใช้ไม่ได้ผล
  • สิ่งที่ต้องใช้ สิ่งที่จะได้ — อินพุตที่ต้องการ รูปแบบไฟล์ และผลลัพธ์ที่ได้ในตอนท้าย
  • ขั้นตอน — ขั้นตอนตามลำดับ ทีละช่อง
  • หากเกิดปัญหา — ความล้มเหลวที่พบบ่อยและสาเหตุ
  • อ่านเพิ่มเติม — บทความเบื้องหลังเครื่องมือ (ถ้ามี) และลิงก์ไปยังหน้าแอตลาส

เริ่มจากตรงไหน

หากรู้แล้วว่าต้องการเครื่องมือใด เลือกได้จากรายการด้านล่าง หากยังไม่รู้ ให้เริ่มจากสิ่งที่ต้องทำ:

  • เปรียบเทียบการตรวจสองครั้งของผู้ป่วยคนเดียวกันตามเวลา → การลงทะเบียนภาพ
  • แยกโครงสร้างออกจาก CBCT → การแบ่งส่วน
  • วางจุดสังเกตทางกายวิภาค หรือจัดภาพสแกนให้ตั้งตรง → จุดสังเกตและการจัดแนว
  • วัด จำแนก หรือทำนายจากรูปทรง → การวิเคราะห์
  • ครอปหรือใช้เมทริกซ์แบบกลุ่ม → เครื่องมือเสริม
  • ดึงข้อมูลหรือลบข้อมูลระบุตัวตนจากข้อความทางคลินิก → ข้อความและภาษา

การลงทะเบียนภาพ

FlexRegลงทะเบียนภาพสแกนในช่องปากสองชุด โดยเลือกบริเวณที่คงที่เอง AREG_IOSลงทะเบียนภาพสแกนสองชุดของผู้ป่วยคนเดียวกัน โดยไม่ต้องวาดอะไร AREG_CBCTซ้อนภาพ CBCT สองชุดของผู้ป่วยคนเดียวกันที่ถ่ายต่างเวลา AREG_IOSCBCTวางภาพสแกนในช่องปากลงในระบบพิกัดของ CBCT GreedyRegลงทะเบียนภาพ CBCT สองชุดด้วยเอนจินของ ITK-SNAP MRI2CBCTจัดแนว MRI และ CBCT ของข้อต่อขากรรไกร

การแบ่งส่วน

AMASSSแบ่งส่วนขากรรไกรล่าง ขากรรไกรบน และโครงสร้างอื่นจาก CBCT BatchDentalSegแบ่งส่วนฟันและกระดูกจากภาพสแกนหลายชุดในครั้งเดียว

จุดสังเกตและการจัดแนว

ALIวางจุดสังเกตทางกายวิภาคโดยอัตโนมัติ ASOจัดภาพสแกนให้อยู่ในแนวเดียวกัน

การวิเคราะห์

VFACEวัดและจำแนกความไม่สมมาตรของใบหน้าผู้ป่วย DOCShapeAXIจำแนกรูปทรง 3 มิติ และดูว่าอะไรเป็นเหตุผลของการตัดสิน CLICค้นหาและจำแนกฟันเขี้ยวคุดบน CBCT SurgMovPredประเมินการเคลื่อนที่ของกระดูกที่คาดว่าจะเกิดหลังผ่าตัด

เครื่องมือเสริม

AutoCrop3Dครอปวอลุ่มหลายชุดให้เป็นบริเวณเดียวกัน AutoMatrixใช้เมทริกซ์การลงทะเบียนภาพกับทั้งชุดข้อมูล

ข้อความและภาษา

CNEดึงข้อมูลที่มีโครงสร้างออกจากบันทึกทางคลินิก MedXสรุปรายงานทางคลินิกและสร้างแดชบอร์ดจากรายงานเหล่านั้น MedicalDataAnonymizerลบข้อมูลส่วนบุคคลออกจากเอกสารข้อความ Agentถามเป็นภาษาธรรมดาว่าควรใช้เครื่องมือใด
