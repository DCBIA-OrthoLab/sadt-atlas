CLIC — ค้นหาและจำแนกฟันเขี้ยวคุดบนภาพ CBCT

CLIC ตรวจภาพ CBCT ทีละสไลซ์และระบุฟันเขี้ยวคุด พร้อมบอก ตำแหน่งของฟันแต่ละซี่เทียบกับกระดูก: ด้านแก้ม (buccal) ระหว่างสองคอร์เทกซ์ (bicortical) หรือ ด้านเพดานปาก (palatal) เริ่มจาก วอลุ่มดิบได้เลย ไม่ต้องแบ่งส่วนหรือวางจุดสังเกตทางกายวิภาค (landmark) ไว้ก่อน

แถบความคืบหน้าไม่ขยับ ซึ่งเป็นเรื่องปกติ

ระหว่างที่เครื่องมือทำงาน แถบความคืบหน้าจะค้างอยู่ที่ศูนย์ และไม่มีอะไรปรากฏใน ฉากของ Slicer แม้การประมวลผลจะเสร็จแล้วก็ตาม นี่ไม่ใช่การแครช ไฟล์ผลลัพธ์ ยังถูกเขียนลงดิสก์ในโฟลเดอร์เอาต์พุตตามปกติ คุณต้อง ไปหาไฟล์และโหลดเอง ดูตำแหน่งไฟล์ด้านล่าง

ใช้เมื่อใด

ใช้เมื่อมีภาพ CBCT ที่มีฟันเขี้ยวคุดหนึ่งซี่หรือมากกว่า และต้องการทราบว่าฟันอยู่ด้านใด ของกระดูกคอร์เทกซ์ โดยไม่ต้องตรวจดูทีละซี่ด้วยตา CLIC ไม่ พึ่งพาโมดูลอื่น ไม่จำเป็นต้องรัน AMASSS, ASO หรือ ALI มาก่อน

สิ่งที่ต้องใช้ สิ่งที่จะได้

สิ่งที่ต้องเตรียม

  • โฟลเดอร์ภาพ CBCT ในรูปแบบ .nii หรือ .nii.gz
  • โมเดลที่ฝึกแล้ว ซึ่งดาวน์โหลดครั้งเดียว
  • โฟลเดอร์เอาต์พุต ซึ่งต้องเลือกเองอย่างชัดเจน

สิ่งที่จะได้

  • โฟลเดอร์ย่อยหนึ่งโฟลเดอร์ต่อภาพสแกนหนึ่งภาพ ซึ่งมี label map .nii.gz
  • ค่าวอกเซลที่เป็นไปได้สามค่า: buccal, bicortical, palatal
  • ซ้อนทับบนภาพต้นฉบับได้โดยตรง ไม่ต้องลงทะเบียนภาพ (registration)
รูปแบบไฟล์ที่เลือกได้แต่ใช้งานไม่ได้จริง

ตัวเลือกไฟล์ยังแสดง .nrrd, .mha และ .mhd ด้วย อย่าใช้รูปแบบเหล่านี้ การประมวลผลอ่านได้เฉพาะ .nii/.nii.gz และจะล้มเหลวกับรูปแบบอื่น แม้ ตัวเลือกไฟล์จะยอมให้เลือกก็ตาม

ใช้ได้บน Linux เท่านั้น

โมดูลไม่มีเส้นทางการทำงานที่ใช้ได้บน Windows ไม่ว่า README จะเขียนไว้อย่างไร ให้รันบน Slicer ที่ติดตั้งบน Linux

ขั้นตอน

  1. ดาวน์โหลดโมเดล ปุ่มเฉพาะจะดึงโครงข่ายประสาทเทียม ที่ฝึกแล้วมาให้ ทำเพียงครั้งเดียว
  2. ระบุโฟลเดอร์อินพุต ต้องเป็นโฟลเดอร์แบบแบนที่มีไฟล์ .nii.gz ไม่ใช่โฟลเดอร์ที่มีโฟลเดอร์ย่อย
  3. เลือกโฟลเดอร์เอาต์พุต ขั้นตอนนี้จำเป็น หากไม่เลือก การประมวลผลจะล้มเหลวตั้งแต่ยังไม่เริ่ม
  4. สั่งรัน การรันครั้งแรกจะติดตั้งสภาพแวดล้อมการคำนวณด้วย จึง ใช้เวลานานกว่าครั้งต่อ ๆ ไป
  5. รอให้เสร็จ แม้หน้าจอจะไม่มีอะไรขยับ การประมวลผลทำ ทีละภาพสแกน โดยไม่มีการแสดงผลระหว่างทาง

ผลลัพธ์อยู่ที่ไหน

เมื่อประมวลผลเสร็จ ให้เปิดโฟลเดอร์เอาต์พุตที่เลือกไว้ ในนั้นมีโฟลเดอร์ย่อยหนึ่งโฟลเดอร์ ต่อภาพสแกนที่ประมวลผลหนึ่งภาพ และในแต่ละโฟลเดอร์มีไฟล์ .nii.gz ที่มีคำต่อท้าย ตามที่แสดงในอินเทอร์เฟซ (ค่าเริ่มต้นคือ seg) ให้โหลดไฟล์นั้นเข้า Slicer เองในฐานะวอลุ่มการแบ่งส่วน (segmentation) ไฟล์นี้ตรงแนวกับภาพต้นฉบับอยู่แล้ว ไม่ต้อง ลงทะเบียนภาพ ค่า 1, 2 และ 3 หมายถึง buccal, bicortical และ palatal ตามลำดับ

หากเกิดปัญหา

ปุ่ม Cancel ไม่มีผล

ปุ่มนี้ไม่หยุดทั้งการคำนวณที่กำลังทำอยู่และโพรเซสเบื้องหลัง หาก จำเป็นต้องหยุดจริง ๆ ให้ปิด Slicer

การรันครั้งแรกต้องเชื่อมต่ออินเทอร์เน็ต

การสร้างโครงข่ายจะดาวน์โหลดน้ำหนักที่ฝึกไว้ล่วงหน้าแบบทั่วไปก่อน แล้วจึงใช้ โมเดลที่ฝึกแล้วทับลงไป หากไม่มีการเชื่อมต่อในครั้งแรก การประมวลผล จะล้มเหลว

มีไฟล์โมเดลสองไฟล์ในโฟลเดอร์

หากโฟลเดอร์โมเดลมีไฟล์โมเดลมากกว่าหนึ่งไฟล์ ไฟล์ที่ชื่อเรียงตามตัวอักษรมาก่อน จะถูกใช้โดยไม่มีคำเตือน ควรเก็บไฟล์ .pth ไว้เพียงไฟล์เดียวใน โฟลเดอร์นั้นเพื่อไม่ให้เกิดความกำกวม

อ่านเพิ่มเติม

เกี่ยวกับวิธีการ

  • He et al., ICCV 2017 — Mask R-CNN. สถาปัตยกรรมที่โมดูลใช้งาน: ตรวจจับวัตถุและสร้างมาสก์ของวัตถุไปพร้อมกัน

  • Pirayesh et al., BMC Oral Health 2024 — A hierarchical deep learning approach for diagnosing impacted canine-induced root resorption. ด้านการละลายของรากฟัน: วิธีจัดระดับความรุนแรง และผลเมื่อเทียบกับผู้ประเมินที่เป็นมนุษย์
