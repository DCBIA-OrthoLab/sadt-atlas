CLIC: ค้นหาและจัดประเภทเขี้ยวฝังคุดบน CBCT

CLIC สแกน CBCT ทีละสไลซ์และปักธงเขี้ยวฝังคุด โดยบอกสำหรับแต่ละซี่ว่าอยู่ตำแหน่งใดเทียบกับกระดูก: ด้านแก้ม (buccal), ทั้งสองผนังกระดูก (bicortical) หรือด้านเพดาน (palatal) คุณเริ่มจากวอลุ่มดิบ: ไม่ต้องแบ่งส่วนหรือวาง landmark มาก่อน

สองวิธีในการรัน

หน้านี้อธิบายโมดูล Slicer แบบ legacy หากใช้ผ่านเซิร์ฟเวอร์ VISOR ดู CLIC กับ VISOR และสำหรับขั้นตอนทั่วไป ดู การใช้ VISOR

แถบความคืบหน้าไม่ขยับ: เป็นเรื่องปกติ

ขณะเครื่องมือทำงาน แถบความคืบหน้าค้างอยู่ที่ศูนย์ และไม่มีอะไรปรากฏในฉาก Slicer แม้ประมวลผลเสร็จแล้ว นี่ไม่ใช่การขัดข้อง: ไฟล์ผลลัพธ์ถูกเขียนลงดิสก์ในโฟลเดอร์ผลลัพธ์อยู่แล้ว คุณต้องไปหาและโหลดมันเอง: ดูด้านล่างว่ามันอยู่ที่ไหน

ใช้เมื่อใด

เมื่อคุณมี CBCT ที่มีเขี้ยวฝังคุดหนึ่งซี่หรือมากกว่า และอยากรู้ว่ามันอยู่ด้านใดของกระดูกเปลือก โดยไม่ต้องตรวจทีละซี่ด้วยตา CLIC ไม่ขึ้นกับโมดูลอื่น: ไม่จำเป็นต้องรัน AMASSS, ASO หรือ ALI มาก่อน

สิ่งที่ต้องใช้ สิ่งที่จะได้

สิ่งที่ต้องมี

  • โฟลเดอร์ของสแกน CBCT เป็น .nii หรือ .nii.gz
  • โมเดลที่ฝึกแล้ว ดาวน์โหลดครั้งเดียว
  • โฟลเดอร์ผลลัพธ์ ที่เลือกอย่างชัดเจน

สิ่งที่ได้

  • โฟลเดอร์ย่อยหนึ่งอันต่อสแกนหนึ่งชุด ภายในมี label map .nii.gz
  • ค่า voxel ที่เป็นไปได้สามค่า: buccal, bicortical, palatal
  • ซ้อนทับบนสแกนต้นทางได้โดยตรง ไม่ต้องลงทะเบียน
รูปแบบที่ยอมรับแต่ใช้งานไม่ได้จริง

ตัวเลือกไฟล์ยังแสดง .nrrd, .mha และ .mhd ด้วย อย่าใช้: การประมวลผลอ่านได้เฉพาะ .nii/.nii.gz และล้มเหลวกับรูปแบบอื่น ไม่ว่าตัวเลือกไฟล์จะอนุญาตอะไรก็ตาม

ใช้ได้เฉพาะ Linux

โมดูลไม่มีเส้นทางที่ใช้งานได้บน Windows ไม่ว่า README จะเขียนว่าอะไร ให้รันบน Slicer ที่ติดตั้งบน Linux

ขั้นตอน

  1. ดาวน์โหลดโมเดล ปุ่มเฉพาะจะดึงเครือข่ายที่ฝึกแล้ว ทำครั้งเดียว
  2. ชี้ไปที่โฟลเดอร์อินพุต โฟลเดอร์แบนที่มีไฟล์ .nii.gz ไม่ใช่โฟลเดอร์ของโฟลเดอร์ย่อย
  3. เลือกโฟลเดอร์ผลลัพธ์ ขั้นตอนนี้บังคับ: ถ้าไม่มี การประมวลผลจะล้มเหลวก่อนเริ่มด้วยซ้ำ
  4. รัน การรันครั้งแรกจะตั้งค่าสภาพแวดล้อมการคำนวณด้วย จึงใช้เวลานานกว่าครั้งหลัง ๆ
  5. รอจนจบ แม้ไม่มีอะไรขยับบนหน้าจอ การประมวลผลทำทีละสแกนโดยไม่มีผลตอบรับทางภาพคั่นกลาง

หาผลลัพธ์ได้ที่ไหน

เมื่อประมวลผลเสร็จ ให้เปิดโฟลเดอร์ผลลัพธ์ที่คุณเลือก: มีโฟลเดอร์ย่อยหนึ่งอันต่อสแกนที่ประมวลผล และภายในแต่ละอันมีไฟล์ .nii.gz ที่มีคำต่อท้ายตามที่แสดงในอินเทอร์เฟซ (seg เป็นค่าเริ่มต้น) ให้โหลดไฟล์นั้นเข้า Slicer เองเป็นวอลุ่มการแบ่งส่วน: มันจัดแนวกับสแกนต้นทางอยู่แล้ว ไม่ต้องลงทะเบียน ค่า 1, 2 และ 3 ตรงกับ buccal, bicortical และ palatal ตามลำดับ

ถ้าค้าง

ปุ่ม Cancel ไม่ทำอะไร

มันไม่หยุดทั้งการคำนวณที่กำลังรันและโพรเซสเบื้องหลัง ถ้าคุณจำเป็นต้องหยุดจริง ๆ ให้ปิด Slicer

การรันครั้งแรกต้องใช้อินเทอร์เน็ต

การสร้างเครือข่ายจะดาวน์โหลดน้ำหนักโมเดลที่ฝึกไว้ล่วงหน้าแบบทั่วไปก่อน แล้วจึงใช้โมเดลที่ฝึกแล้วทับลงไป หากไม่มีการเชื่อมต่อในความพยายามครั้งแรก การประมวลผลจะล้มเหลว

ไฟล์โมเดลสองไฟล์ในโฟลเดอร์

เมื่อมีไฟล์โมเดลมากกว่าหนึ่งไฟล์ในโฟลเดอร์โมเดล ไฟล์ที่ชื่อเรียงตามตัวอักษรก่อนจะถูกใช้ โดยไม่มีคำเตือน ให้เก็บไฟล์ .pth ไว้เพียงไฟล์เดียวในโฟลเดอร์นั้นเพื่อหลีกเลี่ยงความคลุมเครือ

วิธีอ้างอิง

โมดูลนี้ยังไม่มีงานตีพิมพ์ คำอธิบายสาธารณะเพียงแหล่งเดียวคือหน้าโครงการของ NA-MIC

หากคุณใช้ CLIC ในงานวิจัย ให้อ้างอิง:

Tulissi E, Cevidanes L, Prieto J, Bianchi J. Interpretable Deep Learning for the Detection and Classification of Impacted Canines and severity of root resorption. Project page, NA-MIC Project Week 43, Montreal, 2025.

projectweek.na-mic.org. รายงานโครงการ: เป้าหมาย ข้อมูล และความคืบหน้าของงาน ณ ขณะนั้น

เอกสารประกอบ ไม่ใช่การอ้างอิงเครื่องมือ

  • He et al., ICCV 2017: Mask R-CNN. สถาปัตยกรรมที่โมดูลใช้งาน: ตรวจจับวัตถุและสร้างมาสก์ของวัตถุไปพร้อมกัน
  • Swaity et al., Scientific Reports 2023: Deep learning driven segmentation of maxillary impacted canine on cone beam computed tomography images. ปัญหาเดียวกันที่ทีมวิจัยอื่นศึกษา พร้อมค่าความคลาดเคลื่อนที่วัดในกลุ่มตัวอย่างอิสระ
  • Pirayesh et al., BMC Oral Health 2024: A hierarchical deep learning approach for diagnosing impacted canine-induced root resorption. ด้านการละลายของรากฟัน: วิธีจัดระดับความรุนแรง และผลเมื่อเทียบกับผู้ประเมินที่เป็นมนุษย์
