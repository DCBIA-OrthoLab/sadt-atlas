คู่มือ › ข้อความและภาษา

Agent — ให้ผู้ช่วยในเครื่องเลือกเครื่องมือให้คุณ

Agent คือผู้ช่วยแบบสนทนาที่ทำงานทั้งหมดอยู่ในเครื่องของคุณ คุณอธิบายสิ่งที่ต้องการทำด้วยภาษาธรรมดา แล้วมันจะเสนอเครื่องมือจากส่วนขยาย พร้อมเติมพารามิเตอร์ไว้ให้เรียบร้อย — หรือเพียงตอบคำถามของคุณ ขึ้นอยู่กับโหมดที่ คุณเลือก

วิดีโอ
  • AI Agent directly in 3D Slicer to help you learn dental and cranofacial imaging 30 วินาที (ภาพรวม) · ช่อง DCBIA Videos
อ่านตรงนี้ก่อนลองใช้

ตามสภาพของรีโพสิทอรีในวันนี้ Agent หาเครื่องมือที่ตัวเองต้องการ สั่งรันไม่เจอ หากคุณไม่ตั้งค่าด้วยมือเอง ความพยายามรันเครื่องมือทุกครั้ง จะล้มเหลว โหมดที่ตอบคำถามเท่านั้นโดยไม่รันอะไรเลยไม่ได้รับผลกระทบ และ ทำงานได้ตามปกติ

ใช้เมื่อใด

ใช้เมื่อคุณไม่ต้องการนั่งค้นว่าโมดูลไหนในส่วนขยายตรงกับสิ่งที่คุณต้องการ หรือไม่อยาก ประกอบคำสั่งบรรทัดคำสั่งด้วยมือ: คุณอธิบายงาน — "จัดแนวภาพ CBCT ชุดนี้" "แบ่งส่วนภาพสแกนชุดนี้" — แล้ว Agent จะเสนอเครื่องมือพร้อมพารามิเตอร์ที่ เข้าใจได้จากคำขอของคุณ นอกจากนี้ยังใช้เป็นที่ปรึกษาธรรมดาได้ด้วย ในโหมด "Ask" สำหรับคำถามที่ไม่ต้องรันอะไรเลย

สิ่งที่ต้องติดตั้งก่อน

Agent พึ่งพาเซิร์ฟเวอร์โมเดลภาษาที่ทำงานอยู่ในเครื่องของคุณ คือ Ollama หากยังไม่มีอยู่ โมดูลจะเสนอให้ ดาวน์โหลดและเริ่มต้นให้คุณ ไม่ว่าทางใด ให้เตรียมใจว่าการเปิดใช้ครั้งแรกจะ ดาวน์โหลดข้อมูลหลายกิกะไบต์ — เฉพาะโมเดลภาษาเองก็เกิน 5 GB อยู่เล็กน้อย — ก่อนที่คุณจะถามคำถามแรกได้

ฝั่ง Slicer ไม่มีอะไรต้องติดตั้งด้วยมือ

แพ็กเกจ Python ที่จำเป็นจะติดตั้งตัวเองโดยอัตโนมัติในการเปิดใช้ ครั้งแรก ภายใน Python ของ Slicer เอง

สิ่งที่ต้องใช้ สิ่งที่จะได้

สิ่งที่ต้องเตรียม

  • คำขอที่เขียนด้วยภาษาธรรมดา เป็นภาษาอังกฤษหรือภาษาฝรั่งเศส
  • โหมดที่คุณต้องการ: Agent (Automated) เพื่อให้รัน งานจริง หรือ Ask (Interactive) เพื่อเพียงพูดคุย
  • หากเกี่ยวข้อง ให้ลากโฟลเดอร์ที่ใช้มาวางในพื้นที่วางไฟล์

สิ่งที่ได้ออกมา

  • ในโหมด Agent: เครื่องมือที่เลือกไว้ พารามิเตอร์ของมัน กล่องยืนยัน แล้วจึงรันหากคุณอนุมัติ
  • ในโหมด Ask: คำตอบเป็นข้อความอิสระ ไม่มีการรันอะไรเลย
  • หากเครื่องมือล้มเหลว จะมีความพยายามซ่อมแซมอัตโนมัติไม่เกินสองครั้ง แต่ละครั้ง มีกล่องยืนยันของตัวเอง

ขั้นตอน

  1. ตรวจว่า Ollama ทำงานอยู่ หากจำเป็น ให้ Agent ติดตั้งและ เริ่มต้นให้คุณ แล้วรอให้โมเดลดาวน์โหลดเสร็จในการเปิดใช้ครั้งแรก
  2. เลือกโหมด "Agent (Automated)" เพื่อสั่งรันเครื่องมือจริง "Ask (Interactive)" เพื่อรับเพียงคำตอบ
  3. อธิบายสิ่งที่คุณต้องการ ด้วยภาษาธรรมดา เหมือนที่คุณจะ อธิบายให้เพื่อนร่วมงานฟัง
  4. ลากโฟลเดอร์ที่เกี่ยวข้องมาวาง ในพื้นที่วางไฟล์ หากคำขอของคุณ เกี่ยวกับข้อมูลชุดใดเป็นการเฉพาะ — Agent จะพยายามเดาว่าอันไหนคืออะไร
  5. ส่งข้อความ ในโหมด Agent จะมีการเสนอเครื่องมือและพารามิเตอร์ ของมัน ในโหมด Ask คำตอบจะกลับมาทันที

การอ่านกล่องยืนยัน

ในโหมด Agent จะไม่มีอะไรรันถ้าคุณไม่กด "Yes" ในกล่องที่แสดงรายการ พารามิเตอร์ทุกตัวที่มันตัดสินใจไว้ ในรูปของคู่ key=value นี่เป็นจุดเดียว ที่คุณจะจับได้ว่าโฟลเดอร์ถูกเดาผิด หรือค่าใดไม่ตรงกับที่คุณหมายถึง ก่อนที่เครื่องมือจะเริ่มทำงานจริง

อ่านทุกบรรทัดอย่างละเอียด

สำหรับเครื่องมือส่วนใหญ่ การจับคู่ระหว่างสิ่งที่ Agent เชื่อว่าตัวเองส่งไปกับ สิ่งที่เครื่องมือต้องการจริงนั้นคลาดเคลื่อน การรันจึงอาจเริ่มต้นด้วยค่าที่ผิด โดยไม่มีข้อผิดพลาดใดเตือนคุณล่วงหน้า — กล่องยืนยันคือ การตรวจทานจริงเพียงอย่างเดียวที่คุณมี

เมื่อคุณอนุมัติแล้ว อินเทอร์เฟซของ Slicer จะค้างไปจนกว่าเครื่องมือที่สั่งรันจะ ทำงานเสร็จ นั่นเป็นเรื่องปกติ ไม่มีอะไรต้องทำนอกจากรอ

หากเกิดปัญหา

"ไม่มีอะไรรัน หรือข้อผิดพลาดอ่านไม่ได้ความ"

ตามสภาพของรีโพสิทอรี Agent หาสคริปต์ที่ตัวเองต้องการรันด้วยตัวเองไม่เจอ: หากคุณไม่บอกมันเองว่าสคริปต์อยู่ที่ไหน การรันจะล้มเหลวก่อนจะเริ่มต้นเสียด้วยซ้ำ ขั้นซ่อมแซมอัตโนมัติที่ตามมาแก้เรื่องนี้ไม่ได้ — ปัญหาไม่ได้อยู่ที่ พารามิเตอร์ แต่อยู่ที่เส้นทางของสคริปต์

การรันที่เริ่มต้นด้วยค่าที่ผิด

ดูข้างต้น: ตรวจกล่องยืนยันทุกครั้งก่อนอนุมัติ พารามิเตอร์ที่ ไม่ตรงกันมักปรากฏให้เห็นด้วยตาในกล่องนั้นเท่านั้น ไม่ได้ปรากฏใน ข้อความแจ้งข้อผิดพลาด

ทุกอย่างช้าหากไม่มีการ์ดจอ

หากเซิร์ฟเวอร์โมเดลทำงานโดยไม่มี GPU ให้เตรียมใจว่าแต่ละคำตอบจะใช้เวลา ราวหนึ่งนาทีครึ่ง การสนทนาโต้ตอบไปมาจึงรวมเป็น หลายนาที ไม่ใช่หลายวินาที

เกี่ยวกับวิธีการ

  • Qwen Team, arXiv 2025 — Qwen3 Technical Report. แบบจำลองที่ตัดสินว่าจะส่งคุณไปยังเครื่องมือใด และสกัดพารามิเตอร์ของเครื่องมือนั้น
  • Reimers & Gurevych, EMNLP 2019 — Sentence-BERT: Sentence Embeddings using Siamese BERT-Networks. วิธีเปรียบเทียบคำถามกับเอกสารที่จัดทำดัชนีไว้: ขั้นตอนที่กำหนดว่าเอเจนต์จะมีข้อมูลใดอยู่ตรงหน้าก่อนตอบ
  • Nogueira & Cho, arXiv 2019 — Passage Re-ranking with BERT. การจัดอันดับใหม่ที่ใช้กับข้อความที่ค้นคืนมา ซึ่งช่วยปรับปรุงผลลัพธ์อันดับต้น ๆ ได้อย่างชัดเจน
