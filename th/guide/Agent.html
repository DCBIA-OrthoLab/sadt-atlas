Agent: ให้ผู้ช่วยในเครื่องเลือกเครื่องมือ

Agent เป็นผู้ช่วยสนทนาที่ทำงานบนเครื่องของคุณทั้งหมด คุณอธิบายสิ่งที่ต้องการทำด้วยภาษาธรรมดา และมันเสนอเครื่องมือจาก extension ที่กรอกพารามิเตอร์ไว้แล้ว หรือเพียงตอบคุณ ขึ้นอยู่กับโหมดที่คุณเลือก

วิดีโอ
  • AI Agent directly in 3D Slicer to help you learn dental and cranofacial imaging30 วินาที (ภาพรวม) · ช่อง DCBIA Videos
หน้าโมดูล Legacy

หน้านี้อธิบายโมดูล Slicer แบบ legacy extension VISOR จัดส่งสำเนาของแผงนี้ที่ยังรันบนคอมพิวเตอร์ของคุณ และเซิร์ฟเวอร์ VISOR มีเครื่องมือ Agent แยกต่างหากที่ไม่มีแผงใดเรียก: ดูAgent กับ VISOR และการใช้ VISOR

อ่านก่อนลอง

ตามสภาพของที่เก็บโค้ดในปัจจุบัน Agent หาตำแหน่งเครื่องมือที่ต้องการเปิดไม่เจอ หากไม่ตั้งค่าด้วยมือ ความพยายามรันเครื่องมือใด ๆ จะล้มเหลว โหมดที่เพียงตอบ โดยไม่รันอะไร ไม่ได้รับผลกระทบและทำงานตามปกติ

ใช้เมื่อใด

ใช้เมื่อคุณไม่อยากไล่หาว่าโมดูลใดใน extension ตรงกับที่ต้องการ หรือสร้างบรรทัดคำสั่งด้วยมือ: คุณอธิบายงาน เช่น "จัดทิศทาง CBCT เหล่านี้" "แบ่งส่วนภาพสแกนเหล่านี้" และ Agent เสนอเครื่องมือพร้อมพารามิเตอร์ที่มันเข้าใจจากคำขอของคุณ มันยังใช้เป็นที่ปรึกษาธรรมดาได้ในโหมด "Ask" สำหรับคำถามที่ไม่ต้องรันอะไร

สิ่งที่ต้องติดตั้งก่อน

Agent พึ่งพาเซิร์ฟเวอร์โมเดลภาษาที่รันในเครื่องของคุณ คือ Ollama หากยังไม่มี โมดูลเสนอดาวน์โหลดและเริ่มให้ ไม่ว่ากรณีใด คาดว่าการเปิดครั้งแรกจะดาวน์โหลดหลายกิกะไบต์ โมเดลภาษาเพียงอย่างเดียวก็เกิน 5 GB เล็กน้อย ก่อนที่คุณจะถามคำถามแรกได้

ไม่ต้องติดตั้งด้วยมือฝั่ง Slicer

ไลบรารี Python ที่ต้องใช้ติดตั้งตัวเองโดยอัตโนมัติเมื่อเปิดครั้งแรก ภายใน Python ของ Slicer เอง

สิ่งที่ต้องใช้ สิ่งที่จะได้

สิ่งที่ต้องเตรียม

  • คำขอที่เขียนด้วยภาษาธรรมดา เป็นภาษาอังกฤษหรือฝรั่งเศส
  • โหมดที่ต้องการ: Agent (Automated) เพื่อรันบางอย่างจริง Ask (Interactive) เพื่อเพียงสนทนา
  • หากเกี่ยวข้อง โฟลเดอร์ที่เกี่ยวข้อง วางลงในโซนวาง

สิ่งที่ได้ออกมา

  • ในโหมด Agent: เครื่องมือที่เลือก พารามิเตอร์ของมัน กล่องยืนยัน แล้วรันหากคุณอนุมัติ
  • ในโหมด Ask: คำตอบเป็นข้อความอิสระ ไม่มีอะไรถูกเปิดรัน
  • หากเครื่องมือล้มเหลว มีความพยายามซ่อมอัตโนมัติสูงสุดสองครั้ง แต่ละครั้งมีการยืนยันของตัวเอง

ขั้นตอน

  1. ตรวจให้แน่ใจว่า Ollama กำลังรันอยู่ หากจำเป็น ให้ Agent ติดตั้งและเริ่มให้ และรอให้ดาวน์โหลดโมเดลเสร็จในการเปิดครั้งแรก
  2. เลือกโหมด "Agent (Automated)" เพื่อเปิดรันเครื่องมือจริง "Ask (Interactive)" เพื่อรับเพียงคำตอบ
  3. อธิบายสิ่งที่ต้องการ ด้วยภาษาธรรมดา แบบที่คุณจะอธิบายให้เพื่อนร่วมงานฟัง
  4. วางโฟลเดอร์ที่เกี่ยวข้องลงในโซนวางหากคำขอเกี่ยวข้องกับข้อมูลเฉพาะ: Agent จะพยายามเดาว่าอันไหนคืออะไร
  5. ส่งข้อความ ในโหมด Agent จะมีการเสนอเครื่องมือและพารามิเตอร์ของมัน ในโหมด Ask คำตอบกลับมาทันที

การอ่านกล่องยืนยัน

ในโหมด Agent ไม่มีอะไรรันโดยไม่มี "Yes" จากคุณ ในกล่องที่แสดงพารามิเตอร์ทุกตัวที่มันตัดสินใจไว้ เป็นคู่ key=value นี่คือจุดเดียวที่คุณจะจับโฟลเดอร์ที่เดาผิดหรือค่าที่ไม่ตรงกับที่คุณหมายได้ ก่อนที่เครื่องมือจะเริ่มจริง

อ่านทุกบรรทัดอย่างรอบคอบ

สำหรับเครื่องมือส่วนใหญ่ การแมประหว่างสิ่งที่ Agent เชื่อว่ากำลังส่งกับสิ่งที่เครื่องมือคาดหวังจริงคลาดเคลื่อน การรันจึงอาจเริ่มด้วยค่าที่ผิดโดยไม่มีข้อผิดพลาดใดเตือนล่วงหน้า: กล่องยืนยันคือการตรวจจริงเพียงอย่างเดียวของคุณ

เมื่ออนุมัติแล้ว อินเทอร์เฟซของ Slicer จะค้างจนกว่าเครื่องมือที่เปิดจะรันเสร็จ: เป็นเรื่องปกติ ไม่มีอะไรต้องทำนอกจากรอ

หากมีสิ่งผิดปกติ

"ไม่มีอะไรเปิดรัน หรือข้อผิดพลาดไม่สมเหตุสมผล"

ตามสภาพของที่เก็บโค้ด Agent หาสคริปต์ที่ต้องการรันเองไม่เจอ: เว้นแต่คุณบอกมันเองว่าอยู่ที่ใด การรันล้มเหลวก่อนจะเริ่มด้วยซ้ำ ขั้นตอนซ่อมอัตโนมัติที่ตามมาแก้ไม่ได้: ปัญหาไม่ได้อยู่ที่พารามิเตอร์ แต่อยู่ที่พาธของสคริปต์

การรันที่เริ่มด้วยค่าที่ผิด

ดูข้างบน: ตรวจกล่องยืนยันทุกครั้งก่อนอนุมัติ ความไม่ตรงกันของพารามิเตอร์มักเห็นได้ด้วยตาเท่านั้น ในกล่องนั้น ไม่ใช่ในข้อความแสดงข้อผิดพลาด

ทุกอย่างช้าเมื่อไม่มีการ์ดจอ

หากเซิร์ฟเวอร์โมเดลรันโดยไม่มี GPU คาดว่าแต่ละคำตอบจะใช้เวลาราวหนึ่งนาทีครึ่ง การสนทนาโต้ตอบไปมารวมกันเป็นหลายนาที ไม่ใช่วินาที

เอกสารประกอบ ไม่ใช่การอ้างอิงเครื่องมือ

  • Qwen Team, arXiv 2025: Qwen3 Technical Report. แบบจำลองที่ตัดสินว่าจะส่งคุณไปยังเครื่องมือใด และสกัดพารามิเตอร์ของเครื่องมือนั้น
  • Reimers & Gurevych, EMNLP 2019: Sentence-BERT: Sentence Embeddings using Siamese BERT-Networks. วิธีเปรียบเทียบคำถามกับเอกสารที่จัดทำดัชนีไว้: ขั้นตอนที่กำหนดว่าเอเจนต์จะมีข้อมูลใดอยู่ตรงหน้าก่อนตอบ
  • Nogueira & Cho, arXiv 2019: Passage Re-ranking with BERT. การจัดอันดับใหม่ที่ใช้กับข้อความที่ค้นคืนมา ซึ่งช่วยปรับปรุงผลลัพธ์อันดับต้น ๆ ได้อย่างชัดเจน
