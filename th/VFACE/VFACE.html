VFACE

ตัวประสานงาน (orchestrator) ที่ไม่ได้เรียนรู้หรือแบ่งส่วนสิ่งใดด้วยตัวเอง: มันเรียกใช้โมดูลอื่นหกตัวต่อกันเพื่อลงทะเบียนภาพ CBCT เข้ากับภาพสะท้อนของตัวเอง วัดระยะห่าง และจำแนกความไม่สมมาตรของใบหน้าเชิงโครงกระดูกด้วยโมเดล LightGBM สามตัว

SPIE Medical Imaging 2026 vface_cli สภาพแวดล้อม conda: ไม่มี (Python ของ Slicer) บรรณานุกรม

การจำแนกความไม่สมมาตรของใบหน้าเชิงโครงกระดูกบน CBCT โดยอัตโนมัติ VFACE ไม่ได้เรียนรู้หรือแบ่งส่วนสิ่งใดด้วยตัวเอง: มันเป็นตัวประสานงานที่ เรียกใช้โมดูลอื่นหกตัวในรีโพสิทอรีต่อกัน สกัดค่าวัดเชิงเส้นและ เชิงมุมจากผลลัพธ์ แล้วปิดท้ายด้วยตัวจำแนก LightGBM สามตัว เป็นโมดูลระดับสูงสุดของห่วงโซ่ — แผนผังการเรียกใช้ (call tree) คือข้อมูลหลัก ของหน้านี้

หลักการทางคลินิกสรุปได้ในประโยคเดียว: T2 คือภาพสะท้อน ของผู้ป่วยเอง ไม่มีภาพสแกนครั้งที่สอง ภาพสแกนถูกจัดแนว สะท้อน ผ่านระนาบกึ่งกลางซากิตตัล ลงทะเบียนภาพเข้ากับต้นฉบับ และทุกสิ่งที่ วัดได้คือระยะห่างระหว่างผู้ป่วยกับภาพสะท้อนของตัวเอง

4.1 ALI-CBCT

โครงข่าย agent การเรียนรู้แบบเสริมกำลัง (reinforcement learning), monai DenseNet

agent การเรียนรู้แบบเสริมกำลัง: หนึ่ง agent ต่อหนึ่ง landmark เคลื่อนที่ภายใน บริเวณ agent_FOV = [64,64,64] สองสเกล spacing = [1, 0.3] mm, speed_per_scale = [1,1], spawn_radius = 10 การเคลื่อนที่ที่เป็นไปได้หกแบบ (MOVEMENT_MATRIX_6, constants.py:22) เอาต์พุต: ไฟล์ .mrk.json หนึ่งไฟล์ต่อกลุ่มกายวิภาค (CB, U, L, CI) ตั้งชื่อว่า <scan>_lm_Pred_<group>.mrk.json

landmark ที่ขอสำหรับการวัดคือยูเนียนที่ตัดรายการซ้ำแล้วของ คอลัมน์ Point 1 / Point 2 / Line ในรายการ MAND และ CB (createlistprocess.py:141) — dict.fromkeys ป้องกันไม่ให้ landmark ที่ใช้ร่วมกันทั้งสองรายการเรียก agent สองครั้ง

4.3 BDS / DentalSegmentator — พื้นผิว

โครงข่าย nnU-Net 3d_fullres

run_bds เรียก run_dental_segmentation(model="DentalSegmentator", device="cuda", export_formats = VTK | VTK_MERGED) nnU-Net สร้าง label map 5 คลาส (Upper Skull, Mandible, Upper Teeth, Lower Teeth, Mandibular canal, segmentation_logic.py:600) ซึ่งแปลงเป็นพื้นผิว:

  • _exportMergedVTK: vtkDiscreteMarchingCubes (หนึ่งเส้นขอบต่อค่า label ที่มีอยู่ อ้างอิงตามตำแหน่งแทนตามค่า — คอมเมนต์ในโค้ด อธิบายบั๊กที่แก้ไขแล้ว) vtkWindowedSincPolyDataFilter 60 รอบ passband 0.05 normal ต่อเซลล์ vtkQuadricDecimation 0.4 ต่อ label แล้วแปลง IJK→RAS→LPS ก่อนเขียนไฟล์
  • _exportVTKPerLabel: ห่วงโซ่เดียวกันบนการแทนแบบ "Closed surface" ของแต่ละ segment หนึ่งไฟล์ต่อโครงสร้าง

น้ำหนักไม่ได้อยู่ในรีโพสิทอรี: มีเพียง dataset.json และ plans.json ที่ถูกเก็บในระบบควบคุมเวอร์ชัน และ PythonDependencyChecker ตรวจสอบว่ามี Dataset111_453CT/nnUNetTrainer__nnUNetPlans__3d_fullres/fold_0/checkpoint_final.pth หรือไม่ ก่อนดาวน์โหลดจาก URL ใน download_info.json (~220 MB) โมเดลอีกสามตัวที่มีให้เลือก (PediatricDentalsegmentator, NasoMaxillaDentSeg, UniversalLabDentalsegmentator) มีโค้ดดาวน์โหลด แต่ไม่เคยถูกเลือกโดย VFACE: เป็นโค้ดที่ไม่ถูกใช้งานในที่นี้ และพาธ Path(__file__).parent/"Resources" ของโมเดลเหล่านั้นก็ผิดไป หนึ่งระดับ (VFACE_utils/Resources/...) ต่างจากพาธที่แก้ไขแล้วของ โมเดลเริ่มต้น (segmentation_logic.py:457)

สูตรมุม (Angle.__computeAngles, Measure.py:664) u = p2 − p1, v = p4 − p3 สำหรับแต่ละแกน a ใน [2, 0, 1] — ตามลำดับคือ yaw (ระนาบแนวนอน) pitch (ระนาบซากิตตัล) roll (ระนาบโคโรนัล):

  1. ตัดองค์ประกอบ a ออก (ฉายลงสองมิติ) แล้วทำให้เป็นหน่วย
  2. θ = degrees(arctan2(‖u × v‖, u · v))
  3. ถ้า p2 == p3 (เส้นทั้งสองมีจุดยอดร่วมกัน): θ ← 180 − θ — นี่คือ สิ่งที่ทำให้ RCo-RGo / RGo-Me กลายเป็นมุม gonial ทางกายวิภาค
  4. เครื่องหมาย: z = u_x·v_y − u_y·v_x สำหรับแกน yaw เครื่องหมายเป็นไปตาม z สำหรับ pitch และ roll จะกลับเครื่องหมาย

งานตีพิมพ์ที่เกี่ยวข้องคือ "Automated classification of skeletal facial asymmetry in CBCT using a reproducible 3D Slicer workflow for patient-specific decision support", SPIE Medical Imaging 2026, vol. 13929, art. 139292J, doi:10.1117/12.3087010 (หน้า SPIE) บทคัดย่อที่เผยแพร่สาธารณะอธิบายผู้ป่วย Class III 170 ราย และห่วงโซ่ต้นทาง เดียวกัน: การเตรียมข้อมูลแบบมาตรฐาน การสะท้อนภาพ การลงทะเบียนภาพระดับวอกเซล และการสกัดค่าวัดทางกายวิภาค

โค้ดกับบทความไม่ตรงกัน

โค้ดแตกต่างจากบทความที่ขั้นตอนสุดท้าย บทคัดย่ออธิบายแนวทาง แบบไม่มีผู้สอน — การลดมิติ (PCA, t-SNE, UMAP) แล้วตามด้วย Spectral Clustering โดย UMAP+RBF ให้ค่า silhouette score ดีที่สุด ในทางกลับกัน โมดูลมาพร้อมกับตัวจำแนกแบบไบนารีที่มีผู้สอนด้วย LightGBM สามตัว ซึ่งฝึกด้วยฟีเจอร์คงที่ 14 ตัว ทั้งสองไม่ใช่โมเดลเดียวกัน ไม่มีสิ่งใดในรีโพสิทอรีที่เชื่อมโยงป้ายกำกับที่ใช้ฝึก LightGBM เข้ากับกลุ่ม ในบทความ และสคริปต์ที่ใช้ฝึกไม่ได้ถูกเก็บในระบบควบคุมเวอร์ชัน
