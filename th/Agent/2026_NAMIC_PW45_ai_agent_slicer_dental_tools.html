AI-Agent สำหรับ SlicerAutomatedDentalTools

รายงานโครงการ: NA-MIC Project Week ครั้งที่ 45, บอสตัน, 2026 หมวด: โครงสร้างพื้นฐาน

คำแถลงเจตนา ไม่ใช่สถานะ

รายงานนี้ประกาศ llama3:latest ในขณะที่โค้ดกำหนดตายตัวเป็น qwen3:8b และ "ขั้นตอนต่อไป" ของรายงาน (การรวม LLM, การติดตั้งใน Slicer) สำเร็จแล้วในที่เก็บโค้ด ให้อ่านเป็นคำแถลงเจตนาที่มีวันที่กำกับ ไม่ใช่คำอธิบายของโมดูลในสภาพปัจจุบัน ดูหน้าไปป์ไลน์สำหรับสถานะจริง

คำอธิบายโครงการ

ปัญหา: ส่วนขยาย Slicer Automated Dental Tools ให้การวิเคราะห์กะโหลกศีรษะและใบหน้าที่แข็งแกร่ง แต่การเลือกโมดูลและการปรับพารามิเตอร์ที่ซับซ้อนทำให้ผู้ใช้ต้องเรียนรู้มาก

วิธีแก้: โครงการนี้เสนอ AI Agent และ UI แชตบอตที่รวมอยู่ใน 3D Slicer เพื่อให้เวิร์กโฟลว์คล่องขึ้น ด้วยการรับอินพุตแบบลากและวาง และพรอมต์ภาษาธรรมชาติ ผู้ใช้จึงขอให้ทำงานซับซ้อนได้ง่าย (เช่น การแบ่งส่วน การระบุ landmark หรือการจัดทิศทางบน CBCT/IOS) เอเจนต์แปลคำขอเหล่านี้เป็นการกระทำเอง เลือกเครื่องมือที่เหมาะสมและตั้งค่าพารามิเตอร์ให้อัตโนมัติเพื่อรันเวิร์กโฟลว์

วัตถุประสงค์

  • การรวม LLM ในเครื่อง: ใช้ Ollama รันโมเดลในเครื่องขนาดเบา (ปัจจุบันคือ llama3:latest)
  • การดึงข้อมูลด้วย Cross-Encoder: ระบบใช้ Cross-Encoder ให้คะแนนความเกี่ยวข้องเชิงความหมายระหว่างคำถามของผู้ใช้กับกรณีการใช้งานของเครื่องมือโดยตรง เพื่อดึงโมดูลที่เหมาะสมที่สุด 3 อันดับแรก
  • การทำงานอัตโนมัติ: LLM วิเคราะห์บริบทที่ดึงมา เลือกเครื่องมือที่เหมาะที่สุด ดึงพารามิเตอร์ที่ต้องการจากข้อความของผู้ใช้ และสั่งรันภายใน Slicer โดยอัตโนมัติ

แนวทางและแผน

  • สร้างไปป์ไลน์แบ็กเอนด์หลักที่รวมโมเดลการดึงข้อมูลแบบ Cross-Encoder กับ LLM ในเครื่อง
  • ติดตั้งไปป์ไลน์ภายใน 3D Slicer และเชื่อมต่อกับ UI แชตบอตที่ผู้ใช้เห็น
  • สร้างวงจรป้อนกลับอัตโนมัติ โมเดลจะตรวจว่าเครื่องมือ Slicer ที่เลือกรันสำเร็จหรือเกิดข้อผิดพลาด และให้ข้อมูลป้อนกลับแก่ผู้ใช้แบบเรียลไทม์

ความคืบหน้าและขั้นตอนต่อไป

ความคืบหน้าปัจจุบัน
ระบบดึงข้อมูลฝั่งแบ็กเอนด์ทำงานได้เต็มที่ โมเดล Cross-Encoder ระบุและเลือกเครื่องมือ Slicer ที่เหมาะสมจากอินพุตภาษาธรรมชาติได้อย่างน่าเชื่อถือ

ขั้นตอนต่อไป

  • การรวม LLM: สร้างตรรกะให้ LLM ในเครื่องแยกวิเคราะห์พรอมต์ของผู้ใช้ เติมพารามิเตอร์ที่ต้องการอัตโนมัติ และสั่งรันเครื่องมือ
  • การติดตั้งใน Slicer: ฝัง UI แบบโต้ตอบและเชื่อมต่อไปป์ไลน์ AI ทั้งหมดโดยตรงในสภาพแวดล้อม 3D Slicer
