รายงานโครงการ — NA-MIC Project Week ครั้งที่ 45, Boston, 2026 หมวด: Infrastructure

คำแถลงเจตนา ไม่ใช่สภาพที่เป็นจริง

รายงานนี้ประกาศใช้ llama3:latest ขณะที่โค้ดกำหนด qwen3:8b ไว้ตายตัว และ "ขั้นต่อไป" ของรายงาน (การผนวก LLM การนำไปใช้ภายใน Slicer) ก็ทำเสร็จแล้วในรีโพสิทอรี ให้อ่านเอกสารนี้ในฐานะคำแถลงเจตนาที่มีวันกำกับ ไม่ใช่คำอธิบายสภาพของโมดูลตามที่เป็นอยู่ สำหรับสภาพจริงดู หน้า pipeline

คำอธิบายโครงการ

ปัญหา: ส่วนขยาย Slicer Automated Dental Tools ให้การวิเคราะห์กะโหลกศีรษะและใบหน้า ที่เชื่อถือได้ แต่การเลือกโมดูลที่ซับซ้อนและการปรับพารามิเตอร์ทำให้ผู้ใช้ต้องเรียนรู้สูงมาก

แนวทางแก้: โครงการนี้เสนอ AI Agent พร้อม UI แบบแชตบอตที่ผนวกเข้ากับ 3D Slicer เพื่อให้ขั้นตอนการทำงานราบรื่นขึ้น ด้วยการรับอินพุตแบบลากและวางและ prompt ภาษาธรรมชาติ ผู้ใช้จึงสั่ง งานที่ซับซ้อนได้โดยง่าย (เช่น การแบ่งส่วน การวาง landmark หรือการจัดแนวบน CBCT/IOS) ตัวเอเจนต์ จะแปลคำสั่งเหล่านี้เป็นการกระทำด้วยตนเอง โดยเลือกเครื่องมือที่ถูกต้องและตั้งค่า พารามิเตอร์ให้อัตโนมัติเพื่อเดินขั้นตอนการทำงาน

วัตถุประสงค์

  • การผนวก LLM ในเครื่อง: ใช้ Ollama เพื่อรันโมเดลขนาดเล็กในเครื่อง (ปัจจุบันคือ llama3:latest)
  • การค้นคืนด้วย Cross-Encoder: ระบบใช้ Cross-Encoder ซึ่งให้คะแนนความเกี่ยวข้องเชิงความหมาย ระหว่างคำถามของผู้ใช้กับกรณีใช้งานของเครื่องมือโดยตรง เพื่อดึงโมดูลที่เหมาะสมที่สุด 3 อันดับแรก
  • การทำงานด้วยตนเอง: LLM วิเคราะห์บริบทที่ค้นคืนมา เลือกเครื่องมือที่ดีที่สุด สกัด พารามิเตอร์ที่จำเป็นจากข้อความของผู้ใช้ และสั่งให้ทำงานภายใน Slicer โดยอัตโนมัติ

แนวทางและแผนงาน

  • สร้าง pipeline แกนหลักฝั่งหลังบ้านที่ผนวกโมเดลค้นคืนแบบ Cross-Encoder กับ LLM ในเครื่อง
  • นำ pipeline ไปติดตั้งภายใน 3D Slicer และเชื่อมเข้ากับ UI แบบแชตบอตที่ผู้ใช้เห็น
  • ทำวงป้อนกลับอัตโนมัติ โมเดลจะตรวจว่าเครื่องมือ Slicer ที่เลือกไว้ทำงานสำเร็จหรือเกิด ข้อผิดพลาด แล้วแจ้งผลให้ผู้ใช้ทราบแบบทันที

ความคืบหน้าและขั้นต่อไป

ความคืบหน้าปัจจุบัน
ระบบค้นคืนฝั่งหลังบ้านทำงานได้ครบถ้วนแล้ว โมเดล Cross-Encoder ระบุและเลือก เครื่องมือ Slicer ที่เหมาะสมจากข้อความภาษาธรรมชาติได้อย่างน่าเชื่อถือ

ขั้นต่อไป

  • การผนวก LLM: ทำตรรกะให้ LLM ในเครื่องแยกวิเคราะห์ prompt ของผู้ใช้ เติม พารามิเตอร์ที่จำเป็นอัตโนมัติ และสั่งให้เครื่องมือทำงาน
  • การติดตั้งใน Slicer: ฝัง UI แบบโต้ตอบและเชื่อม pipeline AI ทั้งหมดเข้าไว้ในสภาพแวดล้อม ของ 3D Slicer โดยตรง
