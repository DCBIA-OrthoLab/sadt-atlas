Agent — แหล่งอ้างอิง

ยังไม่ตีพิมพ์ ไม่มีงานตีพิมพ์ใดครอบคลุมโมดูลนี้หรือแนวทางของมัน แต่มีเอกสารทางการอยู่ฉบับหนึ่งที่ต้องค้นหาให้พบ: รายงานโครงการของ NA-MIC

รายงานอธิบายเจตนา ไม่ใช่สภาพที่เป็นจริง

มีการเก็บรายงาน NA-MIC Project Week (PW45, Boston, 2026) ที่ลงชื่อโดยผู้เขียน ไว้ที่นี่ รายงานอธิบายโมดูลตามเจตนา ไม่ใช่ตามสภาพที่เป็นจริง — ประกาศใช้ llama3:latest ขณะที่โค้ดกำหนด qwen3:8b ไว้ตายตัว และ "ขั้นต่อไป" (การผนวก LLM การนำไปใช้ภายใน Slicer) ก็ทำเสร็จแล้วในรีโพสิทอรี เอกสารอ้างอิงอื่นที่ เป็นประโยชน์ล้วนเป็นเรื่องเทคนิคทั้งสิ้น: โมเดลที่ให้บริการโดย Ollama ตัว cross-encoder สำหรับการคัดเลือกเบื้องต้น และชุดข้อมูลที่โมเดลนั้น มาจาก

งานที่เกี่ยวข้อง

งานต่อไปนี้ไม่มีชิ้นใดอธิบายโมดูลนี้

  • MS MARCO (Bajaj เก็บไว้แล้ว): reranker ถูกฝึกให้จัดอันดับ passage จากเว็บ สำหรับคำค้นของ Bing ที่นี่มันได้รับการ์ดของโมดูล Slicer และ prompt ของผู้ใช้งาน ซึ่งเป็น โดเมนและระดับภาษาที่มันไม่ได้ถูกฝึกมา และไม่มีการประเมินใด ๆ ในรีโพสิทอรี
  • Qwen3 (เก็บไว้แล้ว): รายงานทางเทคนิคของโมเดลทั่วไป ไม่มีทั้ง system prompt ของโมดูล รูปแบบเอาต์พุต JSON แบบบังคับ และวงซ่อมแซมของโมดูลปรากฏอยู่ในรายงานนั้น — และโค้ด ก็ไม่ได้ส่ง temperature, seed, num_ctx หรือ think ไปด้วย
  • Ollama และ llama.cpp เซิร์ฟเวอร์และกลไกการอนุมานที่ใช้จริง: ไม่มี งานตีพิมพ์ ollama.com · github.com/ggml-org/llama.cpp
  • เอเจนต์อีกตัว โครงการอื่น: Tu P., Dominguez M., Kikinis R., Pieper S., Kim S., Interactive Workflow Replay and Step-Back Navigation for Slicer Agent, 45th NA-MIC Project Week, Boston, 2026 (ลิงก์) รายงานนี้ว่าด้วย puxuntu/Slicer_agent เอเจนต์ที่ สร้างและรันโค้ด Python ภายใน scene ของ Slicer — เป็นโค้ดคนละชุด ทีมคนละทีม นำเสนอใน project week เดียวกัน อย่าสับสนกับโมดูลนี้ ซึ่งเรียก CLI ของส่วนขยายและ ไม่เขียนโค้ดใดเลย
  • LLM ในห้องปฏิบัติการนี้ แต่เป็นงานอื่น: Gaydamour A. et al., Cevidanes L., AI-Driven Multimodal TMJ Patient Modeling: From Unstructured Notes to Precision Treatment, CLIP 2025, LNCS vol. 16126, p. 42-52 (10.1007/978-3-032-05479-1_5) ใช้ BART และ DeepSeek-R1 ที่ผ่าน fine-tuning เพื่อสกัดตัวชี้วัดทางคลินิก 56 รายการจากบันทึกทางคลินิก ของผู้ป่วย ไม่เกี่ยวกับการจัดเส้นทางไปยังโมดูลของ Slicer

สิ่งที่ค้นหาแล้วไม่พบ

ค้นฉบับเต็มบน Europe PMC และ OpenAlex ด้วยคำว่า SlicerAutomatedDentalTools และ "Automated Dental Tools": ไม่พบผลใดเกี่ยวกับเอเจนต์ LLM สแกนโครงสร้างไดเรกทอรี ทั้งหมดของรีโพสิทอรี NA-MIC/ProjectWeek (2,854 ไฟล์ ตั้งแต่ PW35 ถึง PW45): รายงาน PW45 ที่เก็บไว้ ข้างต้นเป็นรายการเดียวที่เกี่ยวกับโมดูลนี้ ค้นบนเว็บด้วย LLM agent + 3D Slicer + ทันตกรรม: ไม่พบ สิ่งใดนอกจากเอกสารประกอบของรีโพสิทอรีและงานทั่วไปเรื่อง LLM ในทันตกรรม ซึ่งไม่เกี่ยวกับโค้ดนี้ ไม่มีงานตีพิมพ์
