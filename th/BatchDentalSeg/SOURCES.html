BatchDentalSeg: แหล่งที่มา

อะไรเผยแพร่แล้ว อะไรยังไม่ และอะไรถูกดึงมาไว้ในโฟลเดอร์นี้

บรรณานุกรม กลับไปที่หน้า

โมดูลนี้เผยแพร่เพียงบางส่วน: ในสี่โมเดลที่มัน bundle ไว้ มีเพียง DentalSegmentator ที่มีบทความ และสำหรับโมเดลนั้นโค้ดกับบทความตรงกัน PediatricDentalSegmentator, UniversalLabDentalSegmentator และ NasoMaxillaDentSegmentator ไม่ผูกกับสิ่งตีพิมพ์ใด: ค้นหาแล้ว และไม่พบอะไร (รายละเอียดอยู่ท้ายไฟล์นี้) ตัวโมดูลเอง (การจัดคิว การจัดการหน่วยความจำ UI แบบชุด) ไม่ได้ถูกอธิบายที่ไหนเลย

ตัวเลข "513 สแกน" ยังไม่มีแหล่งอ้างอิง และขัดกับตัวเอง

ข้อควรระวัง

README ของรีโพซิทอรีประกาศ CBCT 513 สแกนในฟันผสมสำหรับ PediatricDentalSegmentator และ สำหรับ UniversalLabDentalSegmentator และ 135 สำหรับ NasoMaxillaDentalSegmentator โดยไม่มีเอกสารอ้างอิงและไม่มีชุดทดสอบ ไม่มีแหล่งใดมีตัวเลขนี้ แย่กว่านั้น ไฟล์ dataset.json ที่เผยแพร่พร้อมน้ำหนักโมเดลบน GitHub releases ของรีโพซิทอรีขัดแย้งกับมัน:

โมเดลnumTraining ที่ชุดประกาศREADMELabel
PediatricDentalSegmentator3805136 (พื้นหลัง + 5 โครงสร้าง เหมือน DentalSegmentator)
UniversalLabDentalSegmentator46251356 (พื้นหลัง + ฟัน 55 label การเรียงเลขแบบ Universal)
NasoMaxillaDentSegmentator1351357 (5 ของ DentalSegmentator + maxilla แยก)

มีเพียง NasoMaxilla ที่สอดคล้อง ตัวเลขยืนยันซ้ำโดยตรงจาก releases:

curl -sL https://github.com/DCBIA-OrthoLab/SlicerAutomatedDentalTools/releases/download/<TAG>/dataset.json
# PEDIATRICDENTALSEG_MODEL  -> numTraining 380, 6 labels
# UNIVERSALLAB_MODEL        -> numTraining 462, 56 labels
# NASOMAXILLADENTSEG_MODEL  -> numTraining 135, 7 labels

ข้อแตกต่างเล็กน้อยที่ต้องจำไว้: numTraining คือจำนวนเคสในชุดข้อมูลตามที่เตรียมสำหรับ nnU-Net ซึ่งไม่จำเป็นต้องเท่ากับจำนวนสแกนที่เก็บมา คอร์ปัส 513 สแกนที่บางส่วนถูกทิ้งระหว่างการเตรียมหรือแยกไว้เป็นชุดทดสอบ อาจให้ 380 ได้อย่างสมเหตุสมผล ดังนั้นนี่ไม่จำเป็นต้องเป็นข้อผิดพลาด แต่เป็นช่องว่างที่ไม่มีเอกสารใดบันทึก ข้ามสองโมเดล โดยมีตัวเลขเดียวกันที่ประกาศสำหรับสองคอร์ปัสที่ต่างกัน (380 และ 462) คำถามที่ต้องถามผู้เขียนคือ: 513 หมายถึงคอร์ปัสที่เก็บก่อนการเตรียมหรือไม่ และการแบ่งถูกอธิบายไว้ที่ใด

จนกว่าจะได้คำตอบ อย่าคัดลอก "513" ลงในข้อความทางวิทยาศาสตร์โดยไม่ได้รับการยืนยัน

งานที่เกี่ยวข้อง

งานเหล่านี้ไม่ได้อธิบายโมดูลนี้ มันประเมิน DentalSegmentator จากภายนอก หรือให้รากฐานของมัน

  • nnU-Net (Isensee et al. 2021): รากฐานของทั้งสี่โมเดล อธิบายวิธีที่กำหนดค่าตัวเองได้ ไม่ใช่โมเดลเหล่านี้หรือน้ำหนักโมเดลของมัน
  • Sinard et al. 2025 (ไฟล์ 2025_Sinard_DL_impacted_teeth_CBCT.xml): เปรียบเทียบสี่วิธีการแบ่งส่วน รวม DentalSegmentator บนสแกน CBCT ของผู้ป่วยที่มีฟันฝังหลายซี่ เป็นการประเมินภายนอกของโมเดลต้นฉบับ; ไม่กล่าวถึงสามรุ่นย่อยหรือโมดูลแบบชุด วิทยานิพนธ์ที่ตรงกันเข้าถึงได้อย่างเปิดบน DUMAS: dumas-05471245
  • Gkantidis N., Ghamri M., Dot G. Accuracy and generalizability of an open-source deep learning model for facial bone segmentation on CT and CBCT scans: An ex vivo study. Journal of Dentistry 170:106663, 2026, 10.1016/j.jdent.2026.106663 อีกการประเมินภายนอกของ DentalSegmentator (พรีปรินต์ medRxiv 10.64898/2025.12.28.25343101)
  • gaudot/SlicerDentalSegmentator : ส่วนขยายต้นทางและแหล่งของน้ำหนักโมเดล DentalSegmentator
  • KitwareMedical/SlicerNNUnet: ส่วนขยาย NNUNet ที่จำเป็น
  • MIC-DKFZ/nnUNet
