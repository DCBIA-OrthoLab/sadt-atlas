BatchDentalSeg — แหล่งอ้างอิง

สิ่งที่ตีพิมพ์แล้ว สิ่งที่ยังไม่ตีพิมพ์ และสิ่งที่เก็บไว้ในโฟลเดอร์นี้

บรรณานุกรม กลับไปที่หน้าเครื่องมือ

โมดูลนี้ตีพิมพ์เพียงบางส่วน: จากโมเดลสี่ตัวที่รวมมาด้วย มีเพียง DentalSegmentator ที่มีบทความ และสำหรับโมเดลนั้น โค้ดกับบทความ สอดคล้องกัน PediatricDentalSegmentator, UniversalLabDentalSegmentator และ NasoMaxillaDentSegmentator ไม่ผูกกับสิ่งตีพิมพ์ใดเลย — ได้ค้นหาไปแล้ว และไม่พบอะไร (รายละเอียดอยู่ท้ายไฟล์นี้) ตัวโมดูลเอง (การเข้าคิว การจัดการหน่วยความจำ UI แบบกลุ่ม) ไม่มีที่ไหนอธิบายไว้เลย

สามตัวแปร: ไม่มีสิ่งตีพิมพ์เลย

ไม่มีสิ่งตีพิมพ์ สิ่งที่ค้นหาไปแล้วและไม่ได้ผล:

  • Europe PMC, คำค้น PediatricDentalSegmentator, UniversalLabDentalSegmentator, NasoMaxillaDentSegmentator, pediatric dental segmentator mixed dentition CBCT nnU-Net: 0 ผลลัพธ์ ทุกครั้ง
  • OpenAlex ด้วยชื่อเดียวกัน: ไม่พบอะไร นอกจากบทคัดย่อการประชุม EJWF ข้างต้น
  • การค้นหาบนเว็บด้วยชื่อโมเดลแต่ละตัว และด้วย "Cevidanes / DCBIA + pediatric CBCT + primary teeth + 513": ผลลัพธ์ที่พบมีเพียง README ของรีโพสิทอรีเอง และงานของทีมอื่นที่ไม่เกี่ยวข้องกัน (เช่น Baraka et al., Multi-Architecture deep learning for CBCT segmentation of dental hard tissues and pulp in mixed dentition, J Dent 166:106344, 2026, 10.1016/j.jdent.2026.106344 — ทีมอื่นที่ไม่เกี่ยวข้องกัน, ภาพสแกน 151 ชิ้น, โครงสร้างอื่น: นี่ไม่ใช่โมเดล ที่โมดูลนี้ใช้)

ตัวเลข "ภาพสแกน 513 ชิ้น" ยังไม่มีแหล่งอ้างอิง — และขัดแย้งกันเอง

ข้อควรระวัง

README ของรีโพสิทอรีประกาศว่าใช้ภาพสแกน CBCT ในระยะฟันผสม 513 ชิ้น สำหรับ PediatricDentalSegmentator และ สำหรับ UniversalLabDentalSegmentator และ 135 ชิ้นสำหรับ NasoMaxillaDentalSegmentator โดย ไม่มีเอกสารอ้างอิงและไม่มีชุดทดสอบ ไม่มีแหล่งใดที่ให้ตัวเลขนี้ไว้ ที่แย่กว่านั้น ไฟล์ dataset.json ที่เผยแพร่มาพร้อมน้ำหนักบน GitHub releases ของรีโพสิทอรี ขัดแย้งกับตัวเลขนั้น:

โมเดลnumTraining ที่ชุดไฟล์ประกาศไว้READMElabel
PediatricDentalSegmentator3805136 (background + 5 โครงสร้าง เหมือน DentalSegmentator)
UniversalLabDentalSegmentator46251356 (background + ฟัน 55 ซี่ ตามการนับเลขแบบ Universal)
NasoMaxillaDentSegmentator1351357 (5 แบบของ DentalSegmentator + ขากรรไกรบนแยกออกมา)

มีเพียง NasoMaxilla ที่สอดคล้องกัน ตัวเลขได้รับการยืนยันซ้ำโดยตรงจาก releases:

curl -sL https://github.com/DCBIA-OrthoLab/SlicerAutomatedDentalTools/releases/download/<TAG>/dataset.json
# PEDIATRICDENTALSEG_MODEL  -> numTraining 380, 6 labels
# UNIVERSALLAB_MODEL        -> numTraining 462, 56 labels
# NASOMAXILLADENTSEG_MODEL  -> numTraining 135, 7 labels

ข้อควรพิจารณาให้ละเอียด: numTraining คือจำนวนเคสในชุดข้อมูล ตามที่เตรียมไว้สำหรับ nnU-Net ซึ่งไม่จำเป็นต้องเท่ากับจำนวนภาพสแกน ที่เก็บรวบรวมมา คลังภาพสแกน 513 ชิ้น ซึ่งบางส่วนถูกตัดออกระหว่างการเตรียมข้อมูล หรือ กันไว้เป็นชุดทดสอบ ก็อาจให้ผลเป็น 380 ได้อย่างชอบธรรม ดังนั้นนี่จึงไม่ จำเป็นต้องเป็นความผิดพลาด — แต่เป็นช่องว่างที่ไม่มีเอกสารใดอธิบายไว้ ครอบคลุมโมเดล สองตัว โดยประกาศตัวเลขเดียวกันสำหรับคลังข้อมูลสองชุดที่ต่างกัน (380 และ 462) คำถามที่ควรถามผู้เขียนคือ: 513 หมายถึงคลังข้อมูล ที่เก็บรวบรวมมาก่อนการเตรียมข้อมูลหรือไม่ และคำอธิบายการแบ่งชุดข้อมูลอยู่ที่ไหน

จนกว่าจะได้คำตอบนั้น อย่าคัดลอก "513" ไปใส่ในข้อความทางวิชาการโดย ไม่ได้รับการยืนยันก่อน

งานที่เกี่ยวข้อง

งานเหล่านี้ไม่ได้อธิบายโมดูลนี้ แต่ประเมิน DentalSegmentator จากภายนอก หรือเป็นรากฐานของมัน

  • nnU-Net (Isensee et al. 2021): รากฐานของโมเดลทั้งสี่ตัว อธิบาย วิธีที่กำหนดค่าตัวเองได้ ไม่ใช่โมเดลเหล่านี้หรือน้ำหนักของมัน
  • Sinard et al. 2025 (ไฟล์ 2025_Sinard_DL_impacted_teeth_CBCT.xml): เปรียบเทียบวิธีการแบ่งส่วนสี่วิธี รวมถึง DentalSegmentator บนภาพสแกน CBCT ของผู้ป่วยที่มีฟันคุดหลายซี่ เป็นการประเมินจากภายนอกของโมเดล ดั้งเดิม ไม่ได้พูดถึงสามตัวแปรหรือโมดูลแบบกลุ่มเลย วิทยานิพนธ์ที่ตรงกันเป็น open access บน DUMAS: dumas-05471245
  • Gkantidis N., Ghamri M., Dot G. Accuracy and generalizability of an open-source deep learning model for facial bone segmentation on CT and CBCT scans: An ex vivo study. Journal of Dentistry 170:106663, 2026, 10.1016/j.jdent.2026.106663 — การประเมินจากภายนอกของ DentalSegmentator อีกชิ้นหนึ่ง (preprint บน medRxiv 10.64898/2025.12.28.25343101)
  • gaudot/SlicerDentalSegmentator — ส่วนขยายต้นน้ำและแหล่งที่มาของน้ำหนัก DentalSegmentator
  • KitwareMedical/SlicerNNUnet — ส่วนขยาย NNUNet ที่จำเป็นต้องมี
  • MIC-DKFZ/nnUNet
