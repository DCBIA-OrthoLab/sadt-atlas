3.1 การประมวลผลก่อน

สองขั้น เขียนลงใน temp_fold ทั้งคู่ และไม่เคยถูกล้าง:

  1. การทำ windowing ของฮิสโทแกรม, CorrectHisto(scan, out, 0.01, 0.99) (preprocess.py:14): ฮิสโทแกรม 1000 bin, สะสมแล้วทำให้เป็นมาตรฐาน, ตัดที่เปอร์เซ็นไทล์ 1% และ 99%, จำกัดแข็งที่ [-1500, 4000] HU ผลลัพธ์เป็น int16 โดยคง spacing/origin/direction ไว้ ระวัง: ซิกเนเจอร์ค่าเริ่มต้นระบุ max_porcent=0.95 แต่การเรียกส่ง 0.99
  2. การ resample แบบ isotropic หนึ่งไฟล์ต่อหนึ่งสเกล: SetSpacing (itk, การประมาณค่าเชิงเส้น, nearest-neighbor ถ้ามี seg/Seg อยู่ในชื่อ) สำหรับแต่ละ sp ใน spacing = [1, 0.3] mm ขนาดใหม่คือ size * spacing / sp และ origin ถูกจัดให้อยู่กึ่งกลางกล่องทางกายภาพเดิม

3.2 Environment

Environment (environment.py:17) คือผู้ป่วยหนึ่งราย: พจนานุกรม {scale_key: {image, spacing, origin, size}} บวกรายการ landmark ที่ทำนายแล้ว หนึ่งอินสแตนซ์ต่อผู้ป่วยหนึ่งราย โดยเก็บทุกสเกลไว้ในหน่วยความจำ

GetZone(scale, center, crop_size) คือสิ่งเดียวที่เอเจนต์เห็นของโลก:

cropTransform = SpatialCrop(center.tolist() + self.padding, crop_size)
rescale = ScaleIntensity(minv=-1.0, maxv=1.0, factor=None)
crop = rescale(cropTransform(self.data[scale]["image"])).type(torch.float32)

หนึ่งเอเจนต์ต่อหนึ่ง landmark (agent.py:149) สร้างครั้งเดียวแล้วใช้ซ้ำกับผู้ป่วยทุกราย Brain ใหม่ถูกสร้าง และน้ำหนักของมันถูกโหลดใหม่สำหรับทุกคู่ (ผู้ป่วย, landmark) (ALI_CBCT.py:123): DenseNet 2 ตัวถูกสร้างใหม่ และไฟล์ .pth 2 ไฟล์ถูกอ่านใหม่ต่อหนึ่งจุดและต่อหนึ่งสแกน

เครือข่าย DNet (brain.py:39):

                        growth_rate=34, block_config=(6, 12, 24, 16))
