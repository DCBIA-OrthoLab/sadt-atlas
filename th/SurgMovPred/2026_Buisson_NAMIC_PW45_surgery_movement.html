New 3D Slicer Module to predict surgery movement for maxillofacial surgery

คำอธิบายโครงการ

การทำนายการเคลื่อนที่จากการผ่าตัดและเวกเตอร์การเคลื่อนที่ของกระดูกในซอฟต์แวร์วางแผน การผ่าตัดเสมือนยังคงเป็นงานที่ต้องอาศัยผู้เชี่ยวชาญอย่างมาก ศัลยแพทย์ต้องจำลองการตัดกระดูก และปรับชิ้นส่วนกระดูกด้วยมือ แม้จะมีการศึกษาแบบจำลองรูปร่างเชิงสถิติ (statistical shape model) และโครงข่ายถดถอยแบบการเรียนรู้เชิงลึกเพื่อทำขั้นตอนนี้โดยอัตโนมัติ แต่ผลลัพธ์ที่ได้ เป็นสนามการเสียรูปแบบหนาแน่น ซึ่งขาดความสามารถในการตีความเชิงเรขาคณิตที่จำเป็นต่อการ ชี้นำการตัดสินใจทางคลินิกหรือทางศัลยกรรม

โครงการนี้นำเสนอโมดูล 3D Slicer เฉพาะทางที่ขับเคลื่อนด้วยโมเดล Machine Learning แบบ Stacking ซึ่งฝึกบนชุดข้อมูลที่แข็งแรงของผู้ป่วย 1,496 ราย โมดูลช่วยให้ ขั้นตอนทางคลินิกง่ายขึ้น โดยให้ผู้ใช้อัปโหลดไฟล์อินพุต (เช่น Excel/CSV ที่มี พารามิเตอร์ทางคลินิก) แล้วได้รับการทำนายที่แม่นยำและอิงข้อมูลของ การเคลื่อนที่ของกระดูกขากรรไกรและใบหน้าที่ต้องการได้ทันที

วัตถุประสงค์

  • ฝังโมเดล ML แบบ Stacking ที่ฝึกไว้แล้วลงในสภาพแวดล้อมของ 3D Slicer เพื่อใช้ประโยชน์จาก ข้อมูลการผ่าตัดของผู้ป่วยหลายราย
  • ทำให้อ่านไฟล์อินพุต (Excel/CSV) ได้อย่างราบรื่นเพื่อสกัดคุณลักษณะเฉพาะของ ผู้ป่วยแต่ละราย
  • สร้างและแสดงคำแนะนำการเคลื่อนที่ของกระดูกอย่างแม่นยำภายใน หน้าจอ Slicer โดยตรง ตามผลการอนุมานของโมเดล

แนวทางและแผนงาน

  • พัฒนาตัวแยกวิเคราะห์ไฟล์อินพุต (Excel/CSV) เพื่อทำความสะอาดและเตรียมข้อมูลผู้ป่วยสำหรับ โมเดล
  • ผสานโมเดล ML แบบ Stacking ที่ฝึกไว้แล้วเข้ากับ scripted module ของ 3D Slicer ที่เขียนด้วย Python
  • ออกแบบ UI ของ Slicer ที่ใช้งานง่าย ให้แพทย์โหลดไฟล์ผู้ป่วย สั่งการทำนาย และแสดงภาพการเคลื่อนที่ของกระดูกที่แนะนำได้

ความคืบหน้าและขั้นต่อไป

โมเดล ML แบบ Stacking หลักได้รับการฝึกและตรวจสอบความถูกต้องสำเร็จแล้วด้วยชุดข้อมูล ผู้ป่วย 1,496 ราย

ระหว่างสัปดาห์โครงการ เราจะสร้าง UI แบบโต้ตอบและ pipeline ฝั่ง backend ภายใน 3D Slicer เพื่อจัดการไฟล์อินพุตและรัน pipeline การทำนายของโมเดล นอกจากนี้ เราจะตรวจสอบความแม่นยำของเอาต์พุตภายในสภาพแวดล้อม Slicer และสำรวจ วิธีที่เข้าใจง่ายในการแสดงการเคลื่อนที่ที่ทำนายให้ผู้ใช้เห็น
