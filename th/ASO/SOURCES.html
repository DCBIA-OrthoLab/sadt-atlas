ASO — แหล่งอ้างอิง

บรรณานุกรมของ ASO: สิ่งที่เก็บไว้ในโฟลเดอร์นี้ สิ่งที่ยังต้องอ่านออนไลน์ และงานที่เกี่ยวข้อง — งานที่รองรับวิธีการนี้แต่ไม่ได้อธิบายโค้ด

PDF 29 ไฟล์ / ข้อความเต็ม 54 ชิ้น ในคลังทั้งหมด ← หน้า pipeline

ASO_CBCT มีการตีพิมพ์แล้ว ในบท proceedings ของ workshop MICCAI (LNCS 14242, 2023) ซึ่งใช้ร่วมกับ AREG_CBCT: ข้อความเดียวกันอธิบายทั้งการจัดแนว (ASO) และ การลงทะเบียนภาพ (registration, AREG) บทนี้ต้องเสียค่าเข้าถึงที่ Springer แต่ ฉบับของผู้เขียนอ่านได้ฟรีบน PMC (PMC11104011) PMC ปิดกั้นการดาวน์โหลด PDF แบบอัตโนมัติ จึงไม่สามารถเก็บไฟล์ไว้ที่นี่ได้ (ดู "อ่านออนไลน์") ASO_IOS ไม่มีบทความของตนเอง: ข้อความที่ตีพิมพ์แล้วซึ่งใกล้เคียงที่สุดคือ AReg IOS (Hutin et al., LNCS 14350, 2023) ซึ่งอธิบายการจัดแนวเริ่มต้นด้วยจุดศูนย์กลางมวลฟันที่ใช้ร่วมกัน นั่นคือ PrePreAso

คำอธิบาย ASO_CBCT ในบทนี้ตรงกับโค้ด (จุดสังเกตทางกายวิภาค (landmark) ของ ALI_CBCT, การจัดแนวด้วย landmark 3 จุด แล้วปรับละเอียดด้วย ICP) ส่วน pre-orienter แบบ DenseNet ซึ่งไม่ปรากฏในบทความ ก็ไม่ได้ถูกเชื่อมต่ออยู่จริง ๆ แล้ว แต่ให้ระวังด้าน AREG ของบทเดียวกันไว้: มันไม่ได้อธิบายโค้ดการลงทะเบียนภาพในปัจจุบัน อีกต่อไป (รอบเดียวแทนที่จะเป็นสองรอบ, itk-elastix แทน SimpleElastix, AMASSS บน nnU-Net v2 แทน UNETR) — รายละเอียดอยู่ใน ../AREG_CBCT/SOURCES.md

งานที่เกี่ยวข้อง

งานเหล่านี้ไม่ได้อธิบาย ASO แต่รองรับวิธีการนี้หรือแสดงให้เห็น การใช้งานจริง

  • Ruellas 2016, Common 3-dimensional coordinate system นี่คือบทความ ที่นิยามระบบพิกัดร่วม ที่ ASO จัดแนวไปสู่: บทความแสดงก่อนว่า การจัดแนวศีรษะเปลี่ยนค่าการเคลื่อนที่ที่วัดได้ในสามมิติ แล้วจึงเสนอ การสร้างกรอบพิกัดร่วมจาก landmark "มาตรฐานทอง" ของการจัดแนวใน ASO และ landmark อ้างอิงที่มาพร้อมโมดูล มาจากข้อตกลงนี้ บทความไม่ได้พูดถึง ทั้ง ASO และ deep learning: ทุกอย่างในนั้นทำด้วยมือ
  • Gillot 2023, ALI_CBCT ตัวตรวจจับ landmark แบบ reinforcement learning ที่ ASO_CBCT พึ่งพาในการหาจุดต่าง ๆ ไม่ว่าอินพุตจะวางแนวแบบใด อธิบาย landmark 32 จุดและเอเจนต์หลายสเกล ไม่ใช่ขั้นการจัดแนว หน้าของตนเอง: ../ALI/
  • Barone 2024 (AJODO) การใช้งานทางคลินิก ไม่ใช่การตรวจสอบความถูกต้อง: บทความระบุว่า มีการใช้ "เครื่องมืออัตโนมัติที่อาศัย deep learning สำหรับการจัดแนว การลงทะเบียนภาพ การแบ่งส่วนกระดูก และการระบุ landmark" ของ CBCT ใน 3D Slicer นั่นคือ ASO + AREG + AMASSS + ALI ในสภาพ การใช้งานจริง กับผู้ป่วย Class III ที่ได้รับการผ่าตัด 17 ราย
  • หน้า NA-MIC Project Week, ไม่มี DOI: PW38 2023 Gran Canaria — ASO_CBCT (Anchling, Hutin, Gillot, Baquero, Bianchi, Ruellas, Miranda, Barone, Gurgel, Yatabe, Al Turkestani, Joshi, Cevidanes, Prieto) — นี่คือที่ซึ่งอธิบาย pre-orienter แบบ "under testing" ที่ไม่เคยถูกเชื่อมต่อเลย และ PW38 — Automatic Standardize Orientation IOS (Hutin, Anchling, Gurgel, Miranda, Al Turkestani, Barone, Cevidanes, Prieto) ซึ่งเป็นคำอธิบายเป็นลายลักษณ์อักษรเพียงแห่งเดียวของ pipeline ASO_IOS ทั้งหมด — การจัดแนวก่อน ด้วยฟันกรามและฟันหน้า, ICP บนจุดศูนย์กลางมวล 3 จุด, landmark ของ ALI_IOS, โหมดการสบฟัน
  • คลังโค้ด, ไม่มี DOI: lucanchling/ASO, DCBIA-OrthoLab/ASO, DCBIA-OrthoLab/SlicerAutomatedDentalTools

สิ่งที่ค้นหาแล้วไม่พบ

  • ฉบับของผู้เขียนแบบ open access ของบท LNCS ในที่อื่นนอกจาก PMC: Deep Blue (University of Michigan), HAL/DUMAS, Unpaywall, OpenAlex ไม่พบอะไรเลย
  • บทความของตนเองสำหรับ ASO_IOS และ บทความเกี่ยวกับ ALI_IOS (ตัวตรวจจับ landmark บน IOS ที่ ASO_IOS ใช้): ไม่มีอะไรใน Europe PMC, Crossref หรือ OpenAlex ยืนยันตรงกับที่หน้านี้ระบุไว้
  • การตรวจสอบความถูกต้องทางคลินิกแยกเฉพาะการจัดแนวเพียงอย่างเดียว (โปสเตอร์ IADR / AADOCR / AAO, บทความเรื่องความสามารถในการทำซ้ำของ ASO): ไม่มีรายการใดถูกจัดทำดัชนีไว้ ตัวเลข ที่ตีพิมพ์ของ ASO ยังคงเป็นตัวเลขจากบท LNCS (< 3° และ < 2 mm เทียบกับ ผู้เชี่ยวชาญ) บทคัดย่อของ IADR ไม่มี DOI หากมีอยู่จริง ก็ต้องค้นหา ผ่านคลังบทคัดย่อของ IADR
  • สิ่งตีพิมพ์ที่อธิบาย pre-orienter แบบ DenseNet: ไม่มีเลย นอกจาก ย่อหน้าบนหน้า Project Week PW38
